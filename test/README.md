# 测试

按实际行为变化补充必要覆盖，优先验证公开能力接口、资源归属、取消、迟到结果及恢复等可观察保证。避免为纯转发和实现结构添加重复测试。

界面回归从实际页面或共享控件入口验证可见布局、触点或操作结果。材质与动效的渲染通过实际画面核对。

应用与能力包测试分别放在所属模块；仓库工具测试与设备夹具放在本目录。应用测试在 `app/` 下运行 `flutter test --no-pub`，已接入 `scripts/check.sh`，并与静态分析、架构检查、生成一致性及格式检查一起执行。新增其他模块测试时同步接入检查入口。

架构检查回归通过 `dart test/architecture_test.dart` 在临时工作区验证真实导入与类型别名，已接入同一门禁。

Rust 身份测试使用官方 ADB/OpenSSL 固定向量，核对公钥编码、PEM 往返及预哈希授权签名，并接入同一门禁。

多窗口需在原生宿主补验。Android 在系统最近任务核对每个 Activity 的名称和复用。iPad 在系统窗口模式下核对 Scene 创建、聚焦和关闭，iPhone 核对应用内回退。打开同一被控设备的手机屏幕与独立应用，重开其中一个，确认系统聚焦原窗口。用系统按钮关闭其中一扇后，核对另一扇的画面、输入与设备连接。macOS 使用 Flutter 3.50 调试时，请先关闭远控子窗口再热重启。
