## 处理方式

全部问题不逐条修补：设计系统按 Prism UI 重写（`designs/design.md`），Ardot 变量重建为三个集合，母组件全部重建为带变体的组件集，画板原地重建。组件与 ID 见 `ardot-guide.md`。
