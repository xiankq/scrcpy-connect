# 全功能验收

从产品规格、Ardot 画板和代码入口找齐用户可见动作。逐设备记录真实运行结果，启动、单测、实际交互、视觉及性能证据分别登记。USB 与 TCP 指向同一台手机。双设备隔离使用另一台模拟被控端。

## 批次

- 启动、设备列表、发现、配对码、扫码、USB、IP、连接状态、重连、授权、工作台、设备详情、设备管理、连接配置、诊断、导入导出。
- 整机、独立应用、原应用接续、多窗口、首帧、点亮、熄屏、旋转、输入、截图、声音、剪贴板、比例、清晰度、帧率、后台和关闭。
- 文件目录、返回缓存、搜索、详情、批量选择、相册加载和分组、原尺寸、视频预览、目录发送、取回、冲突、中止、系统保存、系统分享、暂存、分享导入。
- 实时通知、过期和清除、系统提醒、通话接续、活动停止、外观、后台、本地记录、密钥、日志、关于、更新、无效路由。

## 证据

用已核对的功能结果判定通过。模拟器启动记录只覆盖安装启动。读取失败、空结果、系统取消、结果待确认单独记录。对实机使用测试样本，避免用个人文件和消息作为证据。
