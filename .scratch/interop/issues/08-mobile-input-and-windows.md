# 08 · 手机控手机的输入、全屏与窗口生命周期

Status: ready-for-agent
Type: research
Priority: P1
Depends on: 06, 07
Requirements: R03、R12、R20、R22–R25、R51

## 问题

怎样让触控、中文键盘、远端应用和本机系统手势在手机上协同工作？

## 研究输入与边界

一手依据与已有调查位于 `docs/research/`：mobile-input-and-clipboard.md；scrcpy-media-and-server.md。入口见[需求审计](../requirements-audit.md)和[任务索引](README.md)。不把文档调查、编译与真机通过混为同一状态；现行规格与用户后续纠正优先于历史研究候选。

## 工作与交付物

- 验证多点触控、边缘返回、导航、主动实体屏幕开关/锁定区别、旋转/横屏/全屏、系统分屏和失焦；保持原始画面比例与输入坐标，禁止新增查看模式。
- 验证移动端进入即全屏、隐藏主控系统栏与外置工具；整机/通知接续/独立应用一致。悬浮退出按钮连续跟手，释放吸附最近左右边并收起，点把手展开，拖动不误退出且触摸不穿透到远端；覆盖旋转/安全区/IME重排、系统边缘手势、读屏和降低动态。退出回工作台保留连接及其他活动。
- 比较本机IME与画面内远端IME，覆盖拼音候选/composing、删除/选区、emoji、WebView/自绘、密码与禁粘贴，不绕过认证。
- 定义键盘弹出/收起、遮挡、候选位置、会话切换与旧输入失效，避免把输入发给已切换设备。
- 验证应用单实例迁移说明、不支持独立窗口转主屏、关闭保留task、主屏与多窗口并行和资源不足。

交付到对应研究报告及能力／流程矩阵；涉及代码或画布验证时保留版本、可复现步骤与证据。依赖项约束对应实验与最终结论，资料研究可先开始。临时截图与日志样本按隐私处理后放临时目录，不把设计预览纳入 Git。

## 完成条件

- [ ] 用实际手机主控和至少常见中文IME形成可观察默认及限制；桌面键盘事件演示不能替代。
- [ ] 每个状态有画面/焦点归属与退出方式，失败有继续操作的路径。
- [ ] 将结果映射到产品coverage与Pencil变体，不要求用户选择底层输入协议。

## 本轮生命周期核查：A43／A45

A43已实际红→绿：发现时退出等待`view.release`／`session.pause`，拒绝或挂起均无法离页；改为本地非阻塞退出，输入释放／精确pause仍有序，失败在返回后提示未确认且不stop真实task。`remote_lifecycle_test`与`session_views_test`共32项通过（2秒），后补悬浮退出／系统返回×失败／挂起4组合全过，只pause原sid一次／无stop，返回页显示含设备归属的未确认提示；第一次修复曾触发新Scaffold前Snackbar断言及重复pause，后移反馈并加exiting guard后通过。**仅局部修复**：旧挂起session队列仍可能阻塞同session立即重进，真实故障UI E2E继续验收，A43不关闭。
