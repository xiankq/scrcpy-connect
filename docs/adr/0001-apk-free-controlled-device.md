# 被控设备保持免安装，通过 ADB 临时运行服务端

面向普通用户提供互联功能，同时要求被控设备无需 root、无需安装额外 APK。用户明确选择由被控设备开启 USB 或无线调试并完成授权，通过 ADB 推送和临时运行 scrcpy 服务端，必要时允许扩展 JAR；不以安装配套 APK 获取能力。

这使产品必须自行承担连接引导、会话启动与恢复，以及不同系统和厂商的权限兼容。通知、通话等扩展功能按实际设备能力验证；短信完整处理经通知进入手机原应用，不建设短信数据服务。源码中的实现路径不等于所有设备均已支持。JAR 的组织方式、生命周期及升级策略仍待研究和访谈决定。
