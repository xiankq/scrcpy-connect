# 独立应用窗口接续被控手机上的真实任务

独立应用窗口使用被控手机上的真实应用与现有登录态。用户接受应用仅支持单实例时迁移现有任务并明确说明，而不是把互联窗口定义为应用克隆；同一应用多实例按系统和应用实际支持提供。

这允许围绕真实 task、显示与焦点设计服务端和界面，不承诺新建虚拟显示即可复制任意应用实例。主屏与多个窗口并行仍是完整功能目标。后续用户将常规产品取舍交由代理依据 scrcpy 与厂商流程决定，当前默认关闭窗口时保留真实任务并交回手机，区别于强制停止应用；这不是将代理默认写成用户对 Q28 的逐项确认。任务迁回、应用自行退出、异常断线和输入法行为仍须验证，依据见当前产品规格。
