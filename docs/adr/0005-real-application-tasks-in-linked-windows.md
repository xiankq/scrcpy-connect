# 独立应用窗口接续被控设备上的真实任务

独立应用窗口呈现被控设备上真实应用的任务和既有登录态。应用只支持单实例时，可以迁移现有任务并说明影响；同一应用多实例按系统和应用实际能力提供，不能以新建虚拟显示等同于克隆应用。

关闭互联窗口默认保留真实任务并交回被控设备，区别于强制停止应用。任务迁回、应用自行退出、异常断线与输入法分别处理；具体行为见[交互规则](../../designs/prod/interaction-rules.md)。

主屏与多个真实窗口并行属于能力目标；大屏侧栏与单一当前内容的布局不构成原生多窗口已实现的证据。实现与验证范围见[应用启动与恢复](../implementation/app-launch-recovery.md)。
