# 主控始终不要求开启调试

主控功能在普通应用身份及用户正常授予的平台权限下运行。主控侧不提供依赖本机无线 ADB 或额外调试授权的增强入口；该限制不等同于禁止普通应用身份下的本机子进程。

Android 普通应用的后台剪贴板读取限制独立存在；前台服务或主控更换实现语言均不补齐该权限。被控设备的 shell 权限也不能转授主控，因此剪贴板同步按实际焦点和权限处理，不能承诺无限制后台读取。

该决定约束主控。被控设备仍通过 USB 或无线调试完成授权并临时运行服务端，遵循[免安装执行模型](0001-apk-free-controlled-device.md)。
