# 测试收敛（2026-10-20）

## 删减规模与复验

删减统计包含测试及专属夹具／驱动，不计文档和产品代码。实际减少约 1.14 万行；不是仅将多个测试改名或合进循环。

| 范围 | 净减少代码行 |
| --- | ---: |
| 应用与设计系统测试／夹具 | 6,918 |
| Bridge、工具与产物测试 | 980 |
| Rust 测试 | 825 |
| 三个设备入口及专属驱动，扣除保留的共享标记读取 | 2,691 |
| XCTest 空模板 | 18 |

应用与设计系统测试／夹具从 25,940 行减少到 19,022 行，减少 26.7%；连同其他范围共净删 11,432 行，移除 27 份旧测试／驱动文件。USB 恢复、Android helper 与仍在使用的场景标记各保留一份精简或迁移后的文件。

Rust 另发现 `remote_helper_android` 把生产源码整份引入集成测试，导致其中 19 项默认单测重复编译和执行。三个独有设备用例迁至 `remote_helper_android_tests.rs`，仅由 `#[cfg(test)]` 加载；生产可见性及原环境、忽略和清理条件不变。新入口是 `cargo test -p interop-core --lib remote_helper::android_tests:: -- --ignored`。其余 `#[path]`／`include!` 未发现同类重复用例。
