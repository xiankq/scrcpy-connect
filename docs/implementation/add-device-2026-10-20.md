# 添加设备统一表单（2026-10-20）

本轮将添加设备从方式选择与独立表单收拢为同一页面。发现设备入口位于方式切换与表单上方，使用标准行高，仍进入独立的发现二级页。下方以连续图文 Tab 切换无线配对码、扫码配对、USB 和 IP 连接；每项图标在上、小文字在下，图标依次使用蓝、绿、橙、珊瑚功能色，以黑白文字和底部短线表示选中，不使用逐项胶囊背景。删除重复的手动无线调试地址入口。

当前产品规则见[设备与连接设计](../../designs/prod/device-connection.md#添加与无线连接)，视觉结构见[视觉规范](../../designs/design.md)，路由兼容与尝试归属见[导航契约](flutter-navigation.md)。本记录仅说明本轮改动与实际验证。

## 源稿与实现

Pencil 使用同页的四种模式代表稿：`W3GRn` 配对码、`G4CpTk` 扫码、`OxUaB` USB、`OpFKk` IP；`yMlVd` 保留发现二级页，`c0wxY` 为连接帮助的局部弹窗。发现入口与表单外壳 `JORmP`、图文 Tab `igSfI`、配对码内容 `XQZRD` 由母组件复用。字段校验、配对后待连接、授权失败和系统授权示意保留局部状态，不新增产品路由。Flutter 使用同一添加页外壳；兼容旧地址时预选对应模式。发现二级页选中结果后回填原表单的地址与已知连接方式。

配对端口与连接端口保持独立。配对成功但未连接时在同页补全连接端口并保留加密方式；已知加密设备不会因编辑地址或切换形式而降级。二维码由主控显示，被控手机扫描；USB 两端授权仍以真实系统结果为准。

## 验证

视觉规范的官方 lint 与 token 漂移检查通过，0 error，保留既有 68 条项目扩展与颜色引用警告，无 token 数值变更。

源稿由 Pencil 对象 API 保存，删除重复手动连接稿 `YvzMk`，帮助内容保留局部状态身份，不建立独立产品路由。静态稿只证明布局与图标状态。

表单精简后，58 项相关回归与最终 384 项全量测试通过（`/tmp/scrcpy-form-polish-all-tests.log`）；分析无问题，路由生成检查通过，`git diff --check` 通过。新增专项覆盖草稿与端口分离、发现二级页返回、USB／QR 取消及迟到结果、配对成功直接切 IP 保留 TLS，以及窄屏大字切换与末项可达。全量检查最初发现三项旧夹具仍依赖已移除的独立入口或空端口默认值，已按当前实际行为同步，保留零请求校验和真实授权结果断言。

最后收整字段标签状态色后，另有 2 项空值校验回归和 1 项实际文字渲染探针通过，确认普通、聚焦、聚焦且错误、失焦且错误四种颜色状态；分析通过。该调整之后未重复全量测试。

四模式在浅色／深色、402 正常文字及 280 双倍字下的 16 张 Widget 截图位于 `/tmp/scrcpy-add-form-polish/`，已目视检查图标功能色、单条 Tab、统一字段字号、发现二级入口及内容可达性。Widget 截图不证明 GPU 材质或两台设备的真实配对互操作。

已发现并连接现有 IDE DTD 实例，最终调用 hot reload 返回 `No active app connection`；当前无运行应用，未完成运行态热重载。没有将该结果登记为设备运行验收。

## 表单文字与字号收整

后续调整移除配对、扫码、USB 和 IP 正文中重复的任务大标题，并移除通用 VPN 提示和 USB 检查免责声明。正文、字段与授权步骤沿用 body，辅助文字与浮动标签沿用 caption，按钮沿用 label；USB 不再重复放大图标。当前方式的完整前提与设置步骤由“连接帮助”承接。Pencil 连接恢复后同步相应母组件与局部状态，源稿与 Flutter 的实际预览分别检查。
