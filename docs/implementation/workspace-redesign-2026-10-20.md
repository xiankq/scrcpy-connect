# 设备工作台重设计验证（2026-10-20）

本记录说明本次实现与证据，不替代[信息架构](../../designs/prod/information-architecture.md)、[设备连接](../../designs/prod/device-connection.md)或[视觉规范](../../designs/design.md)。

## 实现范围

所有状态的设备卡统一进入设备工作台（名称例如“我的手机”），移除“设备当前均不在线”总括提示和独立设备详情页面。旧 details 地址只重定向到同设备工作台。设备信息、本机改名、设备开关、连接偏好、能力、诊断、断开和移除已合并；离线仍可读本机记录与修改偏好。远端内容入口离线禁用。

身份卡保留真实连接状态和屏幕主动作，去掉能力数量与保留会话摘要。“手机应用”宫格读取当前 Android 用户的已启动标准应用任务，按包去重；“全部应用”承接安装列表与搜索。文件、相册、通知、通话使用可换行快捷区。控制窗口只管理互联会话，右上画质作用于后续新建窗口；输入与截图工具只作用于选定会话。

全部应用使用单一滚动视口，避免短横屏嵌套滚动把目标应用定位到标题栏后方。顶部保护渐变的末端收进实际标题栏底部。普通内容首屏仍通过滚动内边距避让标题，滚动视口继续延伸到透明标题背后。

## 数据与兼容边界

`apps.list` 的 `filter: running` 返回真实任务快照，带 deviceId、source、live 与 userId；不以安装列表回填，权限、接口与上限失败保留真实错误。任务元数据验证需要被控 API29+，不影响旧手机整机远控与安装列表。`apps.icon` 从目标手机当前用户的 PackageManager 读取并绘制 PNG；缺包、缺资源或身份不匹配显示中性缺失图形。主控图标查询按设备／包／用户隔离，旧请求不会覆盖新对象。

宫格只在可见且主控前台时定期刷新，前台恢复及应用返回后重新读取；同一读取未结束时不叠加轮询请求。离线清除实时应用呈现，不展示旧任务为在线内容。

## 验证证据

Flutter 应用完整测试 378 项通过，日志 `/tmp/connect-workspace-app-tests-passed.log`；严格静态分析无问题，typed route／provider 生成检查通过。协议生成及打包 manifest 的 5 项工具回归通过。

- 页面回归覆盖全部页面的窄屏／横屏二倍文字、设备卡与安全区、合并后的偏好保存和本机管理、详情旧地址重定向、文件往返、控制窗口、画质及应用打开方式。新增用例验证只接受真实任务响应、图标迟到回执隔离、离线不读取实时任务。
- PageFrame 回归直接检查保护层止于标题栏底部，渐变不延伸到正文；透明栏与滚动视口行为保持可验证。
- 本轮 Flutter 夹具截图：`/tmp/connect-workspace-flutter/`，包含工作台浅深、离线、连接中、需授权及管理末项。已实际查看代表图，素材来自真实设备，但页面数据为夹具，材料为 Widget 测试降级路径，不证明本轮生产 GPU 成像或完整原生动效。
- Pencil 最终导出：`/tmp/connect-workspace-pen-final/`，受影响明暗、后台应用、全部应用、控制窗口及桌面已目视；活动分支布局检查通过。源稿状态数量不等同于运行验收。
- API36／x86_64 AVD 的 Rust 主机到真实目标链路验证：排除桌面；设置未启动时不在列表；启动并 HOME 后仍存在；force-stop 后消失；获取真实 PNG；缺失包明确失败。证据为 `/tmp/connect-target-icons/` 与 `crates/interop_core/tests/apps_android.rs`。这不是 Flutter 到远控会话的完整业务 E2E，也不代表旧 Android 或 OEM 已实测。
- 应用回执在返回前核验设备仍连接、同一 Client、同一 companion 且未取消。确定性回归先复现旧实现接纳迟到成功，再验证 2 个命令在正常、离线、Client 替换／关闭、companion 替换／取消等 12 个组合下的归属；原 companion 生命周期 5 项与应用参数／断连测试通过，Rust 格式与严格 Clippy 通过。
