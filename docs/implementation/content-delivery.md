# 系统保存与外部分享

用户流程见[内容与传输](../../designs/prod/content-and-transfer.md)。`DocumentsCoordinator` 负责选择器、冲突、预算与生命周期，通用 `LocalFiles` 只负责受限路径/FD的复制及发布。

## 完成与未知结果

`DeliveryJournal` 在选择器和写入前保存pending，完整回执落盘后才成功；重启将pending转unknown，不重放，不持久化URI/FD。取回原件、保存到系统提供方、交给接收应用是三个完成点；系统保存不确认云同步，Sharesheet返回不确认接收方读完。

操作固定设备、任务、原件和operationId，冲突决定同时匹配conflictId。离页只取消自己拥有的操作。未知提交保留来源与账本，不再次写入或删除可能已发布的目标。

## 描述符与提供方

- 复制持有原源身份及独占未发布片段，禁止覆盖提交；取消先排空复制，再清理片段与平台描述符。关闭失败沿原scope重试。
- Android提供方只接受rw、空普通文件、可定位及同步的输出；不回退到会截断旧内容的w，不接受管道。
- 成功lease按 `checkError → close → checkError` 核验，失败/取消使用closeWithError。原始PFD保持到原生复制完成或关闭确认。
- Activity分离撤销准入，进程保有资源；新附着先排空同名复制scope，再按当前平台租约关闭旧PFD，随后开放准入。
- Linux/Android私有文件使用 `renameat2(RENAME_NOREPLACE)` 发布；不支持时失败，提交未知时不重试。

## 外部分享接收与传输来源

`ShareCoordinator` 复制系统授权来源，`ShareStore` 独占分享账本，`DocumentSources` 在独立根目录持有文档来源。全部复制、同步与关闭确认后，来源才可用。

发布前持久绑定批次身份和请求指纹，任务日志可靠发布后记录回执。相同请求复用已确认回执，参数不同或提交未知时拒绝重放。消费分享、关闭页面或移除历史不解除传输租约；完整持久引用确认原批次消费者均已结束后才回收来源。

交给外部应用的私有原件持久保留，因为没有可靠读取结束回执。启动先排空旧复制与平台资源，再归还旧页面持有权；不按目录年龄或大小删除未知来源。
