# 被控 Android 条件

以下是被控功能门槛。主控安装下限由各runner及Flutter依赖决定。

| 功能 | 条件 |
| --- | --- |
| 基础画面、触控、图片缩略图 | Android 5 / API21起；实际捕获、编码器与输入权限由启动确认 |
| 独立应用窗口、后台真实应用任务 | API29起；任务不可读时显示受限，不用安装列表代替 |
| 设备输出声音 | API30起；Android 11另有启动时锁屏限制 |
| 视频缩略图 | 当前实现要求API27；更旧版本可取原件，不下载整段视频冒充缩略图 |
| 文本剪贴板 | API21起，取决于实际Binder/AppOps权限 |
| 通知与通话观察 | 分别检查接口与权限；AOSP API21 shell受限 |
| 文件浏览、搜索与传输 | 使用授权身份，无权、截断、未知与空目录分别返回 |
| 无线配对 | 被控提供现代配对协议；传统TCP使用明确IP/端口 |

扩展功能受限不关闭其他能力。API门槛不是全机型验收结论。

## 旧协议与文件服务

ADB 1.0.0保留校验和、OPEN尾零及协商分片；AUTH在总期限内响应重复TOKEN。经典shell无可靠退出码，文件变更另取执行回执；回执丢失保留未知，不重放。

缺少stat_v2/ls_v2时使用[原生文件助手](../../servers/helpers/README.md)，保留64位大小、原始名称及errno，不依赖设备自带stat/find/toybox。子项不跟随符号链接，明确共享存储根别名允许解析。

助手部署到独占目录，回读字节匹配后才授权执行已打开的同一inode。主控EOF触发租约清理。scrcpy与companion由监督器等待自己子进程退出后删除部署文件；删除JAR不作为退出证明。

固定scrcpy与脱糖来源见[vendor](../../servers/vendor/README.md)。服务端、协同JAR及文件助手保持API21构建；设备结果按当次主控、被控SDK、ABI及连接方式报告。
