# 代码、发布和调试重构验收

2026-10-25 从 `fa9b8c3` 及已有两处未提交 ADB 身份修改开始；原身份修改保持原样。此前验收记录是历史证据，不作为本轮架构正确性的前提。现行规则见[架构](architecture.md)、[工具链](repository-tooling.md)及[打包](android-packaging.md)。

## 已确认的问题及实现

- `ApplicationSession` 通过媒体和分派器回调自身执行业务；改为单向组合、枚举执行和直接捕获操作，分派器不再创建或关闭媒体缓存资源。
- 文件、偏好及分享分支绕过统一命令校验；统一在准备、取消和执行副作用前校验。业务 Map 载荷仍保留，没有声称已完成全域 DTO 化。
- release 重复携带独立 ADB 和 scrcpy 同库 ADB；宿主明确注入 bindings，独立 ADB 在链接时按实际初始化可达性裁剪。交付核验拒绝重复库，补齐媒体 ELF 核验。
- 默认发布三个单 ABI APK，通用包改为显式选择；ZIP 回执输出各 ABI 的压缩与展开载荷以及归档开销。
- 纯宿主测试混入 Flutter 原生构建；迁至独立 `tool/host/` Dart 环境。删除仅检查生成源码外形的重复断言，保留协议、恢复、背压和资源释放断言。
- FRB 每轮随机复制大输入并重新建缓存；改为受锁保护的最小私有镜像和稳定 Cargo cache，仍重新生成并逐字节检查。
- 调试 Rust incremental 长期膨胀、Android 调试默认构建三个 ABI；关闭 incremental、保留行号信息，调试仅构建指定单 ABI。
- 驱动子进程输出无界、部分夹具未等待 finally；增加输出预算和退出确认，驱动等待本次夹具收尾，文档夹具精确回收自有目录。
- 7 个驱动的恢复流程会在首个异常后短路，部分无界 VM RPC 阻塞恢复或与恢复竞争；逐项尝试并汇总收尾失败，保留主错误及堆栈，巡检 RPC 限时 5 秒、停止后排空再恢复设备。SDK 正常退出前也在回调中执行必要恢复。
- `servers` 的空壳 shell 入口、Java/DEX 编译和仓库定位存在重复；删除无引用入口、共享编译实现，生产 manifest 排除独立 API 21 探针。companion 日常 `--check` 改为离线输入和产物摘要检查，真实编译归显式 `--rebuild`。
- ADB build hook 交给 link hook 的文件没有进入 Flutter 的直接打包输出依赖；显式登记链接文件，缺失时使构建回执失效。
- Android 私有目录的祖先只允许搜索，原文件域用只读目录句柄遍历，触发 `Permission denied (os error 13)`；Linux/Android 祖先改用 `O_PATH`，授权根仍核验目录并保留实际读写权限检查。非 root 的 0711 祖先回归先红后绿，实际 Android release 冷启动已恢复。
- 已打包的四 ABI 文件助手没有注入实际 ADB 文件能力；初始化先核验资源并完成助手注册，再交付捕获能力。原宿主顺序回归先红后绿，实际 Android 连接后可列出目标 `/sdcard`。
- 实际编码器枚举结果缺少质量页要求的逐格式状态及编码器列表，导致所有格式不可选并误显能力未知；公开质量命令统一给出状态与按格式筛选的编码器，查询失败仍沿原错误路径，不虚构支持。真实命令回归先红后绿。
- 远控消费者将会话解码首帧误当成截图证明，实际恢复及质量重建的 `media_codec.decodedFrame` 被拒绝；统一核对真实首帧及其精确证据，截图证明、保留旧纹理和未知证据仍拒绝。通过真实视频输出协调器的恢复和两种质量事件时序回归，避免手写夹具掩盖两端契约差异。
- 本机文件执行域缺少全局并发限制；增加 scope、在途打开、复制和活动预算，失败及交接沿原资源释放许可，不能用重复打开绕过上限。
- 目录传输先展开后限额、来源核对受无关历史量影响；改为入队前预算和仅对固定托管来源覆盖集合核对完整批次，失败与未知消费者继续保护原件。
- 系统文档导入缺少跨操作持久来源所有权；复用来源账本，页面归还与传输发布分别确认，所有文档共用 8 GiB 上限，旧无账本内容保留并计费。异步来源查询也登记为准备责任，取消必须排空，避免停止后迟到发布。
- Android 将同一私有缓存暴露为 `/data/user/0` 和 `/data/data`，文档来源账本与文件授权根使用不同路径导致实际导入、导出失败；初始化时固定实际根，保留原恢复标识，操作只映射原授权目录下的路径，仍拒绝内部符号链接和越界路径。真实系统选择器已验证文件及目录双向内容、空目录和来源释放。
- 文档页面在等待归还旧来源期间退出，仍可能随后打开选择器；在等待后核验当前操作与页面，迟到归还失败保留精确来源身份。四个实际时序回归先红后绿。
- 同一托管来源第二次传输时，旧完成历史可能按同路径误认新发布并提前删除来源；在准备前持久绑定实际批次身份，规划与发布沿用该身份，未知旧租约保守保留，取消证明只查本次批次。两次消费和冷恢复回归先红后绿。
- 媒体控制器等待暂停订阅的关闭 Future 会无限挂起；实际资源释放后结束流关闭请求，暂停订阅回归先红后绿。
- FFmpeg 工作目录和锁使用不同身份，成功后仍留下编译中间物；改为同一 prefix 摘要隔离，成功及缓存命中回收自身中间物，失败保留排错输入，清理受限不误报编译失败。
- 删除已无生产者的性能测量链与重复脚本外形测试；保留实际像素、设备行为、协议和退出证明。应用的 npm 清单、锁文件及约 992 MB 的 `app/node_modules` 已移除；设计 token 工具仍使用的独立依赖保留。

## 测量与验证

基线通用 release APK 为 **62,011,213 字节**。压缩 ZIP 载荷中，三 ABI 原生库约 55 MiB、assets 约 3.3 MiB；重复 ADB 桥约 8.6 MiB。旧产物由新的交付检查准确拒绝，错误为重复 ADB runtime。

调试存储基线：根 Rust target 约 35 GiB，其中 incremental 约 23 GiB；Native Assets shared 约 12 GiB；应用 build 约 5.4 GiB。它们是基线存储占用，不代表本轮每次调试都会新增同等体积。

FRB 新镜像约 3.6 MiB，专用 cache 约 203 MiB；连续第二次检查 6.08 秒通过，cache 没有增长，不产生新的随机临时源码树。纯宿主测试独立缓存约 57 MiB，不触发根 Flutter workspace hooks。

实际单 ABI arm64 debug APK 为 86,675,096 字节（旧三 ABI debug 为 170,383,108 字节），通过清单、签名、共享资源与原生库检查。相同输入第二次构建 Gradle 耗时 11.9 秒；两次之间 Native Assets cache 配置目录数保持 28，已删除的旧应用 hook 与根 incremental 均未重建。该结果验证同配置复用，不能解释为所有未来源码、SDK 或目标平台变化都不增加缓存。

最终打包及设备验收结束后，按当前 main/debug/release 构建身份和进程文件引用核对，删除 16 个过期 Flutter 编译输出及三份重复或测试 APK，另回收 2,107,014,057 字节；保留四份最终 release、当前构建身份及可复用原生缓存。本轮远端样本、端口转发和外部分享夹具已回收，两个自行启动的模拟器已停止，未清空 AVD 或删除原有设备文件。

## 验证边界

本轮保留现有产品功能和视觉设计。Android 运行证据来自上述 API 36 x86_64 模拟器，包含实际系统界面、ADB 与解码路径；arm/arm64 发布构建检查不能替代对应实体设备运行。物理 USB、OEM 后台行为、其他 Android 版本及其他主控平台尚未完成本轮设备验收。部分业务所有者仍使用 Map 和命令适配，不能把本轮聚合层重构解释为所有模块已重写。
