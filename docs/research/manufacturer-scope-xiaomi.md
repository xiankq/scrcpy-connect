# 小米与华为互联：页面、通知与手机应用的边界

核实日期：2026-10-16。依据 7 个官方来源；未安装或实操厂商产品。本报告区分官网证据与本项目取舍，不以厂商的系统集成能力证明免 APK、ADB 临时服务端的实现可行性。

## 本轮范围依据

用户最新明确：不要录屏，不要文件或相册自动备份；短信只同步通知，打开被控手机屏幕查看。允许通话、相册预览、文件管理拥有专门页面；其余常规体验由代理参考成熟产品取舍。

因此，[此前研究](manufacturer-workflows.md)中代理选择的“主动开启的本地备份”已不适用。本轮也不把“编辑后自动写回”视为用户逐项确认的需求。专门页面是一项产品选择，不代表小米和华为所有平台都有对应的原生数据页。

## 官方资料能确认的路由

| 平台与入口 | 官方行为 | 应如何理解 |
| --- | --- | --- |
| 小米 Windows | 互联应用中选择文件发送；启动妙享桌面操作手机；可从其应用入口打开最近手机应用窗口。官网列出最多两个应用窗口和版本条件。 | 文件传输入口与手机窗口并存。这里的“应用窗口”承载手机应用，官网没有据此证明 Windows 另有原生短信、完整相册或通话资料页。[小米 Windows 互联](https://os.mi.com/continuity/abilities/ab0019) |
| 小米 iPhone | 通知可包含电话、短信和应用消息；同网络时，点击通知打开小米手机应用处理。App Store 2.5.0 增加 iPhone 操作妙享桌面，2.9.0 明确增加通过镜像打开小米手机短信应用回复。 | 短信回复发生在被控手机原应用中，不能写成主控原生短信收件箱。只读旧官网简介会漏掉后续镜像能力。[小米苹果互联](https://os.mi.com/continuity/abilities/ab0016)、[小米互联服务发布记录](https://apps.apple.com/cn/app/%E5%B0%8F%E7%B1%B3%E4%BA%92%E8%81%94%E6%9C%8D%E5%8A%A1/id6673908449) |
| 小米 iPad／Mac | 妙享桌面用于操作小米手机；Mac 支持独立打开最近手机应用；文件可与手机窗口内相册、文件管理拖拽互传。iPad 的拖拽增强也见 2.3.0 发布记录。 | “在窗口内打开相册／文件管理”仍是手机应用路由，不等于主控独立实现相册／文件管理。Mac 的独立应用窗口说明不能无条件套用 iPad。[小米苹果互联](https://os.mi.com/continuity/abilities/ab0016)、[发布记录](https://apps.apple.com/cn/app/%E5%B0%8F%E7%B1%B3%E4%BA%92%E8%81%94%E6%9C%8D%E5%8A%A1/id6673908449) |
| 小米云相册 | iPhone／iPad 可上传照片视频到小米云相册，并查看、下载小米设备的照片；需要账号等条件。 | 这是云相册内容入口。不能拿它证明“实时浏览被控设备本地相册”或“本地自动备份”已经成立。[小米苹果互联](https://os.mi.com/continuity/abilities/ab0016) |
| 华为笔记本多屏协同 | 可在手机窗口输入、发送消息，也可从手机镜像另开手机应用窗口；电脑管家“我的设备 > 我的手机”另有手机文件入口，可交给电脑软件查看或编辑；微信文件的一条明确路径仍经过镜像中的手机文件管理。 | 镜像操作、独立手机应用窗口、电脑端文件入口是三条不同路由，不能统一称为“投屏”，也不能把手机文件管理画面算作主控文件页。[在笔记本上操作手机应用和文件](https://consumer.huawei.com/cn/support/content/zh-cn15943935/) |
| 华为通话与通知 | 上述笔记本帮助确认接听微信、畅连等手机音视频来电并使用笔记本硬件；另一份帮助限定平板消息中心只同步短信、微信、QQ、Welink、钉钉、未接来电，其他通知建议在协同手机的消息中心查看。 | 通话有独立音视频协同能力，不能从中推导所有 SIM 通话均可用；通知同步范围也受具体产品限制。此次资料没有确证华为所有通知点击都走同一路径，更没有证明独立短信数据页。[笔记本操作帮助](https://consumer.huawei.com/cn/support/content/zh-cn15943935/)、[平板消息中心限制](https://consumer.huawei.com/cn/support/content/zh-cn00772958/) |

小米官网同时出现常规版、内测版及 AI 能力的不同版本条件；本次中国区 App Store 页面显示 3.0.0，官网另提部分平台 4.0.x 条件。应分别记录，不能拼接成已全面交付的单一版本承诺。华为笔记本操作帮助明确适用于 Mate X3／HarmonyOS 3.1；平板通知帮助未限定系统版本。这些页面证明所述路径存在，不构成所有当前华为设备的统一功能表。

## 本项目取舍：保留高频任务，限制功能扩张

以下是结合用户范围作出的产品建议，均不是对厂商产品结构的复刻要求。

| 功能 | 建议路由与范围 | 依据及边界 |
| --- | --- | --- |
| 短信 | 进入实时通知列表；点击后进入对应被控设备的屏幕。能定位原通知／应用时提供该动作，不能定位时打开手机屏幕由用户继续操作。 | 不设短信会话页、短信数据库、短信写作器或短信备份。小米“通知 → 手机应用／短信镜像”的证据支持这条轻量路线；本项目按用户要求保留在手机屏幕查看的体验。 |
| 其他应用通知 | 默认点击接续被控手机原应用或屏幕；仅在实际支持时提供应用窗口快捷动作。 | 不为每类通知再造主控业务页。通知失效、手机锁屏、无法定位时应如实显示可用动作，不能承诺必达对应会话。 |
| 通话 | 保留专门的通话页面／来电界面，呈现当前通话与设备、可用操作和音频去向；能力按设备核实。 | 用户允许专门页面。厂商音视频通话证明这种独立协同任务有价值，但不能证明通话控制、SIM 链路或双向音频在本方案中已实现。通讯录与完整通话记录不因一个通话页自动进入范围。 |
| 相册预览 | 提供被控设备当前媒体的预览、选择、手动取用／分享入口，标明来源设备。 | 用户允许专门页面。将实时预览与已手动保存的本地副本区分；不引入云相册、自动下载或自动备份。 |
| 文件管理 | 提供专门页面，浏览实际可访问的被控文件、预览、选择及手动双向传输，衔接传输任务。 | 用户允许专门页面；华为文件入口说明这类高频内容任务可独立于镜像。可访问目录、格式和第三方应用私有数据仍需实际验证。 |
| 本机编辑 | 保留“取到主控设备后用本机应用打开／编辑”和“由用户明确传回”的闭环。暂不把任意编辑器的自动写回作为基础承诺。 | 华为展示远端保存，但另有帮助说明鸿蒙电脑上部分跨设备文件是远程访问，断开后 WPS、剪映等会失去文件；需要离线继续编辑应先保存本地副本。自动写回会新增修改检测、连接中断、覆盖和冲突语义，不能只增加一个编辑按钮。[跨设备编辑断连限制](https://consumer.huawei.com/cn/support/content/zh-cn16063543/) |
| 录屏、文件／相册自动备份 | 从本轮产品范围移除，不设置入口、后台任务或引导。 | 用户已明确排除；是否有厂商提供不影响此决定。手动保存单个文件／照片不是自动备份。 |

## 不能从产品资料直接推出的实现保证

- 小米通知可打开手机应用，不证明 ADB 临时服务端可以在所有厂商上读取完整通知、获得原通知操作、定位短信会话或穿过锁屏。
- 手机镜像、真实手机应用的独立窗口、主控的文件／相册数据页分别需要不同的能力；有前一种能力不能自动验收后一种能力。独立应用窗口继续遵循 [ADR 0005](../adr/0005-real-application-tasks-in-linked-windows.md)。
- 厂商云相册、系统文件挂载、硬件共享及通话链路可能依赖配套服务、账号与系统权限。它们不允许绕过本项目的 [被控设备免 APK](../adr/0001-apk-free-controlled-device.md)和[主控不要求调试](../adr/0006-controller-without-debugging.md)约束。
- 编辑后直接保存在远端、连接期间远程访问、本地下载后编辑再传回，是三种不同的数据语义；本项目没有完成验证前不能把它们统称为“自动回写”。
