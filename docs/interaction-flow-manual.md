# 邻接操作链路手册

## 找到并连接一台手机

打开「设备」后，已保存的手机会出现在列表里。在线手机可以直接进工作台。离线时点「连接」，按提示核对手机上的 USB 或无线调试授权。

第一次使用时点「添加设备」。可以先看「附近设备」，也可以选下面一种方式。

- **配对码** 在手机的无线调试里打开配对码窗口，填入这个窗口显示的地址、配对端口和六位码。配对成功后，邻接会尝试找到连接地址。配对端口与连接端口可能不同。
- **扫码** 按页面指引在手机的无线调试里扫码。配对完成后，看工作台是否出现「已连接」。
- **USB** 插上能传数据的线，再点「检查连接」。手机或主控弹出授权请求时，核对对象后再选择允许。部分主控平台需要使用无线方式。
- **IP 连接** 输入已授权手机的地址和连接端口。等待工作台显示「已连接」，再继续文件或远控操作。

提交时如果漏填地址、端口有误或配对码位数不对，页面会在对应字段下给出原因，并把输入焦点移到第一个需要修改的字段。如果进入连接失败页，按实际原因选择「返回修改」或「重试连接」。核对目标身份失败时先检查是不是选错手机。修改已有设备的连接配置前，页面会提示可能中断的活动。

## 看设备状态和常用应用

在设备工作台确认手机名称、连接方式、电量和充电状态。想核对系统版本、硬件或电源详情时进入「设备详情」，可在该页刷新。读取中的占位会在结果返回后换成实际数据。

「常用应用」可以添加和排序。需要打开其他应用时进「全部应用」。点「正在运行」中的应用时，按页面可用方式选「在手机中打开」或「独立窗口打开」。打开失败时先核对手机是否已打开该应用，再决定是否重新提交。

## 打开手机屏幕和切换窗口

在工作台点「打开手机屏幕」，等画面实际出来后再操作。手机熄屏时可以尝试点亮，锁屏需要按手机正常方式解锁。

从画面边缘展开工具，可以开关设备声音、截图、呼出键盘、旋转、切换窗口或关闭画面。桌面按 Escape 将返回操作发给手机。悬浮工具的「关闭画面」结束这路控制，回到工作台。

同一设备的整机和独立应用分别出现在「切换窗口」中。点「返回工作台」可回到画面所属的设备，已开的会话会保留。支持原生窗口的桌面可以把两路放在不同窗口。宽屏应用内可以在另一行点「与当前画面并排」。先点选要操作的一侧，再输入。只关其中一扇时，另一扇仍可使用。macOS 开启读屏时，远控会回到应用内。

调整清晰度、帧率和画面比例时，进入这台设备的「画面与控制」。弹层会标明这台手机当前保存的档位。连接性能和手机能力会影响实际画质与帧率。

## 浏览文件和相册

从工作台进入「文件」后，可以逐级打开目录，也可以按名称搜索。回上一级时可继续看原目录内容。等待刷新期间，页面会标明当前是否正在读取。看到读取失败时，可以在原位置重试。

进入「相册」后按日期找图片和视频。重新打开时可以接着浏览上次的结果。点「刷新」会检查手机里的相机和图片目录，再查其余共享目录，旧照片可以继续浏览。检查结束后点「更新照片」采用新结果。如果只检查了部分文件夹，未检查的目录仍可能有照片。打开图片可以切换原尺寸，视频按主控可用的方式打开。

## 发送、取回和分享原件

选好文件和目标目录后再发送。遇到同名文件时先读清页面提供的处理方式。发错目录或需要停止时，到「传输」找到这次任务。离开页面后，也能在传输列表继续查看进度或失败原因。

从手机取回文件后，等页面确认原件已进入本机暂存。从文件详情或传输详情继续打开、保存到系统位置，或交给系统分享，入口取决于主控支持的方式。关掉系统分享面板后，可以用暂存原件直接重开。选了接收应用或结果待确认时，先到接收应用核对，再决定是否重试。清空传输历史与清理本机暂存是两个入口。

## 看通知和接续电话

从设备工作台进「通知」。点仍可接续的通知可以尝试在手机应用里继续。过期提示出现时，从手机应用查看当前内容。清除通知前核对操作作用于哪台手机。

电话入口可打开手机电话界面。独立接听和双向音频是否可用，以页面实际提供的操作为准。回到手机继续通话时，通话状态以手机为准。

## 调整设置与处理更新

在「设置」调整外观、后台保持、暂存、设备记录和授权密钥。后台保持取决于系统权限。查看「当前活动」可以确认正在使用的连接、画面及传输。设备记录导入后仍要重新核对手机授权，切换密钥前先看影响说明。

在「关于与更新」核对版本及构建号。带有更新渠道的安装包可以检查更新，并从版本页打开下载。没有配置渠道的开发包会说明原因。查看运行日志或提交问题时，请遮住地址、序列号、通知、文件名和密钥。
