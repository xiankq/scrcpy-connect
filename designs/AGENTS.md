# 产品与视觉设计

产品行为见 [prod/README.md](prod/README.md)；视觉数值与材料用途见 [design.md](design.md)。Flutter token 由[生成工具](../scripts/design_tokens/README.md)生成，Ardot 变量沿用同一数值。

当前工作稿为 Ardot《邻接 Interconnect》（文件 ID `740857962254340`），使用 Ardot 工具编辑。`mobile.pen` 冻结为只读对照，可直接解析源文件核对节点。共享组件改母组件，页面实例只覆盖业务内容和明确变体；同步核对受影响实例。内部增删图层或改变子层几何的状态保留独立结构；有稳定复用需求时再建变体，不强行连接到结构不符的母组件。

字号与输入框高度等独立母组件变体集中在“规范 / 00 迁移变体组件”。文本使用 MiSans，字体来源与本机安装要求见 [MiSans 说明](assets/fonts/misans/README.md)。

远控三键栏在 Ardot 用左右各 67.5 点内边距与 `SPACE_BETWEEN` 排列 44 点命中区；当前 `SPACE_EVENLY` 会把两侧按钮贴到边缘。修改后检查母组件及整机、独立应用、熄屏状态的三个键位。

完整页面、规范板与局部状态各用独立顶层画板。局部错误、菜单和进度只画变化部分；画板不等于路由。远端画面保持原应用外观。

普通内容使用流式布局，远控、遮罩与浮动操作可叠加。`scroll-viewport` 可裁剪完整滚动内容，末项须可达。核对明暗、辅助偏好、窄屏及长文字；静态稿只能验证布局与材料目标，运行效果需实际截图和交互验证。

修改 `design.md` 后运行 token 生成检查。预览放系统临时目录；仓库仅保留源稿、实际引用素材及[来源许可](assets/README.md)。
