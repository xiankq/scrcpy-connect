# 视觉设计

产品行为以 [prod/README.md](prod/README.md) 为准，视觉数值及材料用途唯一维护于 [design.md](design.md)。修改数值后运行 [token 生成检查](../scripts/design_tokens/README.md)，Flutter token 与 Ardot 变量保持一致。

## 工作稿与组件

- 当前工作稿为 Ardot《邻接 Interconnect》，文件 ID `740857962254340`，使用 Ardot 工具编辑；`mobile.pen` 保留为只读迁移对照。
- 共享改动更新母组件并核对实例；实例覆盖业务内容和明确变体。子层结构或几何不同的状态保留独立结构，有稳定复用需求再建立变体。字号与输入框高度的独立变体在“规范 / 00 迁移变体组件”。
- 文本使用 MiSans，来源与本机安装见[字体说明](assets/fonts/misans/README.md)。
- Ardot 的远控三键栏使用左右各 67.5 点内边距、`SPACE_BETWEEN` 与 44 点命中区；当前 `SPACE_EVENLY` 会将两侧按钮贴边。修改后核对整机、独立应用与熄屏状态三个键位。

## 布局与验证

- 完整页面、规范板和局部状态各用独立顶层画板；局部状态只表达变化部分。画板与应用路由分别维护，远端画面保留原应用外观。
- 普通内容采用流式布局；远控、遮罩和浮动操作可叠加。`scroll-viewport` 裁剪完整滚动内容，末项保持可达。
- 核对明暗主题、辅助偏好、窄屏与长文字；静态稿验证布局和材料目标，实际截图与交互验证运行效果。
- 预览放系统临时目录；仓库保留源稿、实际引用素材及其[来源许可](assets/README.md)。
