# 视觉设计

产品行为以 [prod/README.md](prod/README.md) 为准，视觉数值及材料用途唯一维护于 [design.md](design.md)。修改数值后运行 [token 生成检查](../scripts/design_tokens/README.md)，Flutter token 与 Ardot 变量保持一致；Ardot 的 opacity 变量使用百分比值（32 对应 Flutter 的 0.32）。

## 工作稿与组件

- 当前视觉工作稿为 [Ardot《邻接 · 近场工作台》](https://ardot.tencent.com/file/749360133997361?node_id=2%3A14)，使用 Ardot 工具编辑。G 区对照共享组件与状态，G7 对照添加设备，G8 对照通知与电话，G9 对照文件与相册的底部操作。
- 整理画板按[画布布局](design.md#flexible-布局)同步画布与图层树。折叠、平板、桌面、鸿蒙和多窗口按[适配规范](design.md#adaptive-windows--form-factors)核对窗口姿态、保留区、窗口身份和材质边界。
- 共享改动更新母组件并核对实例；实例覆盖业务内容和明确变体。子层结构或几何不同的状态保留独立结构，有稳定复用需求再建立变体。字号、字段高度与辅助偏好变体归入对应组件规范；200% 大字示例同时放大字号与行高。
- 文本使用 MiSans，来源与本机安装见[字体说明](assets/fonts/misans/README.md)。
- Ardot 的远控三键栏使用左右各 67.5 点内边距、`SPACE_BETWEEN` 与 44 点命中区；实现与稿件保持一致，修改后核对整机、独立应用与熄屏状态三个键位。

## 布局与验证

- 逐页审查每个文字层。屏内保留识别对象、完成操作、理解状态所需的文字。标题已经说明用途时从正文直接开始。额外提示放在触发点、失败位置或帮助页。评审稿中的同一规则在一处维护，画面能说明变化时用对应状态示例。

- 完整页面、规范板和局部状态各用独立顶层画板。已有任务的状态优先更新现有画板，局部状态只表达变化部分；画板与应用路由分别维护，远端画面保留原应用外观。
- 普通内容采用流式布局；远控、遮罩和浮动操作可叠加。`scroll-viewport` 裁剪完整滚动内容，末项保持可达。
- 核对明暗主题、辅助偏好、窄屏与长文字；静态稿验证布局和材料目标，实际截图与交互验证运行效果。
- 预览放系统临时目录；仓库保留设计规范、实际引用素材及其[来源许可](assets/README.md)。
