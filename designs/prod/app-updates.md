# 应用版本与更新

设置中的「关于与更新」显示实际安装包的版本号和构建号，提供「检查更新」「更新记录」并保留关于及开源许可。版本信息读取失败时说明原因。更新记录按发布日期倒序，标明已安装版本，展示各版本的发布说明。弹窗展示当前目标版本的摘要，并可进入更新记录查看完整说明。

## 检测与提醒

手动检查在原行显示正在检查、已是最新版本或者失败与重试。应用进入前台后可从当前安装渠道检查与主控设备兼容的版本。同一目标版本首次确认可用时显示「发现新版本」弹窗。近期正在操作远控或通话、提交表单或处理其他弹窗时，先在设置保留更新入口，待合适时机再提示。选「稍后」后仍可在设置手动打开，本次前台会话内收起重复的自动提示。检查失败保留上次确认的信息并注明时效。

更新提示显示当前和目标版本、已知的安装包大小和本次更新内容。仅对当前安装渠道及设备已确认可用的版本提示更新。更新来源、包兼容性和完整性须由对应渠道验证。项目的发布渠道与自动检查频率由实际发布方式确定。

## 下载、校验与系统安装

| 状态 | 页面呈现与动作 |
| --- | --- |
| 发现新版本 | 显示版本和更新摘要。支持应用内下载时提供「下载更新」和「稍后」。 |
| 准备下载 | 显示真实的连接或等待确认状态，用线弧表示未知进度。 |
| 正在下载 | 依据实际收到的字节显示进度。总量已知时显示百分比和大小，总量未知时显示已下载量与等待标记。 |
| 正在校验 | 收到完整更新包后，按渠道核验完整性与可安装性。可收起弹窗，设置保留本次更新入口。 |
| 已下载 | 渠道确认可安装后显示「安装更新」和「稍后安装」。选择安装时说明需要退出或重启应用的影响。存在正在使用的画面、通话或传输时，先说明会受影响的任务。 |
| 正在打开安装程序 | 用户确认后交给系统安装界面。回到应用核对实际安装版本，再更新「当前版本」与安装标记。 |
| 下载、校验或交付失败 | 保留目标版本和更新说明，显示实际原因及当前可用的重试动作。 |

收起弹窗时，下载按渠道能力继续，设置显示可继续查看的更新状态。允许取消的下载在弹窗内提供「取消下载」。回前台或重新进入更新页，先恢复渠道报告的当前状态，再开放相应动作。同一目标版本复用同一下载，安装界面取消后按渠道核验，仍可安装时保留「安装更新」。

## 渠道交付

商店或系统接管更新时，弹窗提供「前往商店」或对应渠道入口，下载和安装进度由渠道显示。Google Play 的弹性更新可在取得进度回执时显示应用内下载状态，下载完成由用户确认安装或重启。App Store 分发遵循商店更新，桌面应用依实际安装渠道进入系统更新或受信任的安装程序。各渠道独立验证后才显示其支持的操作。[Google Play 弹性更新](https://developer.android.com/guide/playcore/in-app-updates/kotlin-java#flexible) · [Apple App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/) · [Windows App Installer 更新设置](https://learn.microsoft.com/en-us/windows/msix/app-installer/update-settings)

设计稿中的 0.2.0、安装包大小和下载量用于示范状态。正式内容来自实际发布记录和下载回执。

## 构建渠道配置

当前外部交付模式通过 `--dart-define=APP_UPDATE_FEED=<HTTPS 地址>` 配置。构建流水线为每个安装渠道和平台提供对应的发布清单。清单为 JSON 数组，每条提供稳定版 `version`、整数 `build`、ISO 8601 格式的 `publishedAt`、字符串数组 `notes`、HTTPS 渠道入口 `url`，可选提供安装包 `bytes`。发布渠道负责兼容性筛选与安装。未提供地址的构建显示实际安装版本和开源许可，检查更新时说明渠道尚未配置。
