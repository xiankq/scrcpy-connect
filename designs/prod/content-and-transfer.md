# 内容与传输

通用设备归属和提交保护见[交互规则](interaction-rules.md#内容保护与提交反馈)。

## 文件与目录边界

文件页支持目录／分类、新建文件夹、重命名、删除及手动取用。操作显示真实来源、目标和路径，删除／替换说明影响；提交后切页或换设备不改对象。不可读、未知与空目录分开；到达上限显示实际范围。遍历不跟随子符号链接，主共享存储根别名单独识别，不把无法表示的名称改成另一可操作名称。

打开、修改或取回前重验身份、类型和可访问性；源变化不拼接成完整原件，目录批次按项反馈。

普通点按图片从文件列表、宫格、搜索结果或相册直接进入共用图片预览，返回保留来源目录或相册位置。其他文件进入按格式呈现的详情页，显示文件标识与真实属性。文件夹继续进入所属目录。

- 文件夹优先、连续排列，无组标题与计数；默认四列自适应网格，可切列表且保留选择。
- 当前目录一次读取全部可访问条目，列表和宫格按可见区域构建。
- 打开尚未读取的目录时先呈现路径，内容沿用当前视图的占位。浏览子目录时在本次浏览页内保留已读的上级目录。返回时直接恢复列表和滚动位置，回到共享存储首页时恢复原筛选。收到目录变更、连接变化或用户主动刷新时重新核验，期间继续显示上次确认的条目，结果到达后原位更新。明确整次读取成功且没有条目后才显示空目录，失败时就地给出可用动作。
- 页头或目录内保留搜索。浏览态底部液态玻璃栏提供“发送”“视图与排序”“更多”。“发送”打开来源选择页，列出当前平台可用的文件／文件夹入口。选定来源后，核对文件、设备和目标目录，可浏览并更换目标目录，确认后才提交。“更多”从对应动作向上展开，包含新建文件夹、选择和刷新。类型入口仅在共享存储首页。
- 排序支持名称、大小、修改时间、类型及方向，两类分别排序，未知值稳定回退；视图与排序本机持久化。
- 文件夹显示完整日期，文件月／日，大小最多两位小数。浏览态从目录搜索旁的路径入口跳上级，返回先回父目录，到根退出。选择态先按下述规则退出选择。

### 文件选择与批量操作

文件列表与宫格共用选择规则。浏览态更多菜单的“选择”进入零项选择，键盘与读屏可使用同一入口；条目额外提供“选择此项”辅助操作。触摸长按、鼠标右键或主键长按可操作条目，直接进入选择态并选中该项；已有选择保留，长按／右键已选项不反选，也不先弹上下文菜单。选择态点击条目任意位置切换勾选，文件夹也只切换选择；不可操作条目不参与选择并保留原因。普通点击的打开行为仅在浏览态生效。

- 页头沿用浏览态高度，大字时随内容增高：左侧返回换为关闭选择（×），中间显示“已选择 N 项”，右侧仅使用全选图标按钮。未全选时执行全选，全部选中后切换为取消全选图标；不显示文字标签，悬停提示与读屏名称分别为“全选／取消全选”。清空勾选后仍留在选择态，显示“已选择 0 项”，由关闭或返回明确退出。
- 全选覆盖当前目录、当前筛选下所有已核验可操作条目，包含滚出视口的条目。子目录内容与筛选外条目另有各自范围。读取受限时保留范围提示，全选只处理本次确认的集合。
- 列表选择框原位替换右侧箭头，两态共用固定尾槽；保留左侧图形、名称、元数据、行高和间距，以及文字的可用宽度、换行和截断方式，不因选择态出现额外挤压、增高或缩放。宫格选择框叠放在缩略图区域的水平及垂直正中，名称、元数据、缩略图与格子尺寸不移动；勾选不得仅靠颜色区分。标记视觉尺寸和命中区域分开，按[视觉规范](../design.md)执行；增加命中范围不参与条目排版。
- 批量操作使用底部悬浮液态玻璃栏：“取回原文件”“删除”“更多”。三项图标与标签均使用标准文字色；删除在提交前确认来源设备、项数和影响。取回、删除在零项或不满足能力条件时禁用并提供原因。更多从底部触发点向上展开，含“重命名”（仅单项可用）及“切换为列表／宫格”；视图切换保留选择、筛选和目录，不改变操作对象。
- 点“删除”在当前页面打开确认弹窗。弹窗显示项数与实际来源，提供“取消”和“同意”。取消关闭弹窗并保留勾选，同意提交同一批次的删除。
- 删除提交后保留待确认条目。确认成功才移除对应项，失败项继续可见，并提供逐项结果和原地恢复入口。
- 选择期间固定设备、路径和筛选范围，在批量栏上方显示当前目录。结束选择后可切目录、筛选、搜索、新建、发送和刷新。源目录变化时移除已失效的选择。断线保留可见选择，重连后核验并恢复提交。
- 系统返回、Escape 与页内关闭语义一致：有菜单或确认层时先关闭该层；否则只退出选择态、清空勾选并恢复浏览底栏，保留当前目录和滚动位置。下一次返回恢复浏览态规则。退出保留筛选和视图；已提交的传输或文件操作不因退出选择而撤销。

选择状态仅属于当前文件页和来源设备，不跨设备或进程恢复。底栏与展开菜单避让安全区，正文能滚到最后一项且不被悬浮操作遮挡；键盘／读屏可进入选择、切换勾选、全选和退出，反馈包含条目名、勾选状态及所选项数。

## 名称搜索

独立列表页，固定来源设备及目录，退出回原浏览状态。“当前目录及其子目录”“手机内部存储”（主共享存储 `/sdcard`）和类型选择同排，默认当前目录及其子目录。类型字段显示当前选项，点按打开选项弹层，可选全部类型、图片、视频、音频、文档、压缩包、文件夹。名称子串或具体类型至少选一项。名称匹配不分大小写，无正文、拼音或规范化匹配。

「搜索」固定底部。改条件时保留已显示结果，提交后逐步显示匹配与检查数量。结果标明完整父目录，打开前核验对象。失败、跳过链接或到达上限时保留已有结果并说明漏查范围。全部检查完且无匹配时显示空态。停止保留结果，离页结束本次搜索。

## 相册检查与加载

检查当前用户主共享存储，优先读取 DCIM、Pictures 和 Movies，再检查其余可访问目录，包含 Download、自定义目录及 Android/media。排除 Android/data、Android/obb、其他用户／卷、子链接与特殊文件。按扩展名识别媒体，不冒充完整系统媒体库。

首次检查分批显示已发现媒体，显示实际检查数量。选中或打开时固定对象和浏览位置。同一设备有可用暂存时，重进直接恢复上次集合、检查时间及滚动位置。离页时仍在检查的集合以已停止状态恢复。无可用暂存或手动刷新时开始新检查。刷新期间保留正在浏览的集合，新结果可用后点「更新照片」再替换。离页后重进仍可采用待更新结果。

停止／离页保留已查范围，局部失败或上限保留可读媒体。到达检查上限时显示只检查了部分文件夹。有限范围零结果时说明仍有目录待检查。结果全量进入同一相册列表，缩略图随滚动读取。当前交付差异见[能力边界](compatibility.md#当前交付边界)。

按文件修改日期分组，组内按修改时间降序、同时间按路径；没有有效修改时间的媒体归入“日期未知”。确认更新后整批替换为同一次检查的完整结果，范围面板关闭保留位置。缩略图不是原件，设备或来源变化不复用；忙碌有限重试，其他失败主动重试。图片直接进入原件预览。视频在相册显示缩略图，点按进入文件详情，提供适用的取回、分享和手机打开动作。

相册底栏上方独立显示已加载数量及检查范围。相册底栏提供“刷新”和“选择”。选择后在相同位置提供“取回原件”，关闭选择后恢复浏览底栏，保留浏览位置。

## 手动传输、冲突与中止

双向手动传输保留层级、空目录和零字节文件。选择或外部分享明确目标设备与目录；只读取此次授权的内容，来源丢失要求重选。每条待处理分享独立结束，页面重进不重复弹出／发送，迟到回执不影响新分享。

外部分享接收的内容先完整复制到受保护的本机来源，确认落盘后才可发送；准备未完成不显示来源可用。关闭分享页、结束该条分享或移除历史不解除已提交传输对来源的保护，须确认使用该来源的所有传输均已结束后才可回收。

按宿主能力显示目录导入和系统保存：Android 使用系统授权目录，桌面使用原生路径选择。iOS 提供当前交付的选取和保存方式。

同名询问保留两份、替换或跳过，显示两端路径。决定仅复用于本任务。停止入口贴近任务，等待停止确认时保持原任务可回访。逐项重试须重验并从头开始，未知写入先核对。

收到回执后显示实际传输阶段。目标目录在该路径最后一个批次收尾后自动刷新，覆盖完成、失败与取消。

### 传输列表

传输中心每个批次显示一条任务。顶部“传输中”含等待、正在传输、需要处理和待核对的任务，按最近更新排序。“已结束”显示已核验的已完成、部分完成、传输失败和已取消结果，按结束时间排序。任务结束后自动进入对应栏。由任务日志记录结束时刻，旧记录缺少时间时省略时间。条目显示文件名或批次名、方向、来源与目标。单张图片有可用缩略图时使用原图缩略，其他文件按格式显示图标。

页签留在列表上方，切回时恢复该列表的滚动位置。进行中显示已确认的传输字节，已知总量时同时显示进度条和百分比。等待决定或核对时显示实际阶段及原因。点按任务进入同一记录的详情，逐项查看文件与结果。原件准备离页后仍可到传输中心查看。编辑副本由用户主动传回。

仅“已结束”提供“清空记录”，确认后移除该栏历史。手机原件、本机已保存文件和已取回的暂存原件均保留，正在进行或等待处理的任务留在原栏。取消确认返回原列表，清空后继续停留在“已结束”并显示空态。

## 原件取回与系统交付

完整取回、校验且暂存仍可用后才提供系统交付，准备过程显示真实进度与取消。

文件详情与图片预览在底部提供“取回文件”和“分享”。图片预览可在同一栏切换“原尺寸／适合屏幕”。单文件“取回文件”完成下载并校验原件后，只要发起页仍在前台，就直接请求主控设备的系统打开方式选择器。候选应用由系统根据格式和已安装应用决定。已离开原页时，可从本次传输记录调用系统选择器。批量取回保留逐项结果，各文件由用户选定后交给系统。[Android 系统选择器](https://developer.android.com/guide/components/intents-filters#ForceChooser) · [Apple Open In 菜单](https://developer.apple.com/documentation/uikit/uidocumentinteractioncontroller/presentopeninmenu%28from%3Aanimated%3A%29)

取消系统选择器回到原页并保留已取回文件，再次打开复用同一暂存原件。系统无兼容应用或选择器不可用时，显示实际原因及可用的保存或分享入口。“分享”在同次操作内准备并校验原件，然后打开系统分享。取消准备或分享后返回来源页，失败在原任务显示原因及恢复动作。当前实现与目标差异见[能力边界](compatibility.md#当前交付边界)。

系统确认已取消分享时，可以直接重新打开分享面板。已经选择接收应用或交接结果待确认时，先到接收应用核对，再决定是否重新分享。

| 完成点 | 含义 |
| --- | --- |
| 原件取回 | 完整原件在主控私有暂存，尚未保存至系统位置 |
| 系统打开 | 将该文件交给主控的系统打开方式选择器，系统决定可用的接收应用 |
| 系统保存 | 目标写入、关闭及结果核验完成，不保证云端提交 |
| 系统分享 | 交给接收应用，不保证其已读取、保存或发送 |

区分手机原件、本机暂存和系统副本或接收应用。待核对时提供检查入口。取消位置选择保留原件；写入后取消时检查并说明已有副本。离页结束本页仍在执行的文档操作。全部跳过显示「未保存」，部分写入显示已保存范围。

### 系统保存的安全边界

新建仅使用独占创建。目标已有内容时显示「保留两份」「跳过」或「取消」，具备可核验原子替换能力时才提供替换。单文件写入要求目标为已核验的空普通文件并支持定位和同步。管道、非空文件及失效授权给出拒绝原因。结果未知时保留目标，先核对再处理。

取回文件时，先完成本机暂存的写入，再开放原件。暂存位置明确拒绝提交时，说明原因并允许重试。提交结果无法确认时，提示先核对目标。

### 保存记录与未知结果

提交前可靠保留记录；不可读写或容量不足拒新任务，不挤掉旧记录。离页、换设备、重进和重启保留已保存／未知保护；进入先只读核验，已保存另存须确认，未知由用户到文件应用核对后明确继续。中断保留待核对及暂存；迟到回执不覆盖其他操作或终态，记录不恢复系统授权。

## 媒体暂存与空间准入

默认固定 512 MiB，区分准备中、受保护和可回收；不含手机原件、用户保存文件或系统分享副本。新准备先回收旧可回收项，仍不足则拒绝，不覆盖使用中文件。

取回、预览大图、分享或接收前检查本次所需和实测空间。不足时显示「需要 X，当前可用 Y」。大小未知时随读取检查，在超出预算前停止。按实际情况提供清理、减少所选文件或在手机上打开。保留原文件及其他设备的功能。

预览、传输、准备、保存和结果待核对期间按对象持有原件。刷新为新读取创建独立副本。交给外部应用后，在其读取期限可确认前保持文件。

暂存页在一组列表行中显示总占用与可回收、受保护、准备中的实际占用，并列出受保护项的文件名、来源、保护原因及可执行动作；所有占用均受保护时，明确显示“当前没有可清理项目”，不提供看似能释放空间的主动作。保存到系统长期位置与暂存释放是两件事，不把保存成功说成自动解除外部读取保护。

清理操作显示可回收项目并在确认后报告实际释放空间。丢失的原件需重新取得后才能保存或分享。受保护项目可另存到长期位置，已交给外部应用的文件仍保留。暂存满时显示可释放范围或返回入口，连接和远控仍可使用。
