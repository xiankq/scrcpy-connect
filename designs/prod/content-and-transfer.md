# 内容与传输

通用设备归属和提交保护见[交互规则](interaction-rules.md#内容保护与提交反馈)。

## 文件与目录边界

文件页支持目录／分类、新建文件夹、重命名、删除及手动取用。操作显示真实来源、目标和路径，删除／替换说明影响；提交后切页或换设备不改对象。不可读、未知与空目录分开；到达上限显示实际范围。遍历不跟随子符号链接，主共享存储根别名单独识别，不把无法表示的名称改成另一可操作名称。

打开、修改或取回前重验身份、类型和可访问性；源变化不拼接成完整原件，目录批次按项反馈。

- 文件夹优先、连续排列，无组标题与计数；默认四列自适应网格，可切列表且保留选择。
- 页头提供搜索、视图／排序、发送文件／文件夹；类型入口仅在共享存储首页。
- 排序支持名称、大小、修改时间、类型及方向，两类分别排序，未知值稳定回退；视图与排序本机持久化。
- 文件夹显示完整日期，文件月／日，大小最多两位小数；浏览态面包屑可跳上级，返回先回父目录，到根退出；选择态先按下述规则退出选择。

### 文件选择与批量操作

文件列表与宫格共用选择规则。触摸长按、鼠标右键或主键长按可操作条目，直接进入选择态并选中该项；已有选择保留，长按／右键已选项不反选，也不先弹上下文菜单。选择态点击条目任意位置切换勾选，文件夹也只切换选择；不可操作条目不参与选择并保留原因。普通点击的打开行为仅在浏览态生效。

- 页头沿用浏览态高度，大字时随内容增高：左侧返回换为关闭选择（×），中间显示“已选择 N 项”，右侧仅使用全选图标按钮。未全选时执行全选，全部选中后切换为取消全选图标；不显示文字标签，悬停提示与读屏名称分别为“全选／取消全选”。清空勾选后仍留在选择态，显示“已选择 0 项”，由关闭或返回明确退出。
- 全选覆盖当前目录、当前筛选下已加载且可操作的条目，包含滚出视口的条目；不递归、不跨目录、不选择未加载或隐藏条目。加载范围有限时保留原范围提示，全选不触发额外读取。
- 列表选择框原位替换右侧箭头，两态共用固定尾槽；保留左侧图形、名称、元数据、行高和间距，以及文字的可用宽度、换行和截断方式，不因选择态出现额外挤压、增高或缩放。宫格选择框叠放在缩略图区域的水平及垂直正中，名称、元数据、缩略图与格子尺寸不移动；勾选不得仅靠颜色区分。标记视觉尺寸和命中区域分开，按[视觉规范](../design.md)执行；增加命中范围不参与条目排版。
- 批量操作使用底部悬浮液态玻璃栏：“取回原文件”“删除”“更多”。取回、删除在零项或不满足能力条件时禁用并提供原因；删除仍需确认来源设备、项数和影响。更多从底部触发点向上展开，含“重命名”（仅单项可用）及“切换为列表／宫格”；视图切换保留选择、筛选和目录，不改变操作对象。
- 选择期间设备归属、路径、类型筛选保持原位；切目录、改筛选、搜索、新建、发送和刷新入口暂停，避免改变选择范围。外部目录变化只移除已确认失效的选择并更新计数，不按同名自动选择替代项；断线保留可见选择并禁用远端提交，重连后重验。
- 系统返回、Escape 与页内关闭语义一致：有菜单或确认层时先关闭该层；否则只退出选择态、清空勾选并隐藏底栏，不回父目录、不关闭页面、不触发路由返回动画。下一次返回恢复浏览态规则。退出保留目录、筛选、视图与滚动位置；已提交的传输或文件操作不因退出选择而撤销。

选择状态仅属于当前文件页和来源设备，不跨设备或进程恢复。底栏与展开菜单避让安全区，正文能滚到最后一项且不被悬浮操作遮挡；键盘／读屏可进入选择、切换勾选、全选和退出，反馈包含条目名、勾选状态及所选项数。

## 名称搜索

独立列表页，固定来源设备及目录，退出回原浏览状态。默认当前目录及子目录，可选手机内部存储（主共享存储 `/sdcard`）；名称子串或具体类型至少选一项。类型为全部、图片、视频、音频、文档、压缩包、文件夹。名称匹配不分大小写，无正文、拼音或规范化匹配。

仅点击搜索提交；改条件保留旧结果并提示更新。逐步显示匹配及检查数量，结果含完整父目录；点击重验。失败、跳过链接或触及上限保留已有结果并说明未完成范围，未查完不能称无匹配。停止保留结果，离页取消本次搜索；进程重启不恢复或自动扫描。

## 相册检查与分页

检查当前用户主共享存储，含根媒体、Download、自定义目录及 Android/media；排除 Android/data、Android/obb、其他用户／卷、子链接与特殊文件。按扩展名识别媒体，不冒充完整系统媒体库。

进入／刷新先显示检查范围及数量，结束后再展示冻结集合。停止／离页保留已查范围，局部失败或上限保留可读媒体；有限范围零结果不称手机无照片。

按修改时间降序、同时间按路径；分页使用同一次结果，不混入新内容，刷新完成后从首批替换，范围面板关闭保留位置。缩略图不是原件，设备或来源变化不复用；忙碌有限重试，其他失败主动重试。图片可用原件预览；视频仅缩略图、原件信息及系统／手机入口，无本地播放器。

## 手动传输、冲突与中止

双向手动传输保留层级、空目录和零字节文件。选择或外部分享明确目标设备与目录；只读取此次授权的内容，来源丢失要求重选。每条待处理分享独立结束，页面重进不重复弹出／发送，迟到回执不影响新分享。

同名询问保留两份、替换或跳过，显示两端路径；决定仅复用于本任务。传输中心每批列一次，详情逐项显示进度与结果。取消区分已完成、部分、失败及未知；无断点续传承诺，恢复记录不恢复字节。批次不整体重放，逐项重试须重验并从头开始；未知写入先核对。

删除历史仅移除记录；活动先确认停止，终态后移除。若影响未保存原件访问须说明；原件准备离页后仍可到传输中心查看。编辑副本由用户主动传回。

## 原件取回、系统保存与系统分享

完整取回、校验且暂存仍可用后才提供系统交付，准备过程显示真实进度与取消。

| 完成点 | 含义 |
| --- | --- |
| 原件取回 | 完整原件在主控私有暂存，尚未保存至系统位置 |
| 系统保存 | 目标写入、关闭及结果核验完成，不保证云端提交 |
| 系统分享 | 交给接收应用，不保证其已读取、保存或发送 |

统一呈现手机原件→本机暂存→系统副本／接收应用，待核对不能标完成。取消位置选择保留原件，写入中取消可能留下部分目标；离页仅取消本页仍执行的系统文档操作。全跳过且无写入显示未保存，确认有写入才称部分保存。

### 系统保存的安全边界

新建须保证不覆盖已有文件，不能先删再复制。提供方无法安全替换时禁替换，仍可保留两份、跳过或取消。单文件仅接受可核验的空普通文件及可定位、同步的目标；非空、管道、授权失效或异常明确拒绝，不退化为可能截断的方式。发布身份／结果不明进入未知，不重写或删除可能完成的目标。

### 保存记录与未知结果

提交前可靠保留记录；不可读写或容量不足拒新任务，不挤掉旧记录。离页、换设备、重进和重启保留已保存／未知保护；进入先只读核验，已保存另存须确认，未知由用户到文件应用核对后明确继续。中断保留待核对及暂存；迟到回执不覆盖其他操作或终态，记录不恢复系统授权。

## 媒体暂存与空间准入

默认固定 512 MiB，区分准备中、受保护和可回收；不含手机原件、用户保存文件或系统分享副本。新准备先回收旧可回收项，仍不足则拒绝，不覆盖使用中文件。

预览、传输、准备、保存及未知交付继续保护原件；更新不原地替换其他使用者的文件。系统分享／打开后无法确认外部读取寿命时持续保留，当前不能安全自动解除或逐项撤回，可能占满预算。

用户确认清理仅删可回收项，报告实际释放空间；原件已丢失不再提供保存／分享。
