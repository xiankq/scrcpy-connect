# 用户流程与页面对应

## 添加与连接设备

设备列表 → 添加设备 → 同页选择配对码、扫码、USB 或 IP → 设备工作台。发现入口先进入二级页，选中结果后返回原表单；帮助在当前方式内打开。配对后尚未连接时，仍在同页补全连接端口。

已有设备的连接配置 `q3bM72` 复用添加页的四方式 Tab、私钥选择、方式内容和帮助，隐藏发现入口，私钥来源置灰只读；操作归属原设备，不新增记录。

表单结构、字段、授权前提、方式切换和取消规则统一见[设备与连接设计](device-connection.md#添加与无线连接)；下方转换表定位具体状态。

## 日常使用手机与应用

从设备工作台进入整机屏幕，或从应用列表先选择打开方式，再进入独立应用窗口或手机屏幕。关闭当前画面即结束其互联画面与输入活动；远端应用真实任务默认保留并交回手机。临时遮挡或短暂断线仅暂停仍打开的窗口，不提供控制窗口管理页或关闭后恢复入口。独立窗口失败、启动结果未知及资源不足按[屏幕、窗口与输入规则](interaction-rules.md#屏幕窗口与输入)处理。

## 从通知接续短信和其他应用

通知中心只呈现当前有效通知。点击通知优先复用该设备已有手机控制画面，再进入原应用；无法定位原内容时说明只打开了应用，缺少有效动作时保留手机屏幕入口。短信全文、历史和新建消息在被控手机原应用完成。

原通知提供快捷回复时就近操作。草稿、未知结果、认证及系统提醒返回的处理统一见[通知与通信](interaction-rules.md#通知与通信)。打开远控画面与点亮被控手机实体屏幕是不同操作，通知接续遵循该设备明确选择的屏幕偏好。

## 文件管理与取用

设备工作台 → 文件页 → 当前目录或分类 → 文件详情／选择内容 → 原文件准备 → 系统保存或分享。发送本机文件或外部分享时先确认接收设备与目录；任务提交后可在传输中心查看进度和逐项结果。系统选择器与分享面板由系统提供，不另建同功能的产品选择器。

当前目录筛选保留在原文件页。“搜索子文件夹” → 填写名称及类型、确认范围 → 明确搜索 → 渐进结果 → 文件详情或文件夹原目录；停止保留已有结果，返回恢复原目录。文件安全边界、搜索条件及部分结果按[内容与传输规则](content-and-transfer.md#名称搜索)处理，下方转换表定位代表状态。

原件准备、系统保存与系统分享分别反馈完成结果；冲突、取消、未知结果核对、传输记录移除及暂存保护统一见[内容与传输规则](content-and-transfer.md)。需要编辑时进入手机原应用，或取回副本后交给本机应用，修改后由用户主动传回。

## 相册预览与取用

设备工作台 → 相册 → 检查可访问范围 → 固定结果分页 → 照片或视频预览 → 手动保存原文件或系统分享。范围面板关闭回原分页；“加载更多”继续当前结果，主动刷新重新检查。停止或离页只取消本次检查，不停止其他活动。

部分可读、有限空态、缩略图与原件的区别及刷新规则见[相册检查与分页](content-and-transfer.md#相册检查与分页)。视频不能预览时保留原件取用或在手机查看；拍摄、修图、整理交给手机原应用。

## 来电、后台与恢复

来电从对应设备进入通话页；主动拨号、联系人和通话记录进入手机原应用。控制与双向语音分别按支持状态提供，处理多台设备来电时沿用[通知与通信](interaction-rules.md#通知与通信)的路由规则。

离开前台、中断和重新进入按[后台与恢复](interaction-rules.md#后台与恢复)处理。保留设备连接、暂停视频和停止设备声音是不同结果。
