# 用户流程与页面对应

本文件只维护任务路径和 Pencil 状态索引。设备与连接规则见[设备连接](device-connection.md)，内容交付见[内容与传输](content-and-transfer.md)，屏幕与窗口行为见[交互规则](interaction-rules.md)。

## 任务路径

| 任务 | 路径 | 关键结果 |
| --- | --- | --- |
| 添加设备 | 设备列表 → 添加设备 → 配对码/扫码/USB/IP → 工作台 | 发现结果是二级页；选中后返回原表单，不把发现当作授权 |
| 连接已有设备 | 设备列表或工作台 → 连接/重新授权 | 沿用设备记录和已知身份；失败不自动重放原远端操作 |
| 打开手机或应用 | 工作台 → 手机屏幕，或应用列表 → 打开方式 | 首帧前显示无中心文字的环境场；失败与未知结果分别处理 |
| 浏览与取回内容 | 工作台 → 文件/相册 → 预览或选择 → 原文件准备 → 系统保存/分享 | 手机原件、本机暂存和系统副本是不同完成点 |
| 传输文件 | 文件页 → 选择来源与目标 → 传输中心 → 逐项结果 | 批次摘要不等于整体事务；未知写入不自动重放 |
| 接续通知 | 通知列表 → 原应用或手机屏幕 | 优先复用已有手机画面；过期动作不执行 |
| 处理来电 | 来电提醒 → 当前通话页或手机原应用 | 控制、音量与双向语音分别判断；不能可靠定位时交回手机 |
| 恢复中断 | 状态核验 → 继续仍存在的同一窗口或明确失败 | 核验失败保持未知；主动停止不被自动恢复 |

## 关键转换

| 起点 | 结果 | 取消或未知 |
| --- | --- | --- |
| 添加页选择发现结果 | 回填同一表单并保留已知连接方式 | 返回不清空可复用字段，不授予信任 |
| 配对完成但尚未连接 | 原位补连接端口并建立加密连接 | 已有配对信任保留，不重复配对 |
| 工作台切换连接方式 | 核验仍是原设备后更新原记录 | 失败保留原配置；结果未知先核对 |
| 远控页面返回 | 关闭当前画面和输入活动 | 临时遮挡、后台和短断线只暂停仍打开的同一窗口 |
| 文件页进入子目录 | 显示该目录并保留视图/排序偏好 | 顶部与系统返回先回上级，搜索离页恢复原目录 |
| 提交文件或应用操作 | 显示实际进度、结果或待核对状态 | 取消只撤回未提交意图，已开始动作可能无法撤销 |

静态状态不证明可点击原型、真实授权、GPU 成像或设备运行；证据要求见[覆盖表](coverage.md#验收依据)。
