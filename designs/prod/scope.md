# 功能取舍

让用户在主控设备上继续使用另一台 Android 的真实应用、内容与通信。优先手机控制手机，适配平板与桌面；两端条件见[平台与能力边界](compatibility.md)。

## 专用功能与原应用接续

跨设备浏览、批量取用、传输和来电处理保留专用页；阅读、编辑、拍摄、账户及系统管理由被控手机原应用承接。

| 专用功能 | 范围 |
| --- | --- |
| 设备与连接 | 发现、授权、工作台、恢复与支持说明 |
| 手机屏幕与应用 | 整机控制、活跃应用、应用列表与搜索、独立应用窗口；沿用真实任务及登录状态 |
| 文件与传输 | 目录与分类、名称搜索、基础文件操作、双向手动传输、进度与冲突处理 |
| 相册 | 图片预览、视频缩略图与原件信息、选择、手动取回和分享；视频交给系统应用或手机查看 |
| 通话 | 当前来电与通话状态；具体动作及语音受[当前交付边界](compatibility.md#当前交付边界)约束 |
| 通知 | 当前有效通知、来源、清除与接续；验证码复制等原通知轻操作按实际能力提供 |
| 设置 | 按[信息架构](information-architecture.md)区分全局、设备和连接配置 |

截图、键盘、声音、剪贴板和系统分享就近提供，规则见[交互规则](interaction-rules.md)。

| 接续任务 | 去向 |
| --- | --- |
| 短信、即时消息、邮件、日历、笔记 | 通知进入手机原应用；全文、新建、回复及历史均在原应用处理 |
| 主动拨号、联系人、通话记录 | 手机电话应用 |
| 拍摄、修图、图库整理 | 手机相机或相册 |
| 文档编辑 | 手机原应用，或取回副本用本机应用编辑后主动传回 |
| 卸载、权限与系统设置 | 手机对应设置；应用列表只负责启动和切换 |

通知接续优先复用已有手机画面；定位失败时明确退到应用或手机屏幕。主动从应用列表打开独立窗口仍保留。

## 移出产品范围

- 录屏、录制中心及录制后台任务。
- 文件／相册自动备份、云相册、计划与删除联动。
- 独立短信、聊天、邮件、日历或笔记系统；通知快捷回复、长期通知档案与联系人同步中心。
- 自动编辑回写、版本合并与编辑副本管理中心。
- 专用相机页、虚拟摄像头／麦克风共享、热点管理。
- 应用安装管理、命令终端和日志查看器；连接诊断与本机运行日志仍保留。

这些是当前取舍，不构成后续补齐承诺；被控应用自身功能仍可通过远控使用。

## 连接服务范围

跨网路径由用户已有的 VPN、网关或隧道提供；不建设自有账号、云中继、自动穿透或远程协助邀请。路径可达与控制授权分别检查，见[设备与连接](device-connection.md)。
