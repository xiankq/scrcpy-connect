# 交互规则

本文规定远控画面、窗口、输入、声音、剪贴板、提交反馈和后台的通用行为。各功能页只写自己特有的规则，通用部分链接到这里。视觉反馈与过渡见[页面交互与动效](../interaction-motion.md)，提示文案的写法见[文案与反馈](../design.md#文案与反馈)，列表等待与刷新的样式见[空态、加载与进度](../design.md#空态加载与进度)。

两条贯穿全文的规则：

- 读取失败时，继续显示上次读到的内容，并说明需要刷新。
- 操作可能已经生效但还没确认时，先提供核对结果的入口，确认没有生效后才允许重试，避免重复执行。

## 设备与操作归属

- 当前操作设备由用户正在看的页面决定。后台事件（如另一台设备的来电或通知）不会改变当前操作设备。
- 操作提交后，来源和目标就固定了。之后切换页面或设备，不会取消原设备上的传输或通话。
- 通过链接或恢复入口进入（如点系统提醒、系统恢复窗口）时，先核对设备、任务和控制会话仍是原来那个。核对通过后可以恢复已有画面。
- 新建控制会话必须由用户在这一次明确点「打开」。没有这一步时，页面显示「重新打开」，由用户决定。

## 选项弹层

适用于应用内的下拉字段和选择行。系统自带的选择器（如文件选择器）沿用各平台行为。

- 窄窗口打开底部弹层，宽窗口打开居中弹窗。
- 系统返回、Escape 或点「取消」：关闭弹层，原值和表单草稿不变。
- 点选普通单选项：关闭弹层，原控件显示选中值。
- 在需要点「提交」的表单里选值：只更新草稿，仍由原页面的提交按钮提交。

## 屏幕、窗口与输入

### 窗口环境与响应式结构

- 布局只依据当前窗口的 `WindowEnvironment`：可用边界、方向、安全区、折叠／铰链保留区、窗口模式、输入能力和窗口身份。
- 窗口尺寸连续变化时，用约束、折行和滚动适配。跨过宽度或高度阈值时，重排导航和窗格，保留当前任务、选中项和编辑中的内容。阈值见[自适应窗口与形态](../design.md#自适应窗口与形态)。
- 重要文字、输入框和控件只放在安全窗格内，不放在铰链或折叠保留区上。
- 窗口按钮、拖动、缩放、系统菜单和快捷键只作用于它所在的窗口。各平台标题栏见[桌面窗口标题栏](../design.md#桌面窗口标题栏)，窗口能力来源见[平台与能力](compatibility.md#窗口与形态适配目标)。
- iPhone Duo 竖栏模式下，设备分栏的「添加」和当前设备管理、传输分栏的任务工具，放在该窗口的系统外缘，见 [iPhone Duo 专项](../design.md#iphone-duo-专项)。
- 桌面导航随窗口宽度在底部导航、图标轨道、带文字侧栏之间切换，切换时保留当前页面、选中项和滚动位置。

搜索（设备列表和全部应用）：

1. 点页头的搜索按钮，或在桌面按 ⌘F／Ctrl+F：搜索框原位替换页标题并获得焦点。
2. 输入时立即按名称、型号或包名筛选。双栏布局下，右侧详情保持不变。
3. 点清除按钮：清空输入，仍停留在搜索状态。
4. 点关闭、按 Esc 或页面返回：恢复页标题和完整列表。

### 画面与窗口

- 「打开屏幕」打开该设备唯一的手机屏幕窗口。每台设备的每个应用最多有一个独立应用窗口。
- 再次打开已打开的画面时，聚焦现有窗口；窗口已最小化时先恢复。
- 从「当前活动」打开画面时，先核对这个控制会话仍然有效。
- 同一设备的多个画面共用一条设备连接；每个画面有自己的视频、输入焦点和界面状态。切换到另一个可操作的画面后，键盘输入跟着焦点转到新画面。

「远控窗口」（设备页、工作台和画面工具里都能打开）：

- 按设备分组列出所有画面，每组第一个是手机屏幕，点应用图标切回对应画面。
- 「返回工作台」回到当前画面所属设备的工作台，画面会话和工作台滚动位置都保留。
- 系统允许多窗口时，可同时显示多个系统窗口。键盘、剪贴板和触控只作用于获得焦点的窗口。
- Android 可从系统最近任务直接切回同一画面。

暂停与关闭：

- 窗口最小化或应用进入后台：画面暂停。
- 应用内窗口被其他窗口遮挡：画面暂停，松开所有按住的按键和触摸；重新切到这个窗口后恢复原会话。
- 关闭一个窗口只结束这个窗口的控制会话。
- 弹层关闭后，已可见的画面恢复播放；键盘、触控和剪贴板要等窗口重新获得输入焦点才恢复。

并排（宽屏应用内）：

1. 在「切换窗口」里，对另一个画面选「与当前画面并排」，两个画面同时显示。
2. 先点选要操作的一侧，再输入。
3. 窗口变窄时只显示当前画面；宽度恢复后恢复并排。
4. 在列表里选「仅显示当前画面」结束并排，两个会话都保留。

并排的宽度条件见[远控窗口](../design.md#远控窗口)，平台能力见[平台与能力](compatibility.md#窗口与形态适配目标)。

### 呈现与启动

画面尺寸：

- 打开桌面手机屏幕窗口前，先读取手机当前屏幕尺寸，按手机屏幕比例设置窗口大小和缩放。手机旋转后更新比例。
- 应用内全屏，或系统限制了窗口尺寸时，按手机屏幕比例完整显示画面，不裁切。
- 悬浮工具避开安全区。三键导航栏贴在视口底边，单独占一条栏高，不盖住画面。

打开画面（布局见[手机屏幕与应用](../design.md#手机屏幕与应用)）：

1. 用户打开手机屏幕或独立应用后，同一视口显示等待界面，直到收到第一帧真实画面。等待期间可以点「关闭」。读屏播报来源设备和当前阶段；需要在手机上授权时，原位显示简短指引。
2. 收到第一帧后立即显示画面，开放输入。
3. 等待超时或收到明确的失败结果时，同一页面切换为「无法打开手机屏幕」或「无法打开独立应用画面」：停止动画，显示实际原因；超时时说明还没收到画面。
4. 失败后：
   - 点「重试」：回到同一页面等待，优先接续已提交的那次尝试，而不是再发一次。
   - 点「关闭」：请求还没提交时，取消这次打开；已经提交时，保留这次打开的记录，可在应用入口核对（见[内容保护与提交反馈](#内容保护与提交反馈)）。

手机熄屏：控制会话已建立且确认手机熄屏时，直接显示黑色视口，中央显示「点亮屏幕」图标。点按后请求唤醒手机，收到可用画面后图标消失。手机处于锁定状态时，用户在画面里按手机正常方式解锁。

暂停和断线：

- 已打开的画面暂停时，保留最后一帧，顶部安全区显示小号「已暂停」提示，不再向手机发送输入。
- 断线时，提示里补充原因和「检查连接」；画面工具里的关闭仍可用。
- 「检查连接」针对原设备和原会话。该会话收到新画面后恢复操作，提示消失。
- 关闭后回到进入画面前的页面，保留原滚动位置。

### 工具、返回与关闭

画面工具：

- 顶部显示设备名和连接状态（读屏也能读到）。
- 操作：播放设备声音／静音、熄屏、截图、转换为独立应用／移回手机屏幕、键盘、旋转、切换窗口、关闭画面。
- 每个窗口的工具只作用于这个窗口的画面。进入或切换会话时保留原视口。

拖动工具把手：

1. 拖动时，圆形把手跟随手指或指针。
2. 松手后变为竖长条，吸附到最近的安全侧边。拖动中再次抓取可打断吸附；开启减少动态时直接吸附，没有动画。
3. 点按长条后，工具面板朝画面内侧展开。读屏提供「展开」和「关闭」操作。
4. 视口、软键盘或安全区变化时，重新计算把手位置。

返回键：

- 控制页拦截系统返回。画面可操作时，系统返回和 Escape 向手机发送返回键。
- 连接等待期间，系统返回不离开控制页；要退出就点「关闭」。
- 普通页面沿用 Cupertino 风格的返回。
- 手机三键导航栏默认显示，可在设备的「画面与控制」里关闭。

关闭：

- 用户点「关闭画面」：结束这个画面和它的输入，回到进入前的设备页。
- 关闭独立应用窗口时，应用任务交回手机继续运行；不强行停止应用，不断开设备连接。
- 已关闭的窗口不会自动恢复。被遮挡、进入后台或短暂断线只让窗口暂停，窗口仍保持打开。收起软键盘不算关闭画面。
- 切换主题或本机页面刷新时，已有控制窗口保持不变：不重新启动手机应用，不新建控制会话。
- 恢复的页面只接续原来的控制会话，不新建。

转换画面：

- 点「转换为独立应用」：先确认手机屏幕上当前在前台的应用，打开或切回它的独立应用窗口；手机屏幕窗口保留。
- 点「移回手机屏幕」：把应用交回手机屏幕，关闭这个独立应用画面，切到手机屏幕窗口。
- 关闭独立应用画面没有得到手机确认时，保留原窗口并显示错误提示。

截图：

- 截取当前收到的那一帧视频，分辨率等于该帧分辨率。暂停时也能截取最后一帧，并标明是最后画面。
- 完成后显示缩略图和「保存到系统位置」「分享」。是否保存或分享成功，以系统返回的结果为准。

### 比例、清晰度与屏幕偏好

这些偏好在设备的「画面与控制」里设置，按设备分别保存。

清晰度：

- 点行尾的当前档位，打开单选弹层。选项依次为「320P（流畅）」「720P（均衡）」「1080P（清晰）」「1920P（超清）」「原画」，默认「720P（均衡）」。
- 设备已保存的值不在上述列表中时，列表里也显示这个值并标为选中。
- 「原画」按设备最大分辨率请求；实际输出取决于设备能力和协商结果。

帧率上限：

- 与清晰度分开选择。选项为 30 FPS、60 FPS，新设备默认 60 FPS。已保存其他值时同样显示在列表中。
- 用于整机画面和独立应用窗口的捕获上限。实际帧率随画面内容和设备处理能力变化。

选择清晰度或帧率上限后：

1. 关闭弹层，保存为该设备的偏好。
2. 已打开的画面重新开始捕获，手机上的应用任务不受影响。之后新开的画面直接使用新设置。
3. 分别提示偏好是否已保存、每个画面是否应用成功。应用失败时结束等待，显示原因，提供重试。
4. 只在下次新建画面时生效的设置项，在该项旁写明生效时机。

屏幕比例：

- 选项：原始、自动、9:16、3:4、1:1、16:9、自定义。没有保存过比例的旧设备记录按「原始」处理。
- 自定义比例的宽和高都必须是正数，宽高比在 1:5 到 5:1 之间。
- 改比例只对之后新开的窗口生效，已打开的窗口保持打开时的比例。
- 「自动」随可用区域变化：扣除导航键和安全区，但软键盘临时遮挡时不改变比例。
- 整机画面的比例会改写手机自身的显示尺寸，独立应用窗口的比例只影响该窗口。
- 整机控制会话结束时，恢复手机原来的显示设置。如果会话期间用户或其他工具改过手机显示设置，保留那次修改。
- 重新连接时，先检查上次是否留下没恢复的手机显示设置。手机确认已恢复之前，新窗口不再改写手机显示设置。恢复请求发出不等于已恢复。

独立应用窗口分别设置像素尺寸、画质上限和逻辑密度，使手机上的文字大小和触控尺寸保持不变。为节省带宽降低分辨率时，不改变内容密度。

屏幕行为：

| 偏好 | 默认 | 行为 |
| --- | --- | --- |
| 显示导航键 | 开启 | 在远控画面下方显示手机三键导航栏 |
| 新画面启动时点亮屏幕 | 开启 | 用户每次明确新建画面时，在第一帧之前唤醒手机一次；同一次打开的重试不重复唤醒 |
| 关闭最后画面时熄屏 | 关闭 | 只在用户主动关闭该设备最后一个活跃画面时熄屏；暂停或在后台的画面也算活跃画面 |
| 保持手机唤醒 | 关闭 | 立即作用于已打开和之后打开的窗口，让已亮屏的手机不自动熄屏；最后一个窗口关闭后取消。不主动点亮屏幕，不修改手机的熄屏时间设置 |

- 没有保存过的项使用上表默认值；用户明确关闭的项保持关闭。
- 连接变化、切换设置、接入已有画面、恢复旧窗口都不触发点亮或熄屏。点通知复用已有画面也不算新建。
- 点亮或熄屏失败时，不阻止打开或关闭画面，也不自动重试。
- 只有确认手机已熄屏或已锁定时才显示「点亮屏幕」图标。不把黑色画面当作锁屏的证据，不绕过手机锁屏认证。点亮不发送电源键，因为电源键是亮灭切换，可能反而熄屏。
- 「熄屏」发送 [Android 休眠键](https://developer.android.com/reference/android/view/KeyEvent#KEYCODE_SLEEP)。是否需要解锁由手机设置决定。确认手机已锁定后显示「已锁定」。

### 输入与应用接续

输入：

- 落在画面外的触控不发送。手势中途移出画面时，取消手势剩余部分。
- 本机键盘只向获得焦点的画面发送已确认的文字和删除键。输入法组字确认后只提交一次。画面失焦、暂停、进入后台或切换会话时，丢弃还没确认的组字。
- 输入非 ASCII 文字时可能借助粘贴完成，因此会改写手机剪贴板。主控不显示手机端的输入法候选、选区、撤销历史或密码内容。

打开应用：

- 「全部应用」「常用应用」「正在运行」里点应用，弹出「在手机屏幕中打开」和「打开独立应用画面」。
  - 「在手机屏幕中打开」：在该设备唯一的手机屏幕窗口中打开应用。
  - 已有该应用的独立窗口时，两项分别变为「移回手机屏幕」和「切回独立应用」。
  - 系统只支持其中一种方式时，另一项说明不可用的原因。
  - 点菜单外或按返回：取消，不打开。
- 打开的是手机上的真实应用，沿用其登录状态。按包名启动时，由手机系统决定复用哪个已有任务。

独立应用画面打开失败时：

- 确认请求没有提交到手机：用户可以改为在手机屏幕中继续，优先复用已打开的整机画面。应用不会自动改用手机屏幕。
- 请求已提交但结果未知：只能核对这一次打开的记录，不能换一种方式再启动一次。用户核对并关闭记录后，才能重新选择打开方式；手机上的应用任务保留。

## 声音与剪贴板

设备声音（被控设备上供主控播放的声音）：

- 同一设备的多个画面共用一路声音；不同设备的声音可以同时播放。
- 用户在画面工具里选「播放设备声音」后开始播放；离开或关闭该设备最后一个控制页面时停止。
- 画面工具显示该设备声音的状态：播放中、静音、受限、待恢复。
- 永久失去音频焦点（如其他应用开始长时间播放）或音频输出中断时停止播放，等用户再次操作才恢复。
- 进入后台时的处理见[后台与恢复](#后台与恢复)。电话接力的声音单独管理，见[电话接力](calls.md#中断与恢复)。

自动剪贴板（在设备管理里按设备开启，默认关闭）：

1. 首次开启时，说明会在两端互相传送新复制的文字，并按系统要求申请粘贴权限。
2. 只有可见且获得焦点的控制画面参与同步。
3. 切换设备、重新进入画面或回到前台时，重新读取两端当前内容作为基准，本机剪贴板内容不被覆盖。之后任一端新复制的文字同步到另一端。
4. 画面失焦、退出、进入后台、权限受限或内容来源待核对时，暂停同步。
5. 权限受限时显示去哪里授权；远控照常可用。

当前交付情况见[能力边界](compatibility.md#当前交付边界)。

## 内容保护与提交反馈

适用于打开应用、保存到系统、删除等需要等手机或系统返回结果的操作。传输和通话的核对与恢复在各自页面提供。

| 情况 | 用户看到的结果 | 下一步 |
| --- | --- | --- |
| 请求已受理 | 按实际阶段显示待确认或进行中 | 等待结果 |
| 收到执行结果 | 完成或失败 | 失败时按原因重试 |
| 结果丢失 | 待核对 | 返回页面、换方式或重连后，继续核对同一次操作，不重新执行 |
| 已受理后用户取消 | 「正在停止」；收到停止确认后显示已停止 | 超时时提示查看结果，保留退出和核对入口 |

待核对的应用打开记录：

- 从应用入口可以查看，显示真实来源设备、应用和未知原因，提供「重新核对」和「关闭记录」。
- 「关闭记录」只结束本机的跟踪，手机上的应用任务保留。
- 核对确认画面仍在时，进入原画面。

提交记录：

- 打开应用和保存到系统这两类操作，提交前先把记录写入本机。记录写不进去（空间不足或读写失败）时，拒绝这次提交。
- 取消只能撤回还没提交的请求。已执行的操作保留实际结果，结果未知的标为待核对。文件交付的规则见[内容与传输](content-and-transfer.md)。

## 通知与通信

[实时通知](notifications.md)规定通知的查看、接续、清除和系统提醒。[电话接力](calls.md)规定电话入口、通话状态和跨设备声音。两者都回到所属设备的来源页面：点通知打开原应用时复用已有控制会话；通话是否继续由通话自身状态决定。

## 后台与恢复

活动：连接、通知、传输、声音、通话各算一项活动，每项标明所属设备。画面暂停后，以手机返回的回执为准更新捕获状态。

后台保持（让主控进入后台后，在系统允许范围内保持连接和已开启的活动）：

| 主控 | 行为 |
| --- | --- |
| Android | 提供开关，默认开启；进入应用即申请系统前台服务 |
| iOS | 目前不支持持续的后台保持，不显示可开启的开关。用户离开应用后，连接、传输和提醒可能暂停 |
| 桌面 | 按应用进程和各系统的实际能力说明，不套用 Android 前台服务的文案 |

- 设置页分别显示三件事：用户的开关偏好、系统是否允许、服务实际是否在运行。
- 后台保持与打开了几个窗口无关，也不会自动打开画面、播放声音或唤醒手机。
- 用户主动停止的活动不会自动恢复。某一项活动失败只结束这一项。
- 应用被系统回收后重新启动时，恢复用户之前开启的意图（如保持连接），不重放历史操作。资源不足时，优先保住已在进行的重要活动。

关闭后台保持：

- 撤销系统的后台保持资格，但不主动断开已有连接、取消传输或停止通知观察；这些活动之后可能因系统限制而中断。
- 离开前台后，暂停新的自动重连和声音播放；回到前台后，核对并恢复仍然有效的意图。不可见的画面和剪贴板按各自规则暂停。
- 暂停重连不清除设备的连接意图。用户明确停止连接的规则见[保持连接与自动重连](device-connection.md#保持连接与自动重连)。

Android 系统通知里的「停止设备活动」：点按后保存停止意图，停止所属的连接和活动，下次连接由用户手动发起。后台设置页分别显示已保存的偏好和服务状态：「重新启用后台保持」保存开启偏好并申请服务；服务已运行但缺少通知权限时，显示「允许连接通知」。

状态中断后：

- 核对原窗口，暂停新的远端操作和剪贴板。
- 可见窗口收到新画面后恢复输入；在后台的窗口继续暂停。
- 确认会话已结束时，清除旧画面。核对失败时保留原状态，提供退出和停止入口。
- 通知和通话重新检查已有的观察；重新启用观察由用户发起。
