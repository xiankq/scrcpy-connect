# 交互规则

## 设备与操作归属

当前操作的设备与正在查看的内容保持可辨。切换设备不自动取消原设备的传输或通话；跨设备分享明确选择目标。文件、通知、声音和窗口都保留来源设备。

已配对、当前连接和功能可用分别呈现。恢复设备名称和偏好不恢复授权身份；更换主控或重新安装后，明确提示重新授权。离线设备仍可查阅允许保留的本地内容，但不能把旧状态显示成实时结果。

保存、分享、回复等操作一旦提交，来源和目标属于该次操作；界面切换到另一设备不悄悄改变目标。提交前仍待确认的操作须持续显示目标，用户可以返回重选。

## 屏幕、窗口与输入

移动端整机、原应用接续和独立应用会话默认沉浸全屏，直接操作远端真实屏幕，不设置“查看模式”。主控状态栏、页头和底部工具栏收起；画面保持比例，比例不同时完整容纳源画面，不拉伸或裁掉远端系统控件。画质/声音、资源不足和断线恢复面板叠加于全屏画面，不能退回带页头的内嵌屏幕；面板出现后退出入口仍可触及。断线最后画面标记暂停，禁用远端输入，恢复首帧后才恢复操作。工作台与会话列表以状态卡提供入口，不呈现裁切的横向可操作画面。

唯一常驻的主控控件是悬浮退出按钮：点击展开的按钮退出，按住拖动时连续跟手，松手吸附最近的左右边缘并收起，拖动结束不触发退出。收起态只显示侧边把手，点击或向内拖动展开；不可完全消失，读屏可直接找到展开与退出动作。按钮命中与拖拽由主控消费，不向远端发送；旋转、分屏、键盘和安全区域变化后重新约束位置，避开关键系统手势区域。返回/主屏/最近任务使用远端原有手势；本机IME跟随输入焦点，其他会话工具由设备工作台或会话设置进入。

退出当前远控呈现后返回进入前的设备页面，例如工作台、应用列表或窗口列表；当前窗口暂停并保留，之后可从会话列表继续。连接、传输和通话按各自规则继续；不等同于远端返回、强制停止应用或断开设备。不可见视频沿用暂停规则。键盘与导航工具服务当前会话，关闭输入界面和退出远端应用具有不同含义。低延迟是默认目标，同时提供流畅、均衡、高清预设以及详细质量设置。画质调整作用于新建窗口；已保留的窗口继续使用原设置，关闭后重新打开才应用新参数，不能把恢复旧窗口描述成已切换画质。

独立应用窗口接续真实任务，不意味着复制应用或创建独立登录态。单实例迁移时说明对被控手机的影响；会话列表提供明确的关闭操作；关闭窗口释放该窗口，默认保留真实任务并交回手机，不影响其他窗口。需要强制停止时进入被控手机的系统设置，关闭窗口不承担该操作。

工具先明确选择窗口，不能仅凭设备名称在多个窗口中任意选择。导航、旋转和输入工具打开对应的全屏画面，恢复可用后才执行一次；返回或页面重建不重复执行。截图可以读取已暂停窗口的最后画面，完成后说明真实保存位置或提供系统分享。录屏不在产品范围内。

## 声音与剪贴板

同一被控设备的多个窗口只播放一份设备声音。多设备默认播放当前选定的一台，允许固定音源；混音由用户主动开启。焦点切换和声音来源分别可辨。

自动剪贴板同步由用户开启，默认跟随当前操作设备，可固定对象；其他后台设备的复制不自动覆盖主控。主动发送时允许选择其他设备。权限受限时提供明确复制、发送或系统分享的入口，不要求主控开启调试。

## 内容保护与提交反馈

| 场景 | 默认行为 |
| --- | --- |
| 传输遇到同名文件 | 询问保留两份、替换或跳过，可应用到当前任务 |
| 取消或传输中断 | 区分已完成与未完成内容，说明能否恢复，避免把部分内容标为完整文件 |
| 本机副本编辑后重新发送 | 用户主动发送，按普通文件传输和同名冲突规则处理 |
| 消息或其他提交结果未知 | 先核对结果或提示用户，不直接重复执行 |

“已发送”“已保存”“已传回”等完成文案以实际结果为准。等待确认、进行中、已完成、失败和结果未知使用不同状态；错误提示给出与当前任务相关的下一步。

## 通知与通信

实时通知上的清除、打开和回复作用于被控手机的对应内容；仅本地隐藏作为独立操作。失效通知不能继续回复，通知中心不建设长期历史档案。短信和其他应用的完整内容通过原应用接续处理，不建立独立数据中心。

主控锁屏默认不公开远端通知正文和验证码；解锁进入App后按授权查看当前内容。点击通知优先复用已有手机画面，不自动另开独立应用窗口；需要手机解锁或应用认证时交还原界面，完成后重新核验原动作。无法定位内容时解释当前只打开了应用或手机；不强制点亮实体屏幕，不绕过认证。

通话控制与主控语音分别呈现可用情况，明确声音在哪里播放和收音。设备不支持完整链路时说明可完成的部分，保留转到手机继续处理的入口。

已有通话保留主控麦克风与通信声音；新的来电不自动接听、抢占或结束旧通话。多设备或等待来电分别标明设备与呼叫对象，提供拒接、留在手机处理或明确切换的路径。设备无法可靠针对某次呼叫执行时，交回手机原电话界面，避免作用于另一通话。

## 后台与恢复

连接、通知、传输、后台声音和通话分别表达活动状态。用户可以明确停止活动或断开设备；暂停不可见画面不等于停止连接。

短暂中断恢复可持续活动，主动停止保持停止。系统回收后在允许恢复或下次打开时重建用户意图，但不把历史活动一律重新执行。资源不足优先保护已有重要活动，降级与暂停都给出可解释反馈。

## 可访问与反馈

状态同时使用文字与图形，不能只依赖颜色。尊重系统文字缩放、减少动态效果和降低透明度的偏好。材质与动画服务导航和操作，内容始终清晰可读；视觉细节统一引用 [design.md](../design.md)。
