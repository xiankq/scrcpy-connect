# 电话接力

电话快捷入口用于打开被控手机的原电话界面，或在能力已验证时接续正在发生的通话。当前已交付的是手机画面路径，详见[平台与能力](compatibility.md#当前交付边界)。

## 能力与入口

按主控平台、被控设备、当前用户及蜂窝或网络通话逐项核验来电观察、接挂控制、下行声音、麦克风上行和声音交接。页面按当次核验的能力提供操作。

| 当前情况 | 入口与结果 |
| --- | --- |
| 没有已核验的当前通话，或设备只能打开原电话应用 | 工作台“电话”直接打开手机电话界面，优先复用已有整机画面。拨号、查找联系人与通话记录均在原应用完成 |
| 观察到来电或通话，手机负责接听 | 工作台来电入口显示来源、已核验身份及声音位置，直接提供“在手机画面接听”或“打开手机通话界面”。接听与挂断由用户在手机画面操作 |
| 已核验同一通话及完整接力能力 | 进入同一电话页。响铃时提供“在此接听”及手机画面路径。接通后提供已核验的静音、声音选择及挂断 |
| 观察或连接已失效 | 停止旧通话动作，显示待核对状态。连接仍可用时核对同一通话，连接中断时先检查连接 |

工作台快捷区的“电话”位置固定。无已核验通话时直接进入原电话应用，省去说明中转。仅原应用或手机通话界面的打开结果无法确认时，显示“电话界面待核对”，可查看原设备画面；该动作沿用同次请求核对画面。已核验失败时在原位置显示原因及可执行的重试或检查连接。原应用已存在的通话可在声音能力验证后转到主控。

前台新来电先出现紧凑来电入口，突出真实来电者并显示来源设备。点按按能力进入同一电话页或直接打开手机通话界面。提示本身不抢占当前任务与键盘焦点，其他设备来电仍可从带来源的独立提示进入。后台按已有来电提醒偏好及宿主实际资格处理，系统提示使用通用文案。身份不可读时使用“来电者未知”；头像仅使用已核验身份所提供的头像。

真实来电或通话在工作台主动作下方显示一条入口。工作台、来电提示以及能确认是同一通来电的通知共用该通话的处理路径。完整接力使用独立页面并保持主控主题，返回、换页及切设备只离开当前界面，通话继续。未验证完整接力时，来电入口直接接续手机通话界面。系统提醒点击只触发进入或核验，接听由用户在适用界面明确发起。

## 接听与通话中

“在此接听”是明确使用主控麦克风和扬声器／当前耳机的动作。首次点按时才请求主控麦克风权限；拒绝后仍可打开手机画面。接听前准备音频、核对来源设备及仍在振铃的同一通话；准备未完成显示“正在准备接听”，可取消准备，尚未接听时取消不得挂断手机来电。准备失败不自动改成在手机接听。提交前来电已结束或被另一通话替换时撤销旧动作，不操作新来电。

提交后显示“正在接听”，接通回执更新通话阶段，声音路由回执单独更新声音位置。计时只从真实接通事件开始。已接通而音频失败时显示“已接通，声音未接通”，保留已核验的手机接续和挂断。拒接及挂断作用于当前可可靠定位的通话；结果未知时在同一位置提供核对，刷新和重连只读取结果。

电话页把来电身份、来源和实际阶段放在固定视觉位置。响铃时，底部左侧为“拒接”、右侧为“在此接听”，两者下方提供“在手机画面接听”。准备或提交期间在原操作区显示当前阶段及可执行动作。接通后底部改为麦克风与声音输出，挂断独立放在下方。麦克风静音控制送往对方的声音，输出选择列出已验证的设备。窄屏、大字与低高度时仍能滚动到所有动作。返回保留当前通话及入口，挂断单独结束该通话。

切回手机和转到此设备都操作同一通话。系统确认目标音频路线就绪后切换显示并释放原路线。失败时保留可用路线，给出可重试动作。缺少切回能力时提供「打开手机电话界面」，保留当前声音位置。

## 中断与恢复

首版每台主控同时接力一通。存在其他通话、来电等待或无法区分对象时，打开手机电话界面处理。新来电出现后保留既有通话。

通话声音在独立活动中运行。接力建立前暂停本应用其他设备声音及媒体预览，结束后恢复仍有效的播放意图。主控来电、音频焦点丢失、耳机移除、麦克风权限撤回或网络中断时，就地更新接收、麦克风和声音位置。需要改为外放时由用户选择。

连接中断时显示「手机通话状态待确认」，暂停主控麦克风和远端通话操作。系统确认声音回到手机后才显示对应状态。重连先核对原通话和音频路线，再由用户选择是否继续接力。

前台接力按宿主实际能力提供。未验证的后台组合在进入后台后按系统事件显示状态。系统来电界面、耳机键和锁屏接听分别核验，再提供对应入口。

## 交付与验证门槛

当前只交付打开手机系统通话界面的路径，见[平台与能力](compatibility.md#当前交付边界)。完整接力稿标记为“待验证目标”；运行产品只出现实际能力和可执行动作，不出现研发说明、假开关或“即将支持”的空入口。

按主控、被控和通话类型记录实测结果。测试覆盖真实接听与对端挂断、双向声音、回声与延迟、静音、声音交接、锁屏和后台、耳机变化、重连和快速更换来电。页面仅提供通过实测的功能与组合。

当前核验范围见[平台与能力](compatibility.md#当前交付边界)。音频能力参考 [scrcpy 音频文档](https://github.com/Genymobile/scrcpy/blob/master/doc/audio.md)。
