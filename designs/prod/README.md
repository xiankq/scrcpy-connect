规则在对应正文中维护，其他文档引用责任章节。研究、实施报告和历史验收可以移除，不能成为理解产品约束的前提；它们的技术细节、实验结论和版本结果不自动成为产品承诺。

Pencil 的一个 Frame 可以表示同一页面的不同状态、抽屉或系统授权示意，不要求逐 Frame 建立路由。源码、静态稿、运行结果与未完成项分别判断，验收证据要求见[流程覆盖](coverage.md#验收依据)。

产品目标、源码已实现行为、静态视觉证据与物理设备验证分别判断。存在入口、设计页面或自动化通过记录，均不能单独证明所有设备已支持相应能力。
