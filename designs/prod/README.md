| [实时通知](notifications.md) | 查看、接续原应用、清除和系统提醒 |
| [电话接力](calls.md) | 电话入口、来电、在主控通话和切回手机 |
| [应用版本与更新](app-updates.md) | 当前版本、检查更新、更新记录、下载和系统安装 |
