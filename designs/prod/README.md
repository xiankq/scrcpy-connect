# 互联产品设计

本目录承接产品目标与设计稿，解释用户在什么场景下使用产品、从哪里进入功能、操作后发生什么，以及中断或受限时如何继续。技术依据和架构取舍见 [docs](../../docs/)，视觉值见 [design.md](../design.md)，具体界面见 [mobile.pen](../mobile.pen)。术语沿用根目录[词表](../../GLOSSARY.md)。

本目录维护产品定位、信息架构、用户流程、交互规则与页面职责。代码库选择、代码目录、协议实现、构建命令和工程路线由技术文档维护。页面样式使用视觉规范，本目录不另定义颜色、字号或间距数值。

## 产品定位

让用户在手边的设备上继续使用另一台 Android 手机的应用、内容与通信。面向普通用户，以手机控制手机为优先场景，同时考虑平板与桌面的使用方式。产品围绕有价值的跨设备任务组织能力，具体设备能做什么由实际能力决定。

主控设备始终不要求开启调试。被控手机无需安装额外应用；连接引导帮助用户完成其系统要求的调试设置和授权，后续日常连接尽量减少重复操作。设备名称和历史记录不等于当前已获得连接授权。

应用互联接续被控手机上的真实任务和登录状态。文件与相册强调浏览和取用；短信等应用内容通过通知进入手机原应用。通话、相册和文件管理提供专用功能页。用户应始终知道当前操作的设备、内容归属和操作结果。

本轮明确移除录屏和自动备份，不再为短信建设独立收件箱或编辑器。其他能力依据[功能取舍](scope.md)确定，厂商存在某项功能不等于本产品也需要加入。

## 设计状态

设计稿当前为十二类、94 个页面（92 个手机页、2 个大屏页），均在同一个文件内按类型分行，每页独立。设备列表是固定首屏，不设置主力／备用角色；补齐列表空态、检查中、全部离线和搜索状态。选择设备后进入工作台，文件、相册、通知和通话分别提供入口。

连接流程区分添加与发现、无线表单和 USB 授权：地址、连接端口、配对端口、配对码分别表达，补齐格式错误、配对过期、配对后未连接、连接中、需重新授权及两端授权状态。设备管理增加详情、名称、连接偏好、诊断、断开、移除和仅恢复元数据的状态。文件目录、重命名、删除确认、传输部分成功、视频与格式回退、通知失效与未知回复、画质选择、设备内剪贴板与导航键开关、后台活动和多设备来电也已补画。

黑白石墨主题、默认浅色与语义状态色继续保留；玻璃用于导航、浮层与控制。九个移动远控状态继续共用全屏组件，退出可拖拽并左右吸附。当前27个母组件，包括设备卡、导航标题、表单字段、状态反馈、功能入口、原文件取用状态和共享搜索条件。

后续7页表达原文件准备、可保存／分享、系统保存取消／成功、未开始失败和结果待核对，另补3页搜索条件、进行中和停止后保留结果。另补应用打开方式与全屏失败后主动回到手机屏幕的两页。再补相册检查／部分可读分页／停止后有限空态／检查范围四页。94页仍是可评审的静态状态集合：手机键盘／横屏、通知认证、文件新建／搜索结果的全部异常组合、提供方和分享返回的全部失败组合、通话路由及后台系统停止等尚未全部画出，详见[覆盖表](coverage.md)。不把页面数量或按钮存在当作交互与技术验收通过。

这里记录产品目标和当前设计默认，未通过实际验证的能力保留受限状态，不因存在设计页面就视为已经支持。画布组织、工具校验与验证记录见[设计工具链记录](../../docs/research/design-system-and-toolchain.md)。本轮产品变更与工程验收见[实施记录](../../docs/implementation/product-refinement.md)。

## 2026-10-18 产品收敛

音源与剪贴板独立页面已移除，设备详情直接提供自动同步剪贴板与显示导航键。无线引导新增旧版 TCP/IP 入口与地址/端口表单 `OpFKk`。普通页面采用 Flex 内容流和紧凑共享组件，取消紫色装饰、厚重边缘与普通内容玻璃卡；远控增加默认三键及只通过关闭按钮离页的规则。分析与验证见[本轮实施记录](../../docs/implementation/product-refinement.md)。
