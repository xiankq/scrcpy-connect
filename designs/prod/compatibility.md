# 平台、权限与能力边界

本文件定义功能准入与受限时的产品行为。安装条件、被控系统、协议能力和单项功能分别判断；版本满足门槛只允许尝试，实际可用还取决于权限、编码器、设备和应用。

## 主控与被控的边界

主控面向 Android、iOS、macOS 和 Windows。各平台共用设备归属、提交保护和恢复规则；平台权限、USB、系统文件选择、通知与媒体输出分别适配。某个平台能编译、某个模拟器能运行，均不代表其他平台或量产设备已经交付。

主控使用普通应用身份与正常的平台授权，不要求本机开启调试，也不提供依赖本机 ADB 授权的增强入口。被控侧的调试权限不能补齐主控的后台剪贴板、麦克风或通知权限。主控安装下限由各平台的应用配置与依赖决定，不能沿用被控 Android 的最低版本。

被控 Android 无需 root 或安装配套 APK；用户仍需启用调试并信任主控。免安装包含通过已授权连接部署和执行临时服务，不表示被控设备没有代码执行，也不赋予主控系统应用权限。临时服务只承担已授权活动，停止、取消和连接结束时释放所属资源；无法确认结束时如实报告，不将删除临时文件当作进程已退出。

## 功能条件与替代路径

| 能力 | 准入条件与受限处理 |
| --- | --- |
| 基础连接 | 按实际协议和授权握手判断；缺少新协议能力不直接排除旧设备。配对、连接、地址与加密策略见[设备与连接](device-connection.md) |
| 整机画面与输入 | 被控 Android 5.0／API21 起；启动时确认捕获、编码及厂商输入权限。失败报告具体能力，其他已可用功能继续保留 |
| 独立应用窗口 | API29 起，另需系统和应用允许真实任务呈现；不支持时由用户选择手机屏幕，不能静默克隆或迁移应用 |
| 活跃应用 | API29 起且能读取当前用户的真实任务；无法读取时显示受限，不用已安装列表冒充活跃任务 |
| 应用图标 | 从被控设备当前用户的应用资源获取；资源缺失与读取失败分别表达，不用主控图标冒充 |
| 设备输出声音 | API30 起；Android 11 启动捕获还受解锁条件约束。受保护内容及应用可限制捕获；有画面不代表有声音，设备声音不等于各窗口的独立应用音轨 |
| 文本剪贴板 | 按两端实际可读文字及权限判断；非文字、平台拒绝或无法读取的内容及后台限制不作为同步成功，规则见[声音与剪贴板](interaction-rules.md#声音与剪贴板) |
| 文件、搜索与相册 | 以当前身份可读范围为准；权限错误、未检查与空目录分开。旧系统也需保留完整文件大小及真实错误，不能静默截断或漏项 |
| 图片与视频预览 | 缩略图和原文件是不同资源。图片按实际解码及方向呈现；当前视频缩略图要求 API27，低版本提供明确限制和原件入口，不能下载整段原视频冒充缩略图 |
| 通知与通话观察 | 按系统接口、当前用户及权限单独检查；缺少权限时不能通过安装被控 APK、root 或权限绕过补齐 |

一个扩展功能受限不等于整台设备离线；只拦截相应操作。未知状态保留检查入口，需要设置时明确在哪一端完成，不支持时提供适用替代路径，避免循环引导无效授权。

## 当前交付边界

通话入口当前只请求打开被控手机的系统通话界面；系统接受请求不证明界面已经可见。安全针对某次呼叫的接听、拒接、挂断和双向通话语音尚未交付，不能以设备输出声音替代双向通话能力。通话稿中的目标状态仍按[流程覆盖](coverage.md)验收。

系统提醒需要主控平台支持、正常权限和仍有效的被控观察。Windows 当前明确不支持发布；iOS、macOS 的权限、通知中心和点击行为不能借用 Android 的运行结果。提醒不可用不应阻止应用内查看设备与内容。

暂停不可见控制页面目前停止本地呈现，保留会话；不承诺远端捕获或编码已停止，也不据此宣称被控耗电已经降低。保留会话、恢复画面和重新创建会话分别处理。

画质偏好表示请求上限，最终尺寸、帧率、编码器及声音以设备实际协商与输出为准。编码或解码不可用时给出原因及可选择的调整路径；不得仅因静态画面没有新帧判定连接断开，也不静默降低已提交任务的结果标准。

主控不支持光学渲染时使用明确的非光学回退，仍保留操作、标签与内容；系统要求降低透明度或提高对比度时优先使用实体材料。平台已声明支持但材料初始化失败时进入可重试的启动错误状态，不能冒充能力不支持或进入缺少必要服务的主界面。具体材料和布局由[视觉规范](../design.md)负责。

## 数据与授权保护

授权密钥仅用于对应连接身份，本机保存与显式导入的规则见[授权密钥](device-connection.md#授权密钥)。设备元数据恢复、系统云备份、页面链接和发现结果均不能恢复信任。产品不将当前本机保管方式宣称为硬件不可导出保护。

授权材料、配对码、通知正文、回复草稿与剪贴板内容不进入诊断日志、错误详情或分享报告。需要排查时先提供不含秘密的状态和失败阶段；复制、系统分享及远端写入由用户的明确动作授权。系统提醒的隐私边界见[通知与通信](interaction-rules.md#通知与通信)。

兼容或权限失败必须保留用户数据与已有重要活动。资源不足时拒绝新准入或明确暂停所属活动，不为了新任务无提示结束其他设备的窗口、传输或通话。恢复与提交结果不能由旧回执、过期地址或页面重建推断。
