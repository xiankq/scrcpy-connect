# 设备与连接

设备记录、配对信任、连接和控制会话分别表达；其中一项存在不证明其他项可用。

## 设备列表

同类卡片显示名称、实际状态与动作。离线仍能进工作台查看本机记录及偏好，远端操作提供连接／重授权入口，恢复后不重放原操作。最近信息标注时间，不把旧电量当实时值。

菜单提供开始连接／断开、连接配置、移除；连接中禁重复请求。断开与移除说明活动影响并确认；移除记录不撤销手机调试信任。名称、型号或 IP 相同不足以合并 USB／无线记录，身份不明时保留独立记录。

## 添加与发现

同一添加页默认无线配对码，另有扫码、USB、IP 四个平等入口；切换保留未提交字段，取消旧二维码及 USB 检查，忽略迟到结果。表单保留字段、条件和主动作，完整教程放“连接帮助”。

“发现设备”进入二级页，支持刷新。结果按名称、实际端点、信任状态排列，IPv6 用 `[IP]:端口`。选中返回原表单带入已知方式；发现不授予信任。

| 方式 | 规则 |
| --- | --- |
| 无线配对码 | 填地址、配对端口及配对码。失效保留地址。配对后仍须连接；未连成显示“已配对，尚未连接”，可补连接端口，无需重配 |
| 扫码配对 | 主控出示二维码，由被控手机无线调试系统扫描；可重新生成。主控无需调试或扫码权限 |
| USB | 分别取得主控 USB 访问许可和被控调试授权。“我已允许”仅重新检查；多设备先选目标，拔线后重新授权，不改连其他设备或复用旧句柄 |
| IP 连接 | 填 IP／主机名和连接端口，默认 5555，范围 1–65535，无配对码；新建须已有授权允许按地址连接，仅用于可信网络 |

配对端口和连接端口不同。已知传输方式随记录／发现结果保留，不能按端口数字推断或因编辑 IP 表单而降低加密保证。跨网使用已有 VPN、网关或隧道。

## 连接过程

提交后显示无中心文字及假百分比的环境场，保留返回和取消；减少动态时静止。取消只结束本次尝试，保留已有信任。失败或未知回原表单，不自动重试。身份检查完成后连接可用，可选设备信息稍后更新；旧结果不能更新新连接。

## 设备工作台

名称只在顶栏；摘要卡显示型号、状态、连接方式、实际端点及实时电量，点击进入设备数据。快捷操作和活跃应用之后按以下分组：

- 设备设置：名称、连接配置、转为 IP、画面、自动剪贴板、导航键、启动点亮、最后画面关闭锁屏、保持唤醒。
- 连接能力：功能支持、连接诊断、当前活动。
- 设备管理：断开、移除。

改名仅改本机记录。偏好默认值见[交互规则](interaction-rules.md)。诊断提供网络、服务、授权和设置的结果及重查，编辑连接到配置页，不提供终端。

## 设备数据

只读页按设备与系统、电池与电源、屏幕与显示、网络与连接、内存与存储分组。支持刷新，失败、未支持与未知分开；离线数据标注时效，迟到刷新保持原设备与连接归属。

## 设备连接配置

复用添加页四种方式，隐藏发现，已绑定私钥来源只读。编辑原记录，沿用身份与可复用字段；重连／重配仍须核验同一目标，不新建设备。取消保留原配置。

## 授权密钥

全局设置提供指纹、导入和重置；默认本机生成保管，不随云备份或设备元数据迁移。导入用多行文本或文件填入同一输入框，文件选择不直接提交；校验 PEM、Base64、32 KiB 上限、RSA-2048 和指数 65537。无效输入保留旧身份，不回显已有私钥。

替换／重置须确认受影响的全局身份连接及活动，设备专属身份不受影响。添加默认全局，也可设专属自定义私钥；建立记录后来源与指纹只读，不静默换密钥。私钥不进入普通设置导出、元数据、快照或事件。

## 转为 IP 连接

从已授权连接发起，只能选择当前设备网络接口提供的地址，不手填；无地址可重查。确认说明会重启调试、打断活动且不使用无线调试加密。经原授权连接开端口，以同一身份验证成功后更新原记录。

失败／取消保留原字段；若端口可能已重启而结果未知，先核对，不自动重放或假报成功。
