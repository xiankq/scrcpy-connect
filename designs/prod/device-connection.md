# 设备列表、管理与连接流程

设备列表是固定首屏；选择设备后进入其工作台。设备身份、配对信任、当前连接与控制会话分别表达，不能由其中一项推断其余状态。

## 首屏与设备记录

有一台或多台设备均使用同一种设备卡，显示名称、明确连接状态与当前可执行动作。已连接卡进入该设备工作台；离线卡连接，授权失效卡重新授权。所有卡片都能进入设备详情。无设备、检查中、全部离线和搜索无结果是列表的不同状态，不是另外一套首页。离线只呈现带时间的最近连接信息；不把旧电量冒充实时值。主动断开显示停止自动重连，与暂时掉线区别。

“设备记录”“当前连接”“控制会话”分别表达。首次配对不是已经在线；连接正常也不代表全部功能可用。USB与无线是同一设备可能使用的连接方式，但不能仅凭同名、型号或IP自动认定为同一台。新增记录若身份无法确认，保留独立记录并请求核对，避免误合并。

## 添加与无线连接

设备列表添加入口进入连接方式选择；“无线调试连接”“USB 数据线”“IP 地址连接”在同一组选项中并列呈现，不将 IP 方式放入底部独立分组。附近发现、手动填写无线调试地址、无线设置指南和 USB 始终可达；没有发现设备不等于网络不可达。发现结果明确等待配对或已有信任，不因展示名称就自动获得控制权。

手动连接填写被控手机无线调试主页面的地址及**连接端口**；地址支持IP或主机名，IPv6与必要网络接口条件由实际平台反馈。端口为1–65535，不将无线调试连接固定为5555。发现失败、已有VPN/网关可达路径时也可手动连接，但不绕过授权。

“IP 地址连接”从添加页直接进入地址和连接端口表单，端口默认 5555，没有配对码；保留重新授权对象的设备身份和可复用地址。表单说明需先通过 USB 完成调试授权，并确认被控手机已允许按地址连接；此方式不使用无线调试的加密连接，只在可信网络使用。新建手动无线调试连接默认使用加密连接，用户可明确切换连接方式；界面不使用“旧版”“现代”或 TCP 等协议标签。连接方式独立于端口，不凭端口数字猜测。发现结果已明确方式时保留该方式；配对后填写日常连接地址仍使用加密无线，编辑已信任的加密连接不能悄悄降级。无线引导仅承接对应的设置、配对码与扫码步骤，不重复单列 IP 入口；缺少无线调试时保留 USB 授权与后续能力检查路径。

配对码表单填写配对窗口的地址、**配对端口**和配对码；不得把配对端口误当日常连接端口。提交按钮在未请求时可点击；点击后先校验，字段空缺或不合法时显示就近错误，不发送请求。请求进行中禁用重复提交。配对码失效后保留可复用地址，引导重新打开被控手机配对窗口并更新端口和配对码。配对完成后还要建立连接；若连接未成功，明确已经配对，允许填写连接端口，无需反复要求配对。

二维码由主控出示，被控手机的无线调试系统扫码功能扫描。失效后刷新，不要求主控开启调试或扫描权限。静态稿只描述方向与操作，真实二维码生成和ADB互操作仍需验证。被控手机没有无线调试配对时走已获授权的USB转无线引导，用户不输入命令，也不将其画成无需首次授权的一键冷启动。

## USB与授权

未插线状态先提示数据线与连接角色；主控普通USB访问许可、被控手机允许USB调试的信任确认是两个步骤，明确在哪台设备操作。主控侧系统弹窗不等于主控开启调试。界面的“我已允许／确认”只触发重新检查；必须收到系统实际授权结果才能推进，不能以用户点按钮代替授权。被控授权未允许、已拒绝或超时各有重试和返回方式；没有权限时不假装可以远程点击该授权。

建立连接过程中按发现路径、确认授权、建立连接和检查功能表达进度，允许取消；成功进入该设备工作台。取消首次连接回添加流程，保留已获得的配对信任，不能把取消当撤销信任。具体探测结果未知时展示检查中或条件说明。

## 详情、偏好与恢复

设备详情承接名称、型号/系统及信息时间、连接方式、功能支持、诊断、断开与移除，并直接提供“自动同步剪贴板”（默认关闭）与“显示导航键”（默认打开）两个设备开关；剪贴板行为及导航键行为分别见[声音与剪贴板](interaction-rules.md#声音与剪贴板)与[屏幕、窗口与输入](interaction-rules.md#屏幕窗口与输入)。离线时仍能查看本机记录和偏好，动态信息注明未更新。改名仅修改本机列表名称。连接路径切换说明会话重建和任务恢复条件，不承诺无中断切换。

主动断开保留记录并停止立即自动重连。移除记录前说明连接及活动影响，保留已完成文件；移除本机记录不等同在被控手机撤销调试信任，也不删除主控用于其他设备的授权身份。只恢复名称与偏好、主控重装/换机或授权被撤销时重新检查信任，不能直接显示为在线。

诊断围绕能采取的行动呈现网络、地址/服务、授权与设备设置，提供编辑地址、重新检查或USB替代路径，不建设命令/日志终端。短暂断线仍用全屏最后一帧与暂停标记，恢复后才接受输入，退出入口保持可达。

## 验证边界

地址字段支持的格式不等于每个平台均已验证可达；IPv4、IPv6、主机名、两端 USB 授权及无线配对需按实际路径验证。二维码静态稿不替代真实扫码互操作。功能页和服务实现也不证明所有设备均支持免安装通知、独立窗口或双向通话音频；剩余条件见[流程覆盖](coverage.md)。
