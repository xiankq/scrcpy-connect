# 设备列表、管理与连接流程

设备列表是固定首屏；选择设备后进入其工作台。设备身份、配对信任、当前连接与控制会话分别表达，不能由其中一项推断其余状态。

## 首屏与设备记录

有一台或多台设备均使用同一种设备卡，显示名称、明确连接状态与当前可执行动作。所有已保存设备均可进入同一个设备工作台，不要求当前在线；卡片尾部菜单在离线时提供“开始连接”、已连接时提供“断开连接”，并提供“连接配置”和“移除此设备”。检查或连接中显示进度并禁用重复连接；需授权时明确重新授权路径。断开和移除分别确认活动影响；取消不提交请求。离线仍可查看本机信息和偏好；远端动作被点击时说明当前不可用并提供连接或重新授权路径，恢复后不自动重放原操作。无设备、检查中、全部离线和搜索无结果是列表的不同状态，不是另外一套首页。全部离线只保留卡片各自状态，不增加“设备当前均不在线”总括提示。离线只呈现带时间的最近连接信息；不把旧电量冒充实时值。主动断开显示停止自动重连，与暂时掉线区别。

“设备记录”“当前连接”“控制会话”分别表达。首次配对不是已经在线；连接正常也不代表全部功能可用。USB与无线是同一设备可能使用的连接方式，但不能仅凭同名、型号或IP自动认定为同一台。新增记录若身份无法确认，保留独立记录并请求核对，避免误合并。

## 添加与无线连接

设备列表添加入口直接打开“添加设备”表单，默认选中“无线配对码”。页面上方先放固定高度的“发现设备”入口，点击进入独立的发现设备二级页；方式切换和表单位于入口下方，发现结果不直接铺在添加页内。方式切换在“无线配对码”“扫码配对”“USB”“IP 连接”四种形式间切换，下方原位显示对应字段或连接内容；不再先进入方式选择页，也不为各方式再打开一层独立表单页。切换形式保留尚未提交的字段，停止当前形式的二维码配对或 USB 检查尝试，旧尝试的迟到结果不能覆盖新形式。正在提交时切换方式会先取消本次尝试，保留已完成的配对信任，避免同一次操作重复提交。

页头和方式 Tab 已标识当前任务，表单正文不再重复“填写配对窗口的信息”“填写 IP 地址与连接端口”等大标题。常态只呈现字段、必要条件和当前操作：配对端口就近标明来自配对窗口，扫码说明由被控手机扫描本机二维码，USB 说明分别在哪台设备授权，IP 保留 USB 授权前提与可信网络条件。四种形式共用说明文字的字号、颜色、主动作和连接帮助的间距，数值见[视觉规范](../design.md)。完整设置步骤、端口区别、可达跨网条件和失败后的替代路径放在当前方式的“连接帮助”，不在每个常态表单追加概括性提示。校验错误、授权状态、配对结果及下一步属于实际任务内容，继续就近呈现。

无线配对码与扫码配对分别直接可选，不再包在“无线调试连接”入口下。发现设备入口在表单上方直接可见，连接帮助作为辅助入口，不取代表单；没有发现设备不等于网络不可达。发现二级页右上角提供刷新，只呈现发现列表及发现中、无结果、失败和重试状态，不提供加号、添加设备或额外的连接操作。列表项依次呈现设备名、实际服务端点和信任状态，IP:端口位于名称与状态之间，IPv4用“IP:端口”、IPv6用“[IP]:端口”，不把配对服务端口当作日常连接端口。选中结果后返回同一添加表单，带入地址、端口和已知连接方式；结果明确等待配对或已有信任，不因展示名称就自动获得控制权。普通地址输入统一使用“IP 连接”形式。

“IP 连接”在同一表单内填写地址和**连接端口**，不填写配对码；地址支持 IP 或主机名，端口为 1–65535，IPv6 与必要网络接口条件由实际平台反馈。新建 IP 连接要求已通过 USB 或现有已授权连接允许按地址连接，端口默认 5555；就近说明授权前提与可信网络条件。发现结果、已配对设备和已有设备记录带入的连接方式必须保留，不能因进入 IP 表单或编辑端口而降级，也不能凭端口数字推断方式。配对后的连接端口补全仍属于本次无线配对，使用加密连接，不增加第五个添加入口。

可达跨网路径仍可在地址表单中使用，范围见[连接服务范围](scope.md#连接服务范围)，不绕过授权。重新授权保留设备身份和可复用地址。被控手机缺少无线调试配对功能时，在同页切换 USB，完成授权后按实际能力转为按地址连接；用户不输入命令，也不将其画成无需首次授权的一键冷启动。

配对码表单填写配对窗口的地址、**配对端口**和配对码；不得把配对端口误当日常连接端口。提交按钮在未请求时可点击；点击后先校验，字段空缺或不合法时显示就近错误，不发送请求。请求进行中禁用重复提交。配对码失效后保留可复用地址，引导重新打开被控手机配对窗口并更新端口和配对码。配对完成后还要建立连接；若连接未成功，明确已经配对，允许填写连接端口，无需反复要求配对。

“扫码配对”形式在添加设备页内由主控出示二维码，被控手机的无线调试系统扫码功能扫描。“重新生成”使用与其他形式主动作一致的全宽实色圆角按钮。失效后刷新，不要求主控开启调试或扫描权限。静态稿只描述方向与操作，真实二维码生成和 ADB 互操作仍需验证。

## USB与授权

“USB”形式在添加设备页内呈现待插线、检查和授权进度，不再建立独立 USB 表单页。未插线状态先提示数据线与连接角色；主控普通USB访问许可、被控手机允许USB调试的信任确认是两个步骤，明确在哪台设备操作。主控侧系统弹窗不等于主控开启调试。界面的“我已允许／确认”只触发重新检查；必须收到系统实际授权结果才能推进，不能以用户点按钮代替授权。被控授权未允许、已拒绝或超时各有重试和返回方式；没有权限时不假装可以远程点击该授权。

识别到多台 USB 手机时，先选择本次目标再连接；缺少序列号的设备仍可选择。所选设备已拔除时要求重新检查，不能自动改连另一台。Android 通过主控系统请求 USB 访问，桌面主控通过其系统 USB 后端检查和打开设备。

USB 设备离线后，从工作台连接主动作或远端功能的连接提示重试，回到同一设备的 USB 检查形式，重新取得当前附着的系统授权与连接句柄。保留设备身份与密钥选择，不复用上次拔线前的连接句柄；连接恢复后不自动重放原远端操作。

建立连接过程中按发现路径、确认授权、建立连接和检查功能表达进度，允许取消；成功进入该设备工作台。取消首次连接回添加流程，保留已获得的配对信任，不能把取消当撤销信任。具体探测结果未知时展示检查中或条件说明。

连接完成必要的授权与设备身份检查后即可使用。电量等可选动态信息随后更新，尚未取得或查询失败时保持未知，不延长连接等待；旧连接的迟到结果不能更新新连接或离线设备。

## 工作台、偏好与恢复

设备工作台的顶栏显示设备名称，首张卡片不重复名称；小型设备轮廓与右侧摘要居中对齐，集中呈现型号、连接状态与方式、实际IP和端口、实时电量及充电状态，Android版本移入设备数据页。网络端点采用“IP:端口”（IPv6加方括号），USB不伪造网络端点。摘要区域带箭头进入设备数据，打开画面或连接主动作独立放在卡片下部。电量和充电信息只在当前连接取得有效数据后显示，过期、读取失败或离线不冒充实时。当前连接方式以“USB”“无线调试”“IP 连接”呈现，按地址连接不另称“TCP”；配对码与扫码是无线调试的授权形式，不据此推断两种当前连接方式。未知字段明确未获取或未记录，离线信息注明来自本机记录。

首卡之后依次呈现“快捷操作”和“活跃应用”；快捷操作承载文件、相册、通知及通话，应用来源规则见[设备工作台](information-architecture.md#设备工作台)。工作台下半部按固定设置行分组，所有行带左侧图标。“设备设置”依次提供“设备名称”“连接配置”“转为 IP 连接”“画面设置”、“自动同步剪贴板”（默认关闭）、“显示导航键”（默认打开）、“新画面启动时点亮屏幕”“关闭最后画面时锁屏”与“保持手机唤醒”（后三项默认关闭）。“远控屏幕比例”位于画面设置页，不再作为外部独立行；“连接能力”提供功能支持、连接诊断和当前活动；“设备管理”只提供断开与移除。画面设置、屏幕比例和生命周期行为统一见[屏幕、窗口与输入](interaction-rules.md#屏幕窗口与输入)，剪贴板行为见[声音与剪贴板](interaction-rules.md#声音与剪贴板)。离线时仍能查看本机记录和偏好，动态信息注明未更新。改名仅修改本机列表名称。连接路径切换说明会话重建和任务恢复条件，不承诺无中断切换。

主动断开保留记录并停止立即自动重连。移除记录前说明连接及活动影响，保留已完成文件；移除本机记录不等同在被控手机撤销调试信任，也不删除主控用于其他设备的授权身份。只恢复名称与偏好、主控重装/换机或授权被撤销时重新检查信任，不能直接显示为在线。

诊断只呈现网络、地址/服务、授权与设备设置的当前检查结果、原因和“重新检查”，不在诊断页重复编辑地址、切换 USB 或其他连接配置入口，不建设命令/日志终端。需要变更连接时由设备列表更多或工作台设备设置进入专门设备配置页。短暂断线仍用全屏最后一帧与暂停标记，恢复后才接受输入，退出入口保持可达。

发现、授权、配对结果与诊断只解释当前检查结果及下一步；同一项的原因与恢复动作就近呈现，不重复通用连接教程。发现列表以各设备的“等待配对”“已有配对信任”或待核对授权状态区分结果，不另外叠加总括性授权提醒；状态未知或失败时仍明确说明。重新授权回到统一表单的对应形式，保留原设备、已绑定身份与已知连接方式；已有设备的地址、端口和USB集中在专门设备配置页，私钥只读，不在工作台的其他二级页重复。

同一可信无线设备可能有多个候选地址。普通不可达可以继续尝试该设备的其他候选，仅在身份核验与连接成功后更新记录；旧发现、已撤销地址和迟到结果不能改写新连接。明确授权拒绝后停止自动重连，不继续向其他候选发送身份，也不退回明文连接。网络权限被拒绝时说明主控权限条件，手填地址不能绕过权限，也不能把权限错误等同被控设备离线。

## 设备数据

设备数据是当前目标的只读详细页，由工作台首卡摘要进入。按设备与系统、电池与电源、屏幕与显示、网络与连接、内存与存储分组，展示ADB实际可取得且对用户有用的数据：型号、品牌、产品与硬件、Android/API与安全补丁、处理器架构、电量和充电、电池健康/温度/电压、屏幕电源与锁定状态、分辨率/密度/刷新率、网络接口IP及连接端点、内存与存储使用。无需堆放原始属性键、命令日志或无助于识别和使用的调试字段；不承诺每台设备都能读取所有项目。

稳定属性与动态数据分别更新，支持主动刷新；读取失败、未支持和未知明确区分。离线只读已保存信息并标明时效，不能把缓存当作实时状态。刷新及迟到回执保持同一设备、同一存活连接归属。首卡只承载摘要，不复制完整参数表。

## 设备连接配置

设备列表更多和工作台设备设置的“连接配置”进入同一个专门设备配置页。连接配置与添加设备高度复用同一表单外壳：保留无线配对码、扫码配对、USB、IP连接四种方式Tab、对应方式字段／授权内容、当前方式主动作和连接帮助。配置页隐藏“发现设备”，私钥字段置灰、仅展示已绑定来源，不能下拉切换、输入或导入；两者的差异由同一外壳的模式表达。连接方式直接通过同一组Tab切换，不另建连接方式下拉表单。

添加设备建立新记录；连接配置始终编辑原设备，沿用可复用地址和已绑定授权身份，连接／配对后核验仍是同一目标，再更新原记录，不因切换方式或重新授权新增设备。重新配对所需的配对端口和配对码由当次配对窗口取得，不用已保存的日常连接端口代替。已有设备不提供更换私钥、恢复全局继承或独立私钥编辑页。切换形式保留尚未提交内容，明确显示对当前连接的影响，校验成功且确认后才应用；取消保留原配置。配置页不重复“转为IP连接”快捷入口，该操作由工作台设备设置进入。

## 授权密钥

设置提供全局 ADB 私钥的指纹、导入和重置，私钥默认在本机生成保管，不随系统云备份或设备元数据自动迁移；本机保管不等于已采用硬件不可导出密钥。导入要求有效 RSA 私钥，不把普通密码视作密钥；不回显已有私钥。替换或重置前均二次确认，明确说明使用全局密钥的连接将断开、活动受影响并需重新授权，使用独立密钥的设备不受影响；重置生成新的全局密钥。

全局导入和添加设备的自定义私钥以可编辑多行文本框为主，也可从本机选择单个文件，将UTF-8文本填入同一个框；选文件不直接提交，取消保留原输入。全局导入页继续前、添加设备当前方式提交前，校验PEM首尾标记匹配、非空合法Base64正文及32 KiB大小上限，公钥、加密私钥、乱码和过大文件显示就近错误；后端再核验RSA-2048私钥及指数65537，无效密钥不替换现有身份。

添加设备的无线配对码、扫码、USB和IP四种形式共用私钥选择：默认使用全局私钥，也可选择设备专属自定义私钥，在当前表单展开PEM输入与文件选择。连接建立后，该设备配置中的来源与指纹仅查看，不提供切换来源、导入或恢复全局继承；重新授权沿用已绑定身份，不另建全局密钥记录。设备身份不可用时明确报错并引导重新添加和授权，不静默回退其他密钥。全局设置的显式导入／重置仍按本节全局影响范围处理。记录恢复和密钥导入是不同操作，密钥不包含在普通设置、设备元数据导出和状态事件中。

## 转为 IP 连接

已通过任一方式建立授权连接的设备，都可在工作台设备设置中选择“转为IP连接”。“目标设备网络地址”为只允许选择的下拉字段，候选来自当前已授权目标全部可用网络接口IP，可显示接口名；不接受自由输入、不使用USB序列号或其他设备的发现地址。地址不唯一时由用户选择，唯一时预选；暂无有效地址或读取失败时明确反馈并允许重新获取，不能退回手填地址。提交前核验候选仍属于当前目标。连接端口默认5555，可改为1–65535。确认前说明重启调试连接将中断当前连接和活动，以及此方式不使用无线调试加密、仅在可信网络使用。

提交后通过当前授权连接开启指定端口，再使用当前设备的授权身份验证目标并连接，实际成功后才更新同一设备记录为 IP 连接。失败或取消不覆盖原连接方式、地址、端口及无线发现身份；调试服务可能已重启，实际连接状态仍需重新核对，不承诺原连接继续在线。离线时先引导连接；设置失败、目标身份不符或结果未知时说明实际状态并保留恢复入口，不假报切换成功，不向其他设备重放操作，也不以编辑普通地址的方式隐式降级已有加密连接。

## 验证边界

地址字段支持的格式不等于每个平台均已验证可达；IPv4、IPv6、主机名、两端 USB 授权及无线配对需按实际路径验证。二维码静态稿不替代真实扫码互操作。功能页和服务实现也不证明所有设备均支持免安装通知、独立窗口或双向通话音频；剩余条件见[流程覆盖](coverage.md)。
