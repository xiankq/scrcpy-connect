# 设备与连接

设备记录、配对信任、连接和控制会话分别表达；其中一项存在不证明其他项可用。

## 设备列表

同类卡片显示名称、实际状态与动作。离线仍能进工作台查看本机记录及偏好，远端操作提供连接／重授权入口，恢复后不重放原操作。最近信息标注时间，不把旧电量当实时值。

菜单提供开始连接／停止连接、连接配置、移除；连接中禁重复请求，但仍可停止。已连接显示“断开连接”，离线自动重连等待期间显示“等待重连”并提供“停止连接”；工作台提供同一停止入口。没有活动时直接停止；存在画面、传输等会受影响的活动时，先列出实际影响再确认，不把空闲断开也做成危险操作。移除始终确认。停止保留记录和已保存文件；移除记录不撤销手机调试信任。名称、型号或 IP 相同不足以合并 USB／无线记录，身份不明时保留独立记录。

## 添加与发现

同一添加页固定提供四个同级 Tab，顺序为“配对码、扫码、USB、IP 连接”，默认选中配对码；切换只替换当前方式的内容，不跳转新页面，USB 与 IP 不收进高级区。配对码／扫码服务首次授权；USB 按主控实际支持提供；IP 的表单就近注明“已有调试授权”。四个 Tab 在各主控上保持顺序一致；iOS 当前 USB 不可用，仍保留 USB Tab，选中后立即说明本机限制并提供切到配对码的动作，不进入授权或等待状态；其他主控同样先检查实际能力。切换保留未提交字段，取消旧二维码及 USB 检查，忽略迟到结果。

默认只展示当前方式的一句操作指引、必要字段及主动作：被控手机“开发者选项 → 无线调试 → 使用配对码配对”。配对端口及配对码有明确标签，不靠占位符区分；配对后自动尝试连接，只有未发现连接端点时才请求连接端口。新建连接统一使用本机管理的全局调试身份；添加与连接配置页不提供高级连接选项、私钥来源选择或专属私钥输入。密钥管理仅在全局设置提供。USB 数据线指引、本机及被控手机说明统一使用 body-compact 正文字体与 text 前景。完整教程留在“连接帮助”。

“发现设备”进入二级页，支持刷新。结果按名称、实际端点、信任状态排列，IPv6 用 `[IP]:端口`。选中返回原表单带入已知方式；发现不授予信任。

| 方式 | 规则 |
| --- | --- |
| 无线配对码 | 填地址、配对端口及配对码。失效保留地址。配对后仍须连接；未连成显示“已配对，尚未连接”，可补连接端口，无需重配 |
| 扫码配对 | 主控出示二维码，由被控手机无线调试系统扫描；可重新生成。主控无需调试或扫码权限 |
| USB | 分别取得主控 USB 访问许可和被控调试授权。“我已允许”仅重新检查；多设备先选目标，拔线后重新授权，不改连其他设备或复用旧句柄 |
| IP 连接 | 填 IP／主机名和连接端口，默认 5555，范围 1–65535，无配对码；新建须已有授权允许按地址连接，仅用于可信网络 |

配对端口和连接端口不同。已知传输方式随记录／发现结果保留，不能按端口数字推断或因编辑 IP 表单而降低加密保证。跨网使用已有 VPN、网关或隧道。

## 连接过程

添加、配对及设备连接提交后使用中性页面、标准进度指示和简短真实阶段反馈，不使用屏幕连接专属的渐变与三球动效。设备与真实阶段提供给读屏并在变化时播报，不使用假百分比。需要在手机完成操作时，显示必要指引。等待超过5秒不自动新增长等待文案或重试按钮，也不等同于失败。

失败、授权尝试结束、身份不符、结果待确认及已配对但未连接等异常出现时，停止进度指示，在同一中性页面直接显示原因及适用按钮，使用标准前景及次要文字色。长文字换行，大字及低高度时可滚动，避让关闭控件。核对期间保留异常反馈，仅更新真实核对状态；用户发起新的连接尝试后才恢复连接进度。

保留既有关闭和系统返回；既有悬浮展开按钮及展开内容不变。取消未完成的本次手动连接尝试并停止其自动接续，保留已有信任；若配对授权已经完成，明确保留已配对结果，不声称撤销手机信任。

失败或结果未知留在同一连接页，直接说明实际原因，不自动退回表单或弹出结果窗口。仅异常态按可确认的事实提供动作：

| 状态 | 原位说明与动作 |
| --- | --- |
| 已确认连接失败 | 显示实际失败原因及可执行的检查建议，提供“重试”和“返回修改”；重新尝试只由用户发起 |
| 本次授权未完成，尝试已结束 | 明确需要在手机允许调试，提供“重新检查”和“返回”；仍在等待授权时没有这组动作 |
| 设备身份不符 | 明确响应设备与已保存设备不一致，仅提供“返回修改”，核对目标前不重试、不覆盖身份 |
| 连接结果待确认 | 说明尚未确认本次结果，提供“重新核对”和“返回”；核对不重发原请求 |
| 已配对，尚未连接 | 说明配对授权已保留、缺少连接端口，提供“补充连接端口”和“返回”，不重新配对 |

返回修改或补充信息时保留已输入字段与已有信任；失败不新启用自动重试，原有连接意图按下述规则处理。身份检查完成后连接可用，可选设备信息稍后更新；旧结果不能更新新连接。成功立即离页，不等待进度指示结束。

本机繁忙、请求排队或容量不足不据此把设备标为离线；诊断区分本机操作失败与设备连接失效，保留各自原因。

### 保持连接与自动重连

手动连接成功后保存继续连接的意图；首次连接失败、仅添加记录或仅配对成功不启用自动连接。已有连接意图的设备暂时断线后自动重连，等待间隔逐步延长且可随时停止；进入 App 或返回前台时恢复仍有效的意图。后台是否继续重连遵循[后台保持](interaction-rules.md#后台与恢复)。

停止连接、取消手动连接及系统停止设备活动后，跨前后台和 App 重启保持停止；再次手动连接成功后恢复连接意图。调度器因后台限制或状态核验暂停尝试，不等于用户主动停止，不能清除原意图。授权失效、目标身份不符、清理或执行结果未知时停止自动尝试，保留原因及检查／重授权入口，等待明确处理。

无线调试的地址或连接端口变化时，可发现同一可信 GUID 的新端点，核验真实身份且新记录可靠保存后才替换原端点，不降低加密要求。USB 离线不自动重连，重新插入后仍通过目标选择与系统授权流程。

前次设备活动尚未确认清理完成时，停止或 App 重启仍保留待清理状态；同一设备重新开放相关活动前先核验并完成必要清理，未知时保留受限原因。待清理状态不产生新的连接意图，也不恢复已主动停止的连接。

连接恢复只恢复通信；不新开画面、播放声音、唤醒手机或重放历史操作。仍打开画面的恢复规则见[交互规则](interaction-rules.md#屏幕窗口与输入)。

## 设备工作台

名称只在顶栏；摘要卡显示状态、连接方式、实际端点及实时电量，点击进入独立“设备详情”页，型号及完整参数留在详情页。其后突出“打开手机屏幕”主动作；真实来电／通话存在时，摘要后插入同一通话卡，按[电话接力](calls.md)显示实际声音位置与入口，无通话不占位。其后固定提供文件、相册、通知、电话四个快捷入口；电话以明亮薄荷底、白色听筒呈现，进入同一完整电话页，实际能力与无通话规则见[电话接力](calls.md)。快捷操作和活跃应用之后用同一个无标题列表组，依次提供名称、连接配置、画面与控制、自动剪贴板、连接诊断、当前活动、断开、移除。不再划分设备设置、诊断与活动、设备管理。导航键及屏幕行为归画面与控制；转为 IP 归连接配置，按实际能力显示。

改名仅改本机记录。偏好默认值见[交互规则](interaction-rules.md)。诊断提供网络、服务、授权和设置的结果及重查，编辑连接到配置页，不提供终端。

## 设备详情

从工作台摘要进入独立页面，直接展示设备与系统（型号、品牌、硬件、Android/API、安全补丁、ABI、构建、序列号）、电池与电源、屏幕与显示、网络与连接、内存与存储。各区使用当前列表行及图标规范，不使用折叠栏。支持单独刷新；失败、未支持与未知分开，局部读取失败不抹掉其他区结果，离线快照标注时效，迟到刷新保持原设备与连接归属。连接诊断仅保留连接检查、处理入口和同样平铺的功能检查。

## 设备连接配置

从工作台进入专用表单页，复用添加页的字段与连接帮助，隐藏发现与普通方式切换，直接展示当前已授权方式并填入已知字段，不能一律回到配对码。不提供高级连接选项或私钥选择；普通地址编辑不改变协议或绑定身份。需要重新授权时明确选择对应添加方式并核验同一设备；重连／重配编辑原记录，不新建设备。转为 IP 是本页的独立操作，仅已有授权连接且实际支持时显示，执行前说明影响。取消保留原配置。

## 记录迁移

导入前预览将新增的记录数量及可选的全局偏好变更，默认保留现有设置；不自动合并授权、不覆盖已有设备偏好。导入保留序列号、可信 GUID 等待核验身份事实，以便重新授权时核对同一设备；这些事实不代表本机已授权，导入记录仍需授权且不恢复自动连接。明确不能恢复连接许可和当前每设备画质、电源、剪贴板设置。重复文件先提示已有导入结果，提交未知先核对，不再追加一批同名记录。导出文件中的设备地址仍属私人信息，保存与分享由用户明确发起。

记录迁移从选择文件到预览、提交和界面刷新期间禁止重复发起。导入已完成而界面刷新失败时，明确保留导入结果，提供仅重新加载本机记录的操作，不要求重新导入。

## 授权密钥

全局设置提供指纹、导入和重置；默认本机生成保管，不随云备份或设备元数据迁移。导入用多行文本或文件填入同一输入框，文件选择不直接提交；校验 PEM、Base64、32 KiB 上限、RSA-2048 和指数 65537。无效输入保留旧身份，不回显已有私钥。

默认重装 App 或更换主控后须重新授权；恢复设备记录不恢复调试信任。显式导入密钥另行处理，复制身份会让不同安装共享被控授权。

替换／重置须确认受影响的全局身份连接及活动，设备专属身份不受影响。新建使用本机统一的全局身份，不提供每设备自定义输入；已有记录保留已绑定身份，普通连接编辑不更换密钥。私钥不进入普通设置导出、元数据、快照或事件。

## 转为 IP 连接

从已授权连接发起，只能选择当前设备网络接口提供的地址，不手填；无地址可重查。确认说明会重启调试、打断活动且不使用无线调试加密。经原授权连接开端口，以同一身份验证成功后更新原记录。

失败／取消保留原字段；若端口可能已重启而结果未知，先核对，不自动重放或假报成功。
