# 设备列表、管理与连接流程

设备列表是固定首屏。设备身份、配对信任、当前连接和控制会话分别表达，不能由其中一项推断其余状态。远控生命周期见[交互规则](interaction-rules.md#屏幕窗口与输入)。

## 设备列表

所有设备使用同一种卡片，显示名称、真实连接状态和当前可执行动作。已保存设备均可进入同一工作台；离线仍可查看本机信息和偏好，远端动作被点击时提供连接或重新授权路径，恢复后不自动重放原操作。

卡片菜单离线时提供“开始连接”，已连接时提供“断开连接”，并保留“连接配置”和“移除此设备”。检查或连接中禁用重复连接。断开、移除分别说明活动影响并确认；移除本机记录不撤销被控手机上的调试信任。

无设备、检查中、全部离线和搜索无结果是不同状态。全部离线不增加总括提示，只保留各卡片状态。离线只显示带时间的最近连接信息，不把旧电量当作实时值。首次配对不等于在线，连接成功也不等于所有扩展功能可用。

USB 与无线是同一设备可能使用的连接方式，但不能仅凭名称、型号或 IP 自动合并记录。身份无法确认时保留独立记录并请求用户核对。

## 添加与发现

添加入口直接打开同一表单，默认“无线配对码”。页面上方是固定高度的“发现设备”入口，下方是“无线配对码”“扫码配对”“USB”“IP 连接”四种方式。切换方式保留尚未提交字段，并取消当前二维码或 USB 检查；迟到结果不能覆盖新方式。

页头和方式 Tab 已说明当前任务，正文不再重复大标题。常态只显示字段、必要条件和主动作；完整步骤、端口区别、跨网条件与失败恢复放在当前方式的“连接帮助”。四种方式共用字段、说明、主动作和帮助的间距规则，数值见[视觉规范](../design.md)。

发现是独立二级页，右上角提供刷新，只显示列表及发现中、无结果、失败和重试状态。列表项依次显示设备名、实际服务端点和信任状态；IPv4 使用 `IP:端口`，IPv6 使用 `[IP]:端口`。选中结果返回原表单并带入地址、端口和已知方式，但不能仅凭发现结果授予信任。

### 无线配对码

配对码表单填写地址、配对窗口显示的**配对端口**和配对码，不把配对端口当作日常连接端口。提交前校验字段，请求中禁用重复提交；失效后保留地址，引导重新取得端口和配对码。

配对完成后仍需建立连接。若连接未成功，界面明确“已配对，尚未连接”，允许补填连接端口，不要求重复配对。连接端口仍使用加密连接，不增加第五种添加入口。

### 扫码配对

主控在添加页出示二维码，由被控手机的无线调试系统扫码功能扫描。二维码可由用户重新生成；失败后刷新，不要求主控开启调试或扫描权限。静态二维码只表示方向，真实协议证据单独记录。

### USB

USB 形式呈现待插线、检查和授权进度；主控 USB 访问许可与被控“允许 USB 调试”是两个步骤。用户点击“我已允许”只触发重新检查，必须收到系统授权结果才能继续。拒绝、超时和未插线分别提供重试或切换方式。

多台 USB 设备同时存在时先选择本次目标；缺少序列号仍可选择。所选设备拔除后必须重新检查，不能自动改连其他设备。离线重试回到原设备的 USB 形式，重新取得系统授权和连接句柄，不复用拔线前的 FD。

### IP 连接

IP 形式填写地址和**连接端口**，不填写配对码。地址支持 IP 或主机名，端口为 1–65535；新建连接要求已通过 USB 或现有授权连接允许按地址连接，并仅在可信网络使用。默认端口为 5555。

发现结果、已配对设备和已有记录带入的连接方式必须保留，不能因为进入 IP 表单或修改端口而降级，也不能凭端口数字推断传输方式。跨网只使用用户已有的 VPN、网关或隧道，不绕过授权。

## 连接过程

连接请求提交后，页面显示与连接页同源的持续环境场；中心不显示任务文字或虚假百分比，底部保留取消，顶部仍可返回。减少动态效果时冻结在静态构图。

取消只结束本次请求，保留已完成的配对信任；失败或结果未知回到同一表单显示原因，不自动重试。连接完成必要身份检查后即可使用；电量等可选信息随后更新，旧连接的迟到结果不能更新新连接或离线设备。

## 设备工作台

顶栏显示设备名称，首卡不再重复。首卡集中显示型号、状态与连接方式、实际 `IP:端口`（或 USB）、实时电量和充电状态；Android 版本移入设备数据页。摘要进入设备数据，独立动作位于卡片下部。

工作台随后显示“快捷操作”和“活跃应用”，再按固定分组显示“设备设置”“连接能力”“设备管理”：

- 设备设置：设备名称、连接配置、转为 IP 连接、画面设置、自动同步剪贴板、显示导航键、新画面启动时点亮、关闭最后画面时锁屏、保持手机唤醒。
- 连接能力：功能支持、连接诊断、当前活动。
- 设备管理：断开、移除。

自动同步剪贴板默认关闭；显示导航键默认打开；新画面点亮、最后画面锁屏和保持唤醒默认关闭。离线仍可查看本机记录和偏好，动态信息标注未更新。改名只修改本机列表名称。

诊断只显示网络、地址/服务、授权和设置的检查结果、原因与“重新检查”，不重复编辑连接配置，也不提供命令或日志终端。需要变更连接时从设备列表菜单或工作台进入专门配置页。

## 设备数据

设备数据是当前目标的只读详情页，由首卡摘要进入。内容按“设备与系统”“电池与电源”“屏幕与显示”“网络与连接”“内存与存储”分组，只展示 ADB 实际可取得且对用户有意义的字段。

读取失败、未支持和未知分别表达；稳定属性与动态数据分别更新，支持主动刷新。离线只读已保存信息并标注时效。刷新及迟到回执必须保持同一设备和同一存活连接。

## 设备连接配置

设备列表菜单和工作台设备设置进入同一配置页。配置页复用添加设备的四种方式、字段、主动作和帮助；隐藏发现入口，私钥字段只读展示已绑定来源，不能切换、输入或导入。

添加设备建立新记录；配置始终编辑原设备。沿用可复用地址和授权身份，配对或连接后核验仍是同一目标，再更新原记录。切换方式或重新授权不得新增设备。取消保留原配置。

## 授权密钥

全局设置提供 ADB 私钥指纹、导入和重置。私钥默认在本机生成保管，不随系统云备份或设备元数据迁移；本机保管不等于硬件不可导出。

导入和自定义私钥使用多行文本框，也可从本机选择一个文件填入同一框。文件选择不直接提交。校验 PEM 边界、Base64、32 KiB 上限、RSA-2048 和指数 65537；无效输入不替换现有身份，也不回显已有私钥。

全局替换或重置前二次确认，说明使用全局密钥的连接和活动会受影响；设备专属身份不受影响。添加设备的四种方式默认使用全局私钥，也可选择设备专属自定义私钥。连接建立后，该设备只读展示来源和指纹，不静默回退其他密钥。

记录恢复、元数据导入和密钥导入是不同操作。私钥不进入普通设置、设备元数据、快照或事件。

## 转为 IP 连接

任一已授权连接都可在工作台设备设置中选择“转为 IP 连接”。地址为只读候选下拉，来自当前目标全部可用网络接口，可显示接口名；不接受自由输入或其他设备地址。无有效地址时允许重新读取，不退回手填。

确认前说明调试连接重启会中断当前连接和活动，且此方式不使用无线调试加密。提交后通过当前授权连接开启指定端口，再以当前设备身份验证并连接；成功后才更新同一记录。

失败或取消保留原连接字段，不向其他设备重放。端口可能已重启但连接状态未知时先核对，不能假报切换成功，也不以修改普通 IP 表单隐式降级已有加密连接。

## 验证边界

地址格式支持不等于所有平台路径可达。IPv4、IPv6、主机名、两端 USB 授权、无线发现和扫码需按实际设备验证。静态稿、主机夹具和编译成功不证明 OEM、物理线缆或量产安全已通过；证据范围见[覆盖表](coverage.md)与[验收记录](../../docs/implementation/validation.md)。
