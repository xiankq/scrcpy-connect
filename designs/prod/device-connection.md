# 设备与连接

设备记录、配对信任、连接与控制会话各有独立状态，界面按对应事实显示。

## 设备列表

设备记录按已有顺序在同一列表中显示。连接、断开和刷新只在原行更新状态与动作，搜索保留命中项目的相对顺序。每行显示设备形态、名称、当前连接状态和对应动作。点行身进入工作台，点尾部动作直接打开屏幕或开始连接。离线仍可进入工作台查看本机记录及偏好；恢复后用户再决定是否打开屏幕。最近信息标注时间。

读完设备记录并确认列表为空时，在设备页显示首次添加内容。正文的「添加设备」直达原连接入口，返回后仍是同一设备页。有设备记录时使用搜索和页头的添加按钮。搜索无匹配保留查询条件，提供「清除搜索」。

长按、右键或使用读屏的“设备操作”打开记录菜单，提供开始连接／停止连接、连接配置、移除。连接中禁重复请求，但仍可停止。已连接显示“断开连接”，离线自动重连等待期间显示“等待重连”并提供“停止连接”；工作台提供同一停止入口。没有活动时直接停止；存在画面、传输等会受影响的活动时，先列出实际影响再确认，不把空闲断开也做成危险操作。移除始终确认。停止保留记录和已保存文件；移除记录不撤销手机调试信任。名称、型号或 IP 相同不足以合并 USB／无线记录，身份不明时保留独立记录。

## 添加与发现

从设备列表点“添加”直接进入添加设备页。按“配对码、扫码、USB、IP 连接”的顺序切换，默认打开配对码。切换保留页头、附近设备入口和方式选择器，并保留输入草稿。“附近设备”独立放在方式切换前，进入发现页后可刷新。结果显示名称、实际端点和信任状态，IPv6 用 `[IP]:端口`。选中后回到添加设备页，按已确认的方式带入已知字段；普通返回恢复进入发现前的页签和草稿。发现本身不授予信任。

正文先显示该方式的表单、二维码或 USB 状态，之后是短说明和对应的帮助入口，主动作固定在底部。每种帮助独立成页，按实际步骤区分在哪台设备完成，随后返回原 Tab 并保留已填字段。来回切换 Tab 保留本次草稿；离开正在等待的扫码或 USB 流程时停止该次等待，忽略迟到结果。返回扫码时使用仍有效的二维码，需要时重新生成。

新建连接统一使用本机管理的全局调试身份。高级连接选项、私钥来源和专属私钥输入不出现在添加或连接配置页；密钥管理在全局设置。

| Tab | 底部动作与流程 | 帮助页 |
| --- | --- | --- |
| 配对码 | “配对并连接”提交手机地址、配对端口及六位配对码。配对完成后自动查找手机的连接地址并继续连接。配对码过期时，从失败状态返回修改可保留地址和端口 | 在手机开启无线调试、打开配对码弹窗、照录地址和配对端口 |
| 扫码 | 进入后由主控显示二维码并等待扫描。“重新生成二维码”替换上一张码。由被控手机无线调试系统扫码，主控无需相机或调试权限 | 在被控手机选择“使用二维码配对”、扫描主控屏幕、处理过期二维码 |
| USB | “检查连接”发起检查，“重新检查”重新读取授权和设备状态。分别取得主控 USB 访问许可和被控调试授权，多设备先选目标，拔线后重新授权。主控受限时就地说明，提供“切到配对码” | 使用支持数据传输的线、开启 USB 调试、分别确认两端的授权提示 |
| IP 连接 | “连接设备”提交 IP／主机名和连接端口，默认 5555，范围 1–65535。适用于已授权且允许按地址连接的设备，只在可信网络使用 | 确认已有授权，查找当前连接端点，再填写地址与连接端口 |

配对端口和连接端口使用各自的字段标签，帮助页给出手机端位置。传输方式与加密条件沿用授权记录或发现结果。跨网使用已有 VPN、网关或隧道。

提交表单时，若有字段需要修改，在字段下显示原因，并将输入焦点移到第一处错误。字段修正后可以再次提交。

USB Tab 在同一状态卡更新反馈。初始提示接线。检查中提示有授权弹窗时在相应设备上允许。确认检出设备后显示“已检测到 USB 设备”，需要选择时在卡片下列出可选设备。检查无结果时显示“未检测到 USB 设备”并给出重新检查入口。读取失败、主控受限与已建立连接各自显示原因或下一步。设备提示以本次检查结果为准。

## 连接过程

提交首次连接后显示同一个全屏等待页，底部固定“取消连接”。配对、查找连接地址、建立连接及身份核对在同一尝试内推进，只有实际阶段变化时更新文字。设备和当前阶段提供给读屏，需要在手机确认时就地说明操作。

无线配对完成后自动发现并连接与该授权身份及传输方式相符的端点。找不到地址、授权未通过或无法连接时，停止等待并在原页显示失败原因和可执行的恢复动作。配对授权留作后续重试，查找连接地址属于同次连接流程。

底部取消和系统返回结束本次未完成的尝试及后续自动接续，恢复发起操作的页面与草稿。若配对已产生授权，则保留已确认的信任。

失败和结果待确认共用连接页。正文长时可滚动，底部提供当前可用动作。核对期间保留原因和真实核对状态，用户发起新尝试时恢复等待。恢复动作随发生的原因变化。

| 状态 | 原位说明与动作 |
| --- | --- |
| 已确认连接失败 | 显示原因，例如未发现连接地址、配对码过期或连接建立失败。可以修正字段时提供“返回修改”，可以直接重试时提供“重试连接” |
| 本次授权未完成，尝试已结束 | 明确需要在手机允许调试，提供“重新检查”和“返回”；仍在等待授权时没有这组动作 |
| 设备身份不符 | 明确响应设备与已保存设备不一致，仅提供“返回修改”，核对目标前不重试、不覆盖身份 |
| 连接结果待确认 | 说明尚未确认本次结果，提供“重新核对”和“返回”；核对不重发原请求 |

返回修改恢复原 Tab 和可用的草稿。首次连接失败时，由用户决定是否重试；原有连接意图按下述规则处理。确认连接可用且身份正确后，首次添加直接进入该设备的工作台，可选设备信息稍后更新。迟到结果只归属原尝试。

本机繁忙、请求排队或容量不足不据此把设备标为离线；诊断区分本机操作失败与设备连接失效，保留各自原因。

### 保持连接与自动重连

手动连接成功后保存继续连接的意图；首次连接失败、仅添加记录或仅配对成功不启用自动连接。已有连接意图的设备暂时断线后自动重连，等待间隔逐步延长且可随时停止；进入 App 或返回前台时恢复仍有效的意图。后台是否继续重连遵循[后台保持](interaction-rules.md#后台与恢复)。

停止连接、取消手动连接或从系统停止设备活动后，前后台切换及应用重开都保留停止意图。再次手动连接成功后恢复该设备的连接意图。后台受限或状态待核验时暂停调度，保留已保存意图。授权失效、身份不符或结果未知时暂停自动尝试，提供检查或重新授权入口。

无线调试的地址或连接端口变化时，可发现同一可信 GUID 的新端点，核验真实身份且新记录可靠保存后才替换原端点，不降低加密要求。USB 离线不自动重连，重新插入后仍通过目标选择与系统授权流程。

前次设备活动尚未确认清理完成时，停止或 App 重启仍保留待清理状态；同一设备重新开放相关活动前先核验并完成必要清理，未知时保留受限原因。待清理状态不产生新的连接意图，也不恢复已主动停止的连接。

连接恢复只恢复通信；不新开画面、播放声音、唤醒手机或重放历史操作。仍打开画面的恢复规则见[交互规则](interaction-rules.md#屏幕窗口与输入)。

## 设备工作台

已连接、未连接、连接中、连接失败共用设备工作台。设备概览显示设备名、型号或系统版本、电量图标与已确认百分比，以及图标和对应连接方式。工作台在前台可见且已连接时读取当前连接的 Android 电池数据，每 30 秒刷新。连接断开、读取失败或电量未知时显示“—”。实际充电时显示带闪电的电池图标。右侧深色手机轮廓以图标表达连接状态，读屏播报状态。“设备详情”始终可打开，离线快照在详情标注时效。

概览下方共用一个主按钮。已连接显示“打开手机屏幕”，优先回到同设备已有的整机画面。未连接显示“连接”，连接中显示“取消连接”，已确认失败显示“重试”。连接成功后留在工作台，由用户决定下一步。文件、相册、通知、电话等依赖连接的快捷入口保持位置，暂不可用时点按原地提示“无法打开”及原因。真实来电或通话入口在概览下方，回到同一通话。

快捷入口后依次显示“常用应用”和“正在运行”两张自适应宫格卡片。快捷入口和应用宫格均以图标呈现，应用沿用原图标，功能名和应用名提供给读屏及悬停提示。

常用应用按设备保存勾选结果和顺序。为空时点“添加常用应用”直达勾选，完成后保存并回到工作台。已有应用时，点“编辑”进入管理页，可拖动把手排序，也可用读屏操作上移或下移。“选择应用”进入下一级，勾选结果带回管理页，原有条目保留相对顺序，新条目追加在末尾。管理页点“完成”保存，返回放弃本次编辑。未连接时可查看和调整已保存顺序，读取已安装应用需要连接。

“正在运行”显示当前手机用户已核验的任务，同一应用只出现一次。点图标弹出“在手机中打开”和“独立窗口打开”，按实际能力提供动作，优先复用适用的已有会话。确认空结果时显示“当前没有正在运行的应用”，仍可点“全部应用”。读取中、读取失败和需要连接显示实际状态。工作台的应用、画面、传输及通话各自处理回到原任务和核对结果。

右上角设置图标直达“设备管理”，集中名称、连接配置、画面与控制、自动剪贴板、诊断、断开和“移除设备”。移除需要确认，范围见[设备列表](#设备列表)。导航键及屏幕行为归画面与控制，转为 IP 归连接配置。

改名仅改本机记录。偏好默认值见[交互规则](interaction-rules.md)。诊断提供网络、服务、授权和设置的结果及重查，编辑连接到配置页，不提供终端。

## 设备详情

从工作台进入“设备详情”，从字段与值的单列列表开始。在同一页依序查看设备与系统（型号、品牌、硬件、Android/API、安全补丁、ABI、构建、序列号）、电池与电源、屏幕与显示、网络与连接、内存与存储。首次读取较慢时，在值的位置显示骨架。刷新期间保留同一来源的已有信息。电池与电源按 Android 状态区分充电中、放电中、已接电源未充电、已充满和未知。失败、未支持与未知分开，局部读取失败保留其他区的值，离线快照标注时效。连接诊断平铺连接检查、处理入口和功能检查。

## 设备连接配置

从工作台打开连接配置，直接显示当前已授权方式和已知字段。地址编辑沿用协议和设备身份。重新授权时选择对应方式并核验同一设备，成功后更新原记录。已有授权连接实际支持转为 IP 时显示该操作，执行前说明影响。取消保留原配置。

## 记录迁移

导入前预览新增记录和可选的全局偏好更新。默认沿用本机设置，已有设备偏好保留。新记录保留序列号及可信 GUID，重新授权时核验身份。授权成功前保持断开；画质、电源和剪贴板在本机重新设置。重复导入时显示已有结果。提交未知时先核验。导出和分享由用户发起。

记录迁移从选择文件到预览、提交和界面刷新期间禁止重复发起。导入已完成而界面刷新失败时，明确保留导入结果，提供仅重新加载本机记录的操作，不要求重新导入。

## 授权密钥

全局设置提供指纹、导入和重置；默认本机生成保管，不随云备份或设备元数据迁移。导入用多行文本或文件填入同一输入框，文件选择不直接提交；校验 PEM、Base64、32 KiB 上限、RSA-2048 和指数 65537。无效输入保留旧身份，不回显已有私钥。

默认重装 App 或更换主控后须重新授权；恢复设备记录不恢复调试信任。显式导入密钥另行处理，复制身份会让不同安装共享被控授权。

替换／重置须确认受影响的全局身份连接及活动，设备专属身份不受影响。新建使用本机统一的全局身份，不提供每设备自定义输入；已有记录保留已绑定身份，普通连接编辑不更换密钥。私钥不进入普通设置导出、元数据、快照或事件。

## 转为 IP 连接

从已授权连接发起。地址行打开选项弹层，仅列出当前设备网络接口提供的地址，无地址可重查。选择后回到转为 IP 连接页，等待确认。确认说明会重启调试、打断活动且不使用无线调试加密。经原授权连接开端口，以同一身份验证成功后更新原记录。

失败／取消保留原字段；若端口可能已重启而结果未知，先核对，不自动重放或假报成功。
