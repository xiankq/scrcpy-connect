# 信息架构

本文规定每个页面和设置项放在哪里、从哪里进入、返回到哪里。

## 设备优先

- 应用的固定首屏是设备列表，设备按设备记录保存的顺序排列。
- 选择一台设备后进入它的工作台。从工作台进入的任务页（文件、通知等）属于这台设备；页头只写任务标题，不写设备名。
- 涉及两台设备的动作（如传输），在对象旁标明来源和目标。远控画面的展开工具显示来源设备和真实连接状态，读屏也能读到。

启动顺序：

1. 应用启动后直接显示设备页和全局导航。
2. 首帧显示之后，才准备连接服务、读取设备记录。进度和失败显示在相关页面的内容区。
3. 准备完成或重试成功后，留在用户当时所在的页面。
4. 设备记录读完并确认为空，才显示首次添加的空态。

系统级的独立窗口（如桌面远控子窗口）打开时直接进入它所属的控制会话，不经过设备页。

导航：

- 设备、传输、设置三个根页面用全局导航切换，各自保留滚动位置。
- 任务页返回到进入它的页面。
- 大屏可以并排显示列表和详情。能否打开独立的控制窗口取决于平台，见[窗口与形态适配目标](compatibility.md#窗口与形态适配目标)。
- 点「添加」直接进入添加设备页。附近设备和连接帮助是它的下一级页面，返回时恢复原来选中的连接方式。流程见[添加与发现](device-connection.md#添加与发现)。
- 全局「传输」进入[传输列表](content-and-transfer.md#传输列表)，桌面可并排查看任务详情。

## 设备工作台

- 工作台从上到下是设备概览、快捷入口、「常用应用」和「正在运行」。右上角进入设备管理。入口、状态和返回路径见[设备工作台](device-connection.md#设备工作台)。
- 「通知」只显示当前设备的通知。从应用外的系统提醒进入时，先核对通知仍然有效，再打开同一个[通知列表](notifications.md)。
- 「电话」和来电提示按[电话接力](calls.md)进入手机电话界面或独立电话页。
- 排查故障进入「连接诊断」，查看设备参数进入「设备详情」。每项功能的状态和受限原因显示在对应检查项旁。

## 设置与本地数据

全局设置分「使用偏好」和「本机数据」两组。

| 内容 | 放在哪里 |
| --- | --- |
| 外观、后台保持、通知提醒、来电提醒 | 设置根页的行内开关或分段，直接操作 |
| 液态玻璃 | 设置根页的一行，行尾显示当前值，点按打开选项弹层 |
| 后台运行状态、媒体暂存、设备记录与恢复、授权密钥、本机运行日志、「关于与更新」 | 各自的详情页 |
| 单台设备的名称、连接、画面偏好 | 该设备的设备管理页，不放在全局设置 |

- 后台保持：主控支持时显示开关，不支持时显示说明。
- 「关于与更新」行尾显示已安装版本，点按进入[版本与更新](app-updates.md)。
- 外观：浅色、深色或跟随系统。首次安装默认跟随系统。
- 「液态玻璃」：跟随平台、极致、标准或关闭，保存在当前主控上。选「跟随平台」时，macOS、iPhone、iPad 默认极致，Windows 默认关闭，Android 和 Linux 默认标准。各选项的渲染效果见[材质](../design.md#材质)。
- 文字缩放、减少动态、降低透明度、提高对比度跟随系统设置，应用内不另设开关。
- 删除传输记录不删除用户文件；清理媒体暂存不删除手机上的原件。

本机的设备记录、偏好或操作记录文件损坏，或文件格式版本高于当前应用时：保留原文件，明确报错。不自动重置，也不用空列表覆盖原数据。

本机运行日志：

- 在本机按大小上限轮转保存，支持筛选、导出和清空（清空前确认）。
- 级别和来源在同一个弹层里编辑，点确认后生效。
- 设备标识脱敏后记录，只保留必要的诊断字段。
- 解码后端、硬件加速、纹理准备、画面呈现各自按实际采集到的值显示，不互相推断。

功能状态分五种：未知、需要设置、可用、受限、不可用。需要设置时说明在主控还是手机上完成。一项功能受限不影响其他功能使用。
