# 信息架构

## 设备优先

设备列表是固定首屏。产品没有主力、备用或附属手机的角色，所有被控设备同等列出；用户选择某台设备后，才进入它的工作台、应用、内容和通信。全屏远控用远端画面与可退出的会话上下文表达来源，其他远端功能页保留设备名称；文件发送、复制和消息操作明确作用对象，避免把多台手机的数据混在一起。

全局导航分为三个目的地：

| 目的地 | 用户在这里完成什么 |
| --- | --- |
| 设备 | 查看已连接、离线和需授权的设备；添加设备；进入设备工作台 |
| 传输 | 汇总跨设备任务，处理进度、冲突、失败、取消和待恢复事项 |
| 设置 | 管理外观、后台保持和本地数据 |

无设备时仍停留在设备列表，展示空态和添加入口。已有设备时支持名称／型号搜索，分别呈现检查中、已连接、离线和需授权；全部离线和搜索无结果有各自出口。离线设备显示最近连接时间，不把旧电量当作实时数据。恢复设备记录不等于恢复授权。

设备卡进入工作台，卡片的更多入口进入设备详情；添加从右上角进入独立流程，在同一组选项中并列提供无线调试连接、USB 数据线与 IP 地址连接；附近发现和手动填写无线调试地址作为已有信息的补充入口。设备详情负责名称、型号、系统、连接路径、功能支持与诊断，并区分断开连接和移除本机记录。完整入口、表单、权限和结果规则见[设备与连接设计](device-connection.md)。

## 设备工作台

工作台显示当前设备的连接状态、支持能力、近期活动和常用入口。屏幕与应用位于操作主线；文件、相册、通知和通话提供明确入口。短信通过通知或手机原应用访问，不成为单独目的地。设备能力与授权设置可从当前设备直接进入。

| 功能域 | 主要内容与操作 |
| --- | --- |
| 手机屏幕 | 直接操作整机画面、导航、键盘输入、旋转、全屏和画质 |
| 应用 | 浏览、搜索、最近与常用应用；打开独立应用窗口；切换已有会话 |
| 文件 | 目录与分类浏览、搜索、选择、发送／取回、新建文件夹、重命名与删除 |
| 相册 | 浏览图片和视频、预览、手动保存原文件与系统分享 |
| 通知 | 当前有效通知、进入手机原应用、清除、原通知提供时快捷回复 |
| 通话 | 来电、通话中、接听／拒接／挂断和可用的声音控制；主动拨号进入手机电话应用 |
| 声音与截图 | 已打开控制页面自动播放对应设备声音；就近截图 |
| 设备管理 | 设备信息、授权、连接偏好、自动同步剪贴板、显示导航键和连接问题诊断 |

应用设置、联系人、短信、相机拍摄等进入被控手机的原应用。互联产品不建设对应的应用管理、联系人、短信或拍摄工具；详细范围见[功能取舍](scope.md)。当前画面上的“更多”入口按当前任务提供操作，不把所有功能堆进同一个菜单。

## 设置与本地数据

全局设置提供外观、后台保持、媒体暂存和本地数据管理。外观页只提供浅色、深色与跟随系统；易用性偏好直接遵循系统，不另设产品开关。连接偏好、自动同步剪贴板和显示导航键归属设备详情；画质与当前会话工具就近提供。设备声音没有专用设置目的地，行为见[声音与剪贴板](interaction-rules.md#声音与剪贴板)。

设置中的“媒体暂存”汇总互联预览和接收原件的空间占用，区分受保护、可回收和正在准备的内容。用户确认后只清理可回收内容，结果报告实际释放的空间；仍有受保护内容时，不显示“已全部清空”。预览、准备、系统保存或分享仍可能读取的原件继续保留，不能因离开页面或分享返回就推断读取完成。手机上的原件和用户已经保存的文件不受影响。

再次查看已清理内容时从被控手机重新获取；已清理的传输原件不再提供保存或分享动作。分享给其他应用的原件在读取寿命无法确定时保留，并明确说明占用原因。媒体暂存不等于本机全部应用数据，也不提供自动备份。

## 手机、平板与桌面

手机一次聚焦一个主要工作区，通过底部全局导航切换目的地，通过会话列表恢复已保留窗口。

当前大屏布局为侧栏加单一当前内容区；侧栏与手机底部导航使用相同的全局目的地。内容按父容器实际可用空间布局，不能把手机稿整体缩放或把设备列表写成侧栏。多个远控窗口并行是产品目标，现有大屏工作台稿和侧栏实现不证明应用、文件及传输已能同时并排操作。窗口存在、当前呈现及设备连接的区别见[交互规则](interaction-rules.md)。

## 功能支持状态

| 状态 | 呈现与下一步 |
| --- | --- |
| 未知 | 显示正在检查或尚未检查，不承诺可执行 |
| 需要设置 | 说明缺少的设置、应在哪台设备上完成，以及完成后如何继续 |
| 可用 | 提供对应操作和结果反馈 |
| 受限 | 说明可完成的部分与限制，保留适用的替代入口 |
| 不可用 | 解释当前设备不支持的原因，避免反复引导无效设置 |

工作台按状态组织可用入口，设备能力页保留完整说明。首次授权、连接状态和某项功能的支持状态分别表达。
