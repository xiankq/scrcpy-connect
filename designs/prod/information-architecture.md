# 信息架构

## 设备优先

设备列表是固定首屏。产品没有主力、备用或附属手机的角色，所有被控设备同等列出；用户选择某台设备后，才进入它的工作台、应用、内容和通信。全屏远控用远端画面与可退出的会话上下文表达来源，其他远端功能页保留设备名称；文件发送、复制和消息操作明确作用对象，避免把多台手机的数据混在一起。

全局导航分为三个目的地：

| 目的地 | 用户在这里完成什么 |
| --- | --- |
| 设备 | 查看已连接、离线和需授权的设备；添加设备；进入设备工作台 |
| 传输 | 汇总跨设备任务，处理进度、冲突、失败、取消和待恢复事项 |
| 设置 | 管理外观、后台保持、全局授权密钥和本地数据 |

无设备时仍停留在设备列表，展示空态和添加入口。已有设备时支持名称／型号搜索，分别呈现检查中、已连接、离线和需授权；全部离线时沿用各卡片状态，不追加总括提示；搜索无结果提供清除搜索出口。离线设备显示最近连接时间，不把旧电量当作实时数据。恢复设备记录不等于恢复授权。

所有连接状态的设备卡均进入该设备工作台。添加入口打开统一表单，发现仍为二级页；完整入口、方式切换、授权和结果规则见[设备与连接设计](device-connection.md)。

## 设备工作台

工作台（例如“我的手机”）在顶栏显示设备名称，首卡集中呈现设备信息与连接状态，不再重复名称或在下方重复设备信息；字段与连接方式命名见[工作台、偏好与恢复](device-connection.md#工作台偏好与恢复)。在线提供打开手机屏幕，离线提供连接，需授权提供重新授权；检查或连接中显示进度状态并禁用重复连接。其下“活跃应用”宫格只列当前被控设备仍保留的已启动真实应用任务，包含暂在后台的应用，按包去重；已安装但未启动的应用不混入宫格。“全部应用”进入完整应用列表与搜索。宫格和应用列表的图标均从当前被控手机按包名获取，读取失败显示中性缺失标识，不用品牌绘制或主控图标替代。桌面、最近任务等系统容器不当作应用任务；无法读取时分别表达读取中、读取失败或平台受限，不能把未知当作空列表。离线不展示旧任务或旧电量为实时状态。文件、相册、通知和通话使用一组可换行的快捷入口，离线时远端操作可触发连接或重新授权提示，恢复后不自动重放。短信通过通知或手机原应用访问，不成为单独目的地。设备能力与授权设置可从当前设备直接进入。

| 功能域 | 主要内容与操作 |
| --- | --- |
| 手机屏幕 | 直接操作整机画面、导航、键盘输入、旋转、全屏和画质 |
| 应用 | 后台已启动应用宫格、全部应用与搜索；打开独立应用窗口；控制窗口管理已有会话 |
| 文件 | 目录与分类浏览、搜索、选择、发送／取回、新建文件夹、重命名与删除 |
| 相册 | 浏览图片和视频、预览、手动保存原文件与系统分享 |
| 通知 | 当前有效通知、进入手机原应用、清除、原通知提供时快捷回复 |
| 通话 | 来电、通话中状态及实际可用的控制；不能安全定位具体通话或需主动拨号时进入手机电话应用 |
| 声音与截图 | 已打开控制页面自动播放对应设备声音；就近截图 |
| 设备管理 | 设备信息、授权、连接偏好、自动同步剪贴板、显示导航键和连接问题诊断 |

应用设置、联系人、短信、相机拍摄等进入被控手机的原应用。互联产品不建设对应的应用管理、联系人、短信或拍摄工具；详细范围见[功能取舍](scope.md)。当前画面上的“更多”入口按当前任务提供操作，不把所有功能堆进同一个菜单。

## 设置与本地数据

全局设置提供外观、后台保持、全局授权密钥、媒体暂存和本地数据管理。密钥导入、重置与影响范围见[授权密钥](device-connection.md#授权密钥)。当前活动归属每台设备工作台，按设备过滤并停止，不在设置提供全局活动入口；旧全局活动地址返回设备选择。外观页只提供浅色、深色与跟随系统；易用性偏好直接遵循系统，不另设产品开关。连接偏好、自动同步剪贴板和显示导航键归属设备工作台；画质与当前会话工具就近提供。设备声音没有专用设置目的地，行为见[声音与剪贴板](interaction-rules.md#声音与剪贴板)。

设置中的“媒体暂存”展示受保护、可回收和正在准备的内容；空间准入、清理确认与外部应用读取保护统一见[媒体暂存与空间准入](content-and-transfer.md#媒体暂存与空间准入)。系统保存、原件暂存和手机上的原件是不同对象，清理入口不承担传输记录删除或远端删除。

## 手机、平板与桌面

手机一次聚焦一个主要工作区，通过底部全局导航切换目的地，通过会话列表恢复已保留窗口。底部导航支持点击及横向拖动切换，触点立即得到反馈；当前选中项始终对应已呈现的目的地，手势反馈不另产生一份导航状态。系统要求减少动态或降低透明度时仍保留目的地标签、选中反馈和操作能力。

当前大屏布局为侧栏加单一当前内容区；侧栏与手机底部导航使用相同的全局目的地。内容按父容器实际可用空间布局，不能把手机稿整体缩放或把设备列表写成侧栏。多个远控窗口并行是产品目标，现有大屏工作台稿和侧栏实现不证明应用、文件及传输已能同时并排操作。窗口存在、当前呈现及设备连接的区别见[交互规则](interaction-rules.md)。

## 功能支持状态

| 状态 | 呈现与下一步 |
| --- | --- |
| 未知 | 显示正在检查或尚未检查，不承诺可执行 |
| 需要设置 | 说明缺少的设置、应在哪台设备上完成，以及完成后如何继续 |
| 可用 | 提供对应操作和结果反馈 |
| 受限 | 说明可完成的部分与限制，保留适用的替代入口 |
| 不可用 | 解释当前设备不支持的原因，避免反复引导无效设置 |

工作台首卡承载设备信息，下半部承载设备偏好、当前活动与管理，功能支持和连接诊断各有一个入口；不再提供独立设备详情页。控制窗口只管理互联保留的控制会话，不重复列举手机后台应用。画质归属控制窗口管理入口，作用于后续新建窗口；屏幕与输入工具只作用于选定控制会话，工作台不另设重复入口。设备能力页保留完整说明。首次授权、连接状态和某项功能的支持状态分别表达。
