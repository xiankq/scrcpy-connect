# 信息架构

## 设备优先

设备列表是固定首屏，设备按记录顺序展示。选择设备后进入该设备的工作台。所属任务页保留设备归属，常规页头只显示任务标题。跨设备动作在对应对象旁注明来源与目标，远控展开工具显示来源与真实连接状态，读屏可查询。

应用启动直接进入设备页并显示全局导航。连接服务和设备记录在首帧之后准备，进度与失败在相关页面内容区显示。准备完成或重试成功后，保留用户已选页面。设备记录读完后才显示首次添加空态。独立应用窗口沿用所属控制会话的入口。

设备、传输、设置三个根页面使用全局导航，切换时各自保留浏览位置。任务页返回来源。大屏可并排显示列表与详情，独立控制窗口按[宿主能力](compatibility.md#窗口与形态适配目标)提供。

设备列表的“添加”直达同一个添加设备页，配对码、扫码、USB 和 IP 连接在页内切换。附近设备和四种连接帮助是该页的下一级任务，返回恢复原添加方式。提交后进入连接页，等待和失败在同页转换，连接成功直接进入设备工作台。见[设备与连接](device-connection.md#连接过程)。

全局“传输”用“传输中”和“已结束”切换任务列表。每条任务可进入对应详情；桌面可在列表旁查看详情。“清空记录”属于已结束列表。见[传输列表](content-and-transfer.md#传输列表)。

## 设备工作台

同一工作台承载四种连接状态。设备概览后依次是文件、相册、通知、电话和两张应用宫格。真实来电或通话入口出现在概览和快捷区之间。“常用应用”下设管理和勾选两级页面，“正在运行”提供打开方式菜单与全部应用入口。右上角设置直达设备管理。见[设备与连接](device-connection.md#设备工作台)。

通知页属于当前设备，点通知条目直接接续手机画面。清除图标独立处理单条或当前设备的通知集合。应用外提醒经过核验后回到同一列表，见[实时通知](notifications.md)。

工作台“电话”快捷入口根据实际通话与接力能力打开手机原界面或进入同一通话。来电提示和工作台通话入口沿用该路径。完整接力使用独立电话页，返回保留通话；拨号、联系人和通话记录留在手机原应用。见[电话接力](calls.md)。

故障处理进入“连接诊断”，设备参数进入“设备详情”。功能状态和受限原因随检查项展示。

## 设置与本地数据

全局设置按“使用偏好”和“本机数据”组织。外观、后台保持和提醒等高频偏好在行内直接操作。媒体暂存、设备记录与恢复、授权密钥、本机运行日志和「关于与更新」进入各自详情。单台设备的名称、连接和画面偏好归对应设备的管理页。后台保持根据主控实际支持提供控件或说明。

「关于与更新」在设置行尾显示已安装版本，详情提供构建号、检查更新、继续下载或安装的入口、更新记录与开源许可。[应用版本与更新](app-updates.md)

外观选浅色、深色或跟随系统。「液态玻璃」可选跟随平台、极致、标准或关闭，选择保存在当前主控。跟随平台时，macOS、iPhone 和 iPad 默认极致，Windows 默认关闭，Android 和 Linux 默认标准。文字缩放、减少动态、降低透明度和提高对比度遵循系统。删传输记录不删用户文件，清暂存不删手机原件。

本机设备记录、偏好或操作记录损坏、格式高于当前版本时，保留原文件并明确报错，不自动重置或以空列表覆盖原数据。

运行日志在本机有界轮转，支持筛选、导出和确认清空。筛选弹层同时提供级别与来源。记录脱敏设备标识及必要诊断字段。解码后端、硬件加速、纹理准备和画面呈现按各自采集到的事实展示。

功能状态区分未知、需要设置、可用、受限、不可用；说明设置在哪一端完成。单项受限不阻断其他功能。
