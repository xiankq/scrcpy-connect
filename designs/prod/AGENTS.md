# 产品规格维护

从 [README](README.md)选择责任文档。范围、能力边界、入口、连接、内容、交互和覆盖分别维护；跨文档引用具体章节，不复制默认规则。

描述对象、触发条件和可观察结果。设备连接、控制会话、已打开控制页面及当前操作设备是不同对象，术语按根目录[词表](../../GLOSSARY.md)使用。

新增页面或设置项前，按[信息架构](information-architecture.md)核对对象归属、现有入口与是否需要持久偏好；运行中的状态或派生行为不直接转化为用户设置。修改返回、关闭、声音或剪贴板时，核对[交互规则](interaction-rules.md)中的生命周期及设备切换行为。

本文档集描述用户可见规则及保护这些规则的约束；协议字段、具体资源对象、构建命令和历史实验留在实现与研究资料。颜色、字号和材料数值归[视觉规范](../design.md)。长期产品规则须在本目录独立成立，不能只链接可移除的报告。

新增约束先核对实现和已接受取舍，区分现行行为、能力目标与待验范围；研究建议不直接成为承诺。按[验收依据](coverage.md#验收依据)判断证据，已有设计状态不等于功能交付。修改默认行为直接更新责任正文和受影响流程，避免追加互相矛盾的修订段落。
