# 产品规格

从 [README](README.md) 选择行为的责任文档，直接更新该处规则，以用户操作、结果和失败恢复描述行为。术语沿用[词表](../../GLOSSARY.md)，视觉数值维护在 [design.md](../design.md)。

先写可观察的行为。能力受限时说明适用条件、此时页面怎么做和可走的路径。逐段删除重复保证、背景辩解与已经由标题表达的说明。

新增页面或设置先核对[信息架构](information-architecture.md)，设置只表达用户选择，派生状态按信息展示。修改返回、关闭、声音或剪贴板时核对[交互规则](interaction-rules.md)。能力目标与已交付行为分别表述，交付结论须有运行证据。
