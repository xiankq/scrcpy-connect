# 产品规格维护

从 [README](README.md)选择规则的责任文档。范围取舍、入口组织、连接条件、交互行为和流程覆盖分别维护；跨文档引用具体章节，避免重复一整套默认规则。

描述对象、触发条件和可观察结果。设备连接、保留会话、已打开控制页面及当前操作设备是不同状态，术语按根目录[词表](../../GLOSSARY.md)使用。

新增页面或设置项前，按[信息架构](information-architecture.md)核对对象归属、现有入口与是否需要持久偏好；运行中的状态或派生行为不直接转化为用户设置。修改返回、关闭、声音或剪贴板时，核对[交互规则](interaction-rules.md)中的生命周期及设备切换行为。

本文档集描述用户可见规则；协议字段、资源租约、渲染库与构建命令归[工程文档](../../docs/implementation/architecture.md)。颜色、字号和材料数值归[视觉规范](../design.md)。

流程覆盖中的“已有设计状态”只表示源稿包含代表状态；实际功能与运行证据由验收记录说明。修改默认行为应直接更新所属规则和受影响流程，不能仅在文末补充一段修订说明。
