# 页面交互与动效

动效标明触点和当前状态。业务结果、取消和页面恢复由[交互规则](prod/interaction-rules.md)及对应[产品规格](prod/README.md)定义，尺寸和材质见[视觉规范](design.md)。数值沿用 [Prism UI 0.1.3](https://github.com/chen08209/prism_ui/tree/v0.1.3)。

## 时长与曲线

| 用途 | 值 |
| --- | --- |
| 短过渡（淡入、标签切换、按压后的填充变化） | 200 毫秒 |
| 常规过渡（列表增删、页面淡入淡出、开关） | 300 毫秒 |
| 进入曲线 | `(0.05, 0.7, 0.1, 1)` |
| 标准曲线 | `(0.2, 0, 0, 1)` |
| 弹簧 | 默认临界阻尼（无回弹）。只有导航镜片移动（回弹 0.15）、底部导航落位（0.32）、页头按钮出现（0.25）和拖回（0.15）带回弹 |

开启减少动态效果时，所有时长为 0，只保留状态结果。

## 触点反馈

- 任何按钮按下都不缩小。
- 实体按钮与列表行：浅色下降到 75% 不透明，深色叠加 20% 白；释放用 250 毫秒恢复。列表行按下时用 `pressed` 覆盖整行，隐藏其上下的分隔线。
- 滚动区内的按压延迟 150 毫秒才显示，快速轻扫不闪。
- 玻璃按钮与按钮组：按住时向外膨胀，最多放大 16 点（不超过 25%），弹簧刚度 311、阻尼比 0.593，带一次轻微回弹；手指处出现 16% 的白色辉光，覆盖约 高/√2，进入 120 毫秒、离开 360 毫秒并向外扩散。拖动时玻璃朝手指方向拉伸，最多拉长短边的 7/32。
- 相邻的玻璃胶囊按下时彼此融合（smooth-min，静止 8、按下 16）。
- 光照不跟随手势或陀螺仪，高光固定在上下边缘。

## 导航与覆盖层

- 页面推入：300 毫秒临界阻尼弹簧，被覆盖页向左移 30% 并压暗 10%。支持从左缘拖回：超过 46.65% 宽度或速度大于 1.5 倍宽/秒时返回。
- 桌面页面：200 毫秒淡入加短位移，返回沿同一路径。工作区切换设备或任务时只过渡详情窗格，列表、滚动位置和焦点保留。
- 底部导航：选中托盘随目标页签移动（400 毫秒，回弹 0.15），按住或横拖时托盘化为放大镜，速度越快越扁（宽 ×(1+s)、高 ×(1−1.4s)），释放后落在切换成功的目的地。各根页在原位交叉淡化 220 毫秒，并保留各自的滚动位置。
- 分段：选中胶囊 250 毫秒滑到目标项，标签字重 200 毫秒过渡。传输的两个列表各自保留滚动位置；添加设备只交叉淡化方式对应的内容，页头、附近设备入口和分段保持不动。
- 搜索：标题淡出，搜索框和关闭按钮从页头标题槽展开，正文保留同一个滚动区；关闭时恢复。
- 锚点菜单：从触发按钮“生长”出来，按钮的 regular 玻璃过渡到 menu 玻璃，以水滴形融合展开（弹簧刚度 400、阻尼比 0.754，约 450 毫秒），关闭时缩到 0.8 并淡出。
- 确认框：从 1.2 倍缩到 1 并淡入（约 400 毫秒），关闭只淡出。遮罩同时淡入。
- 抽屉：弹簧入场，可拖动；停靠在 9/16 和 0.9 屏高。叠放的上一层缩到 0.92 并露出 10 点。
- 横幅：自顶部弹入，信息与成功停留 3 秒、警告 5 秒、错误 6 秒，170 毫秒淡出。

## 等待与状态切换

- 首次等待超过 150 毫秒时，在受影响的区域显示骨架；骨架在 50%–100% 不透明之间以 1.6 秒为周期呼吸。真实内容在原位 200 毫秒淡入。已有内容的刷新、进度更新和分页保留在当前位置。骨架离页、进入后台或减少动态时停止。
- 整页加载超过 400 毫秒才出现：三枚形状依次跳起，一轮 1.2 秒。首帧到达后直接交给真实画面，加载层 200 毫秒淡出，淡出期间画面已可交互。失败时形状停止，原位显示原因与重试。
- 首次添加插画中的卡片和手机从初始位置靠近，约 320 毫秒停稳。减少动态时直接显示停稳帧。
- 文件选择只过渡勾号和操作栏，条目保持原位。
- 列表增删：300 毫秒，高度用 easeInOutCubic，内容在后半段淡入。
- 更新提示从略低处短位移入场。

## 直接操纵与辅助偏好

- 远控把手拖动时跟随指针，释放后吸附到最近的侧边；吸附可被下一次拖动打断。画面工具面板从把手所在边缘展开，收起时回到同一边缘，收起途中可再次展开。
- 减少动态时保留按压、选中和阶段信息，持续等待改为静态提示，浮层即时定位，省去位移、膨胀和形变。
- 降低透明度或提高对比度时，玻璃换成同尺寸的实体浮层面，动效不变。

## 各流程的动效位置

| 流程 | 动效位置 |
| --- | --- |
| 设备与工作台 | 底部导航切换、详情窗格切换、设备列表与工作台首次到达、常用应用排序 |
| 授权与添加设备 | 连接方式切换、附近设备读取、连接阶段文字、确认框 |
| 画面、控制与应用 | 首帧交接、把手吸附与工具面板、画面设置、应用接续 |
| 文件与相册 | 目录与搜索结果原位淡入、视图菜单从触点生长、缩略图解码后淡入 |
| 传输与交付 | 分段切换、详情窗格切换、首次任务读取、冲突与系统交付反馈 |
| 通知与电话 | 首次通知读取、清除后的列表收拢、来电期间缓慢呼吸的环线 |
| 设置、数据与更新 | 页面推入、选择与确认浮层、开关、更新提示入场 |
| 窗口与辅助偏好 | 跨阈值时侧栏宽度与正文位置逐帧衔接，图标固定在导航轨道中心，文字随展开显现；窄窗切回底部导航，保留页面与滚动位置 |
