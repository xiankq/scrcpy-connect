# 页面交互与动效

动效标明操作触点和当前状态。业务结果、取消和页面恢复由[交互规则](prod/interaction-rules.md)及对应[产品规格](prod/README.md)定义，尺寸和材质见[视觉规范](design.md)。

## 按压、导航与覆盖层

- 玻璃操作在按下时产生局部高光和轻微形变，释放后用弹簧回到稳定形态。形变参数由 `glass-interaction` 维护。实体按钮沿用各自的按压、悬停和焦点反馈。
- 搜索从页头唤起。标题淡出，输入面和关闭动作从标题槽展开，正文保留同一个滚动区。关闭时恢复标题和原操作。开启减少动态效果时直接切换。
- 手机页面沿用平台导航过渡。桌面页面用 200 毫秒短位移和淡入，返回沿同一路径。工作区切换设备或任务时只过渡新详情窗格，保留列表、滚动位置和操作焦点。
- 页签共用 180 毫秒短过渡，使用缓入缓出曲线。主导航的选中镜片跟随目标页签，设备、传输和设置的页面在原位交叉淡化。传输页的选择器保持在列表上方，两个列表各自保留滚动位置。添加设备只交叉淡化方式对应的内容，表单随内容收展，页头、附近设备入口和方式选择器保持稳定。点选立即更新选中状态与操作归属，连续切换从当前透明度衔接。减少动态时即时切换。
- 操作菜单从触点展开。抽屉用 260 毫秒入场、200 毫秒退出并支持拖动。居中弹窗用短位移、轻微缩放和淡入，关闭沿同一路径。

## 等待与状态切换

- 首次添加插画中的卡片和手机从分镜初始位置靠近，约 320 毫秒停稳。页面操作保持可用。减少动态时直接显示停稳帧。 [首次添加分镜](https://ardot.tencent.com/file/749360133997361?node_id=12%3A28)
- 首次等待超过 150 毫秒时，在受影响区域显示骨架。每组骨架共享更新节奏，渐变仅绘制在占位形状内，每 1.8 秒改变方向。真实内容在原位约 200 毫秒内淡入。已有内容的刷新、进度更新和分页保留在当前位置。骨架离页、后台或减少动态时停止。
- 首帧等待时，三球沿椭圆轨道每 4.2 秒绕行一周，分别以 2.8、3.4、3.9 秒为周期在 0.7–1.6 倍间平滑缩放。三层渐变分别以 16、20、18 秒为周期缓慢漂移并叠色。失败时冻结背景、收起三球，重试从原相位继续。首帧到达即交给真实画面，并让等待层在 200 毫秒内淡出。淡出期间真实画面可交互。离页、后台或减少动态时停止等待动效。
- 文件选择只过渡勾号和操作栏，条目保持原位。减少动态时立即切换标记。删除成功的呈现时机见[文件选择](prod/content-and-transfer.md#文件选择与批量操作)。
- 更新提示从略低处短位移入场，减少动态时直接呈现稳定布局。

## 直接操纵与辅助偏好

- 远控把手拖动时随指针移动，释放后贴边。画面工具从把手所在边缘位移、缩放和淡入，收起返回同一边缘。收起途中可再次展开。未完成的贴边吸附可由下一次拖动打断。
- 减少动态时保留按压、选中和阶段信息，持续等待使用静态提示，浮层即时定位，省去位移与形变。降低透明度时使用对应实体面。

## 各流程的动效位置

| 流程 | 动效位置 |
| --- | --- |
| 导航与设备 | 主导航与详情窗格切换，设备列表和详情首次到达，常用应用选择与排序 |
| 授权与添加设备 | 四种方式切换、附近设备读取、连接阶段文字和确认弹窗 |
| 画面、控制与活动 | 首帧交接、画面工具、贴边吸附、画面设置和活动列表；输入跟随手机画面 |
| 文件与相册 | 目录与搜索结果原位淡入，视图菜单按触点展开，图片解码完成后在缩略格或预览区淡入 |
| 传输与交付 | 传输页签和详情窗格切换，首次任务读取、冲突与系统交付的状态反馈 |
| 通知与电话 | 首次通知读取、明确操作之后的列表反馈、来电期间缓慢呼吸的窄环线 |
| 设置、数据与更新 | 页面导航、选择和确认弹层、开关反馈及更新提示入场 |
| 响应式、窗口与辅助交互 | 布局随实际窗格可用宽度调整，切换保留当前对象和焦点；辅助偏好控制动画和材质 |

桌面跨越主导航宽度阈值时，侧栏宽度和正文位置逐帧衔接。图标固定在图标轨道中心，文字随展开显现，收起时退回图标轨道。窄窗切回底部导航，保留页面和滚动位置。开启减少动态效果时直接重排。
