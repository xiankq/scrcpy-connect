# 页面交互与动效

动效交代触点、位置和状态变化。首要反馈发生在原触点，页面进入后可立即操作。各页保留自己的任务和阅读位置。通用布局、加载外观和色彩见[视觉规范](design.md)，操作权限和取消边界见[交互规则](prod/interaction-rules.md)。

## 通用反馈

| 时机 | 表现 |
| --- | --- |
| 指针按下 | 点击区域立即改变填充或前景。独立图标按钮可在 80–100 毫秒收紧至约 97%，抬起在约 160 毫秒回弹。文字、列表与表单保持几何。有效抬起才执行，滚动、长按和拖动接管时撤掉按压态。键盘焦点和悬停有各自的静态反馈。 |
| 页面前进与返回 | 单窗格跟随平台导航方向，约 220–280 毫秒。可交互返回随手势走，取消则回到当前页。分栏在详情窗格内替换内容，高亮源列表项。返回恢复原项、滚动、查询和焦点。系统弹层沿用系统过渡。 |
| 同级切换 | 玻璃导航选中面移至目标，图标和文字一起更新。页内 Tab 只变选中样式及内容区，约 160–200 毫秒过渡，选中项可见。添加设备 Tab 无底线，表单位置固定，各方式各自保存草稿。快速切换以最后一次选择为准。 |
| 局部覆盖 | 窄窗底部弹层从底部进入，宽窗居中弹窗淡入，短操作菜单贴近触点。在约 200–260 毫秒内完成展开。关闭后恢复触发控件焦点。系统返回和 Escape 先退出最上层。待提交更改、下拉关闭和失焦按对应内容的取消规则处理。 |
| 直接操纵 | 达到平台拖动阈值才接管。抓取件实时贴手，松手选择有效落点，约 220–320 毫秒收敛，可再次抓取打断。提供点按或键盘的等价操作。滑动、拖动或双指结束后不再触发原点击。 |
| 等待和结果 | 目标位置立即给出按压或已受理反馈。约 150 毫秒内完成的读取直接呈现。随后按内容用骨架、线弧或真实进度。约 180–240 毫秒原位替换，失败、部分完成和结果待确认保留实际范围。只播报阶段变化和用户可操作的结果。 |
| 减少动态和辅助输入 | 保留同样的操作路径与状态信息。移动、缩放、呼吸、扫光和持续旋转改为直接切换、静态符号或短淡入。跟随手势的元素仍提供位置反馈。减少透明度时提高玻璃背景实体度，状态保留形状和语义，不依赖颜色、触觉或动画。 |

时间用于统一相近动作的节奏。真实结果可以立即结束等待。系统手势和系统窗体使用各平台节奏。列表回到原位置时以稳定项定位。弹层、换设备和窗口重排期间保留有效草稿，迟到的结果只更新对应任务。

## 导航与设备

| 页面或状态 | 进入与操作 | 等待、中断与结果 |
| --- | --- | --- |
| 应用进入与主导航 | 直接呈现恢复位置或设备页。设备、传输中心和设置各自记住当前内容和滚动。重复点当前页签保留任务。 | 缺少数据时局部加载。恢复失败在相应区域给出动作。启动无需独立文案或等待页。 |
| 设备列表与查找 | 整张卡进入工作台，状态符号属于设备图标区。搜索时保留列表结构和输入。 | 同一设备原卡更新连接状态。清除搜索恢复原浏览位置，无匹配保留关键词。 |
| 首次设备空状态 | 确认没有设备后，设备图形进入一次，添加按钮始终可达。附近设备在添加页选择。 | 添加过程取消后回到原页，图形保持静止。首台设备确认后以真实设备卡替换空态。 |
| 设备工作台 | 已连接、未连接、连接中和连接失败共用布局。打开手机屏幕入口承接连接或重试。右上玻璃设置进入管理。 | 手机内状态槽就地变化。启动画面使用首帧过渡，缺少可用连接的功能在原控件附近提示。返回保持卡片与排列。 |
| 常用应用与排序 | 空卡保留设置入口。应用勾选与排序为两级操作，拖动手柄排序，可用上移和下移。 | 确认后宫格按新顺序更新，取消保留原顺序。提交失败保留草稿和原焦点。 |
| 正在运行与全部应用 | 空态留在原卡。已取得应用显示图标，点击弹出「在手机中打开」「独立窗口打开」等可用动作。全部应用保留搜索与选择。 | 启动反馈贴近所选应用。系统路径返回卡片或列表，窗口路径在对应窗口接续首帧状态。 |
| 设备管理与移除 | 设置图标进入管理，详情项用文本清楚表达目的。移除设备用确认弹层。 | 移除等待保留管理页。确认后返回列表并收拢原卡。取消回确认触点，失败仍可查看设备。 |
| 设备详情与名称 | 已知设备名称先出现，详情按普通信息列表布局。可编辑字段进入后聚焦原值。 | 保存仅更新对应行与工作台设备名，失败保留草稿，读取失败就地重试。 |
| 设备连接与切换 IP | 选项弹层及地址表单先展示当前值。修改、断开和恢复各有明确触点。 | 连接结果在原区域更新，保留可用地址。切换失败时明确仍可用的连接，回到首次触发位置。 |
| 诊断与不可用页面 | 诊断项共享同尺寸无底色语义图标。不可访问设备、会话或任务时展示原来源和可用去路。 | 检查进度逐项更新，未检查与失败有独立语义。重试指定项；返回优先回到原设备或原列表。 |

## 授权与添加设备

| 页面或状态 | 进入与操作 | 等待、中断与结果 |
| --- | --- | --- |
| 添加设备与四种方式 | 附近设备入口在 Tab 之上。无线调试、扫码、USB、IP 用上图标下文字，亮色直接着色图标。主动作固定底部。 | 切换只替换中部内容。表单、图示与二维码保持基线，说明位于内容下方，返回帮助后保留草稿。 |
| 附近设备 | 刷新在来源附近反馈，发现结果沿用设备行，点选后保留原发现对象。 | 未发现提供刷新或其他方式，系统权限返回只重新检查。列表变化保留选中对象，离开后发现结果不跳转页面。 |
| 无线调试与配对表单 | 先定位动作所需字段，按下一项移动焦点。提交前就地校验，错误聚焦首个需要修改的字段。 | 确认发起后进入连接等待。失败回到原表单和字段，保留可用输入，只有失效的配对信息提示替换。 |
| 扫码配对 | 二维码在固定码区淡入，尺寸、说明和操作锚点保持。刷新仅更新码区。 | 过期在原位给出刷新动作。扫描取得设备后由当前尝试接管，关闭旧尝试后忽略其迟到结果。 |
| USB 探测与授权 | 线缆示意固定，未插入、检查、授权待确认、检出和受限共用状态槽。检测到多个设备时可选择目标。 | 仅实测成功后连线变亮。拔出回到接线提示，设备选择或授权错误就在原卡说明。提交后的失败沿用连接结果。 |
| IP 连接 | 当前 Wi‑Fi 方式与地址表单同屏，地址及端口输入合法后主动作可用。 | 保留地址草稿和光标。环境变化或连接失败说明可执行下一步，重试复用有效值。 |
| 无线调试帮助 | 从对应 Tab 进入，图示对照手机设置，步骤可独立浏览。 | 返回恢复表单、键盘策略和滚动，帮助中的系统入口返回后按需重新核实。 |
| 扫码帮助 | 先说明手机在哪里扫描，码区的内容保持。 | 返回原码区，过期则在原位提示刷新。 |
| USB 帮助 | 图示区分接线和手机授权，平台差异在对应步骤显示。 | 返回保持是否接线；实际探测变化在 USB 状态卡接续。 |
| IP 帮助 | 显示地址和端口的取得位置，返回入口随阅读可达。 | 返回保留地址和端口。 |
| 正在连接与失败 | 无顶栏全屏显示设备间路径，线弧等待，底部可取消。外壳与操作槽固定。 | 确认成功立即进入工作台。失败同一视图停转并显示原因及动作。取消离开后保留提交边界，恢复原连接方式。 |

## 画面、控制与活动

| 页面或状态 | 进入与操作 | 等待、中断与结果 |
| --- | --- | --- |
| 打开手机屏幕 | 流光视口和玻璃关闭键先出现。普通等待使用线弧，保持关闭和返回可操作。 | 可信首帧原位接管，失败原位变为「无法打开」。退出返回原发起页，保留其浏览位置。 |
| 独立应用窗口与恢复会话 | 从应用动作菜单或已经核验的会话进入。打开、焦点、内容和关闭属于当前窗口。 | 等待使用同一首帧规则。创建失败保留打开来源；宿主能力不同则使用适用窗格。关闭回到源，其他窗口保留状态。 |
| 画面输入与导航键 | 控件按住时反馈，三键在原位置响应。远端触摸和缩放遵循实际画面比例。 | 暂停、失焦或断线释放输入。系统返回先作用在可关闭覆盖层，明确的远端返回动作由远端收到。 |
| 画面工具与贴边 | 点击展开，拖过阈值后工具贴手移动并收起，靠边时预示落点。松手形成长条吸附，可再次拖出或用键盘换边。 | 松手不展开，贴边后点按才展开。窗口变化保留边和相对位置，工具不挡安全区、导航键和画面焦点。 |
| 熄屏、暂停与恢复 | 熄屏保留已连接的黑色视口，点亮键在中央。暂停在原画面用小胶囊提示。 | 唤醒后由真实画面替换，暂停恢复后去除胶囊。断线保留最近画面和检查连接入口。 |
| 截图与处理 | 截图反馈出现在画面工具或结果槽，预览可用后出现保存与分享。 | 连续截图各自更新所选结果。系统取消回预览，有实际交付回执后再显示完成。 |
| 画面与控制设置 | 清晰度用弹层选择，分辨率由 320P 到原画。比例、显示和控制能力按各自入口调整。 | 应用中保留原值，确认后切换。失败保留实际值。 |
| 声音、剪贴板与画面工具操作 | 音频、同步或复制在触发位置反馈。系统授权仅在实际需要时出现。 | 退回后保留工具状态。失败说明未执行的动作，远端功能不可用时给可执行下一步。 |
| 当前活动与会话列表 | 显式进入时呈现简单记录列表。点项定位所属任务或可恢复会话。 | 已结束和无法恢复在原行显示。关闭确认后更新该会话，返回列表保留原位置。 |

## 文件与相册

| 页面或状态 | 进入与操作 | 等待、中断与结果 |
| --- | --- | --- |
| 文件目录与路径 | 标题和路径先更新，新目录用同视图骨架。文件夹用黄色图标，回上层定位进入前文件夹。 | 已读目录刷新保留旧内容。读取失败在原路径重试，全量内容由列表直接承接。 |
| 文件视图、排序与批选 | 底部液态玻璃栏承接视图、排序、选择和相关动作。选择标记与工具原位过渡。全选作用于当前范围。 | 列表和宫格共用选中项及可见项定位。退出批选回到原阅读位置，选中行不缩放。 |
| 文件搜索与筛选 | 范围、存储、类型在同一区域，宽度足够时同一行，类型选择弹层。搜索固定底部。 | 已找到结果边读边出现。调整条件只更新结果区，关闭筛选保留草稿并恢复焦点。 |
| 新建、重命名与批量删除 | 从发生操作的行或底栏打开表单或确认。删除弹窗使用「同意」「取消」。 | 确认后先在原项显示处理中。实际成功才收拢，部分成功保留失败项及相应操作。 |
| 文件详情与图片路径 | 图片直接进入媒体预览。其他文件按格式显示标识、文件名、可用元数据和取回。 | 元数据局部加载；取回完成衔接系统「使用…打开」。取消打开方式返回同一文件。 |
| 目录选择 | 继承文件浏览路径、返回定位和目录位置，固定底部确认。 | 创建目录后只在所属路径加入。取消还原目标，确认回原流程并填入所选位置。 |
| 相册、范围与批选 | 已有日期标题和缩略格持续可见。范围用底部弹层或宽窗弹窗。 | 扫描在原区显示真实范围，图片到达后逐格渲染。失败只更新相关图格；取消选择保留日期和位置。 |
| 媒体预览与播放 | 从图片缩略位置接续深色舞台，首次打开保留关闭。双指缩放围绕手势中心，视频反馈跟随播放结果。 | 打开失败在原舞台提供重试或取回。离开时返回原缩略格，缩放、滑动、系统边缘返回各有清楚接管边界。 |

## 传输与交付

| 页面或状态 | 进入与操作 | 等待、中断与结果 |
| --- | --- | --- |
| 传输中心 | 「正在传输」「已完成」各自保存位置。列表独立背景，真实缩略图或文件图标与方向同行。 | 实际字节原位推进，未知比例用线弧。完成更新记录和对应栏，持续操作期间保持当前 Tab 与焦点。 |
| 任务详情与取消 | 点任务进入所属设备和方向下的详情。暂停能力、取消及重试由真实任务状态决定。 | 已提交动作留在任务并显示结果，部分完成指出具体文件。返回原 Tab 和任务位置。 |
| 已完成记录清空 | 已完成栏提供清空，确认说明作用范围仅为记录。 | 原列表等待确认。成功一次收拢，失败保持记录，取消回原触点。 |
| 发送、目标与冲突 | 选定文件与目录后再确认。已有同名文件时显示适用解决方式，保持原文件与目标可见。 | 逐项显示进度及受影响文件。修改冲突选项回到原任务，取消只停止可取消的项目。 |
| 取回内容与本机保存 | 已知文件和来源先显示，选择本机位置或可用的手机文件取回路径。 | 读取、写入、交给系统按实际顺序反馈，取消回原详情。部分完成保留每项状态。 |
| 文档导入 | 通过系统入口选文件，回到原流程展示已选项与目标。 | 无选择返回原操作。已读取项保留，失败项可更换来源或重试。 |
| 文档导出、打开与分享 | 先显示待写入的文档身份，再打开系统保存、打开方式或分享。 | 交付回执确认为完成，等待回执保留检查入口。系统取消回表单或原文件。 |
| 系统传入分享与目标目录 | 保留系统已经交付的项目，选择设备与文件夹后由明确按钮发送。 | 进入目录选择再返回时保留项目与目的地，提交固定目标。返回、失败和部分完成可辨实际送达范围。 |

## 通知与电话

| 设置首页 | 固定列表先出现，值、开关和导航位于所属行。点击可进入外观、后台、数据、媒体暂存、身份、日志和更新。 | 返回恢复原行。单项读取或失败只占其尾槽，对其他行保持可操作。 |
| 外观 | 选择弹层显示当前值，主题、字号和辅助变化在可用系统范围内响应。 | 应用后原位更新背景，保留位置与焦点。返回设置展示真实采用的值。 |
| 后台运行与系统权限 | 开关触点旁展示当前值，访问系统设置前说明用户要执行的动作。 | 返回后复查权限和当前值，系统拒绝时原位反馈。已开启项目照常可用。 |
| 设备记录与恢复 | 迁移范围放在相关选项或确认区。导入、导出和恢复从原设置项触发。 | 系统取消保留原设置，确认后呈现实际结果。部分恢复说明受影响记录，返回原入口。 |
| 媒体暂存 | 占用大小放在相关存储行。清理从存储操作触发，可展开受影响内容。 | 清理期间占用仍用最后确认值。完成后原位更新，处理失败保留项目和重试。 |
| 调试身份 | 密钥选择交给系统文件选择器。更换或清理在所属项确认，返回保留原视图。 | 成功才更新身份显示，错误聚焦需要处理的输入。系统取消恢复焦点。 |
| 运行日志 | 固定工具栏，按真实日志区间展示内容，查看和复制沿用原选择。 | 刷新保留现有读点。系统导出取消回日志，完成或失败反馈贴近触发控件。 |
| 版本检查与更新记录 | 当前版本为设置项。检查结果可触发精细更新弹窗，更新记录在弹窗内可独立滚动。 | 未发现新版或检查失败在原控件反馈。弹窗返回保留当前版本行和焦点。 |
| 下载、校验与安装 | 更新弹窗共用标题、版本、记录和动作槽。开始后显示实际下载进度，校验阶段原位转换。 | 完成后进入宿主安装方式。交给系统后返回仍展示真实版本，校验或安装失败留原状态和恢复入口。 |
| 恢复与不可用资源 | 返回前台或重开应用优先恢复设备、目录、查询及任务。资源检查在所属正文进行。 | 暂时不可用则保留可用数据与返回，已删除资源回安全上一级。主动操作才重开控制会话。 |

## 响应式、窗口与辅助交互

| 页面或状态 | 进入与操作 | 等待、中断与结果 |
| --- | --- | --- |
| 手机、平板与桌面 | 窄窗单列与宽窗导航、列表、详情使用同一任务身份。拖拉边缘时持续重排，跨阈值转移焦点至对应内容。 | 跨阈值保留查询、表单、选中项与滚动。能力受限在相应窗格就地解释。 |
| iPhone Duo 与折叠姿态 | 外屏使用单窗格；内屏按可用矩形决定横栏、竖栏和分栏。半折叠按安全窗格放置画面和控制。 | 连续姿态变化保留任务身份和当前目标。边缘工具迁到可到达的原侧或最近边，不跨铰链。 |
| 键盘、触摸、指针与大字 | Tab、方向键、Enter 和 Escape 对应同一可见任务。触控按钮至少 44 点。大字号使用换行、滚动或重排维持操作顺序。 | 弹层打开时焦点留在弹层，关闭回触发点。键盘出现后底部动作保持可达。协助设置即时作用在所属控件。 |
| 多窗口与宿主切换 | 每窗独立保存设备、任务、焦点和工具状态。切换激活只改变该窗的输入拥有者。 | 失焦释放输入。重排与重新激活沿用该窗视口和身份，关闭回到所属来源并核实会话。 |
